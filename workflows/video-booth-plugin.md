# 视频展台插件：安装、展示与退出

本文件约定插件的安装、展示与退出行为。使用和维护说明见[视频展台插件](../docs/视频展台插件.md)，真实硬件与模型效果须现场验收。

## 目标与范围

老师在教室端创意工坊导入自己的视频展台插件，在同一台 Windows 电脑上把摄像头画面展示在 WPS 放映上方，并能启用、禁用及卸载插件。第一版仅支持教室端本机安装和运行。

课堂点评见 [数学课堂点评工作流](math-classroom-review.md)。安装和普通视频展示本身不调用 AI、不消耗班班次数；USB / 电脑摄像头展示保留原有离线能力。

## 用户已经确认

- 入口：教室端创意工坊。
- 安装：本机选择插件包，不包含远程分发或插件商店。
- 摄像头、WPS、插件宿主运行在同一台教室电脑。
- AI 沿用现有班班连接与设备月度次数。
- 点评时定格作答，手动继续；记录只在本次会话保留。

## 触发、参与者与检查点

- 安装循环：老师选择本机 ZIP 包，查看名称及版本后点击“安装”。
- 展示循环：老师点击“打开视频展台”，在全新工作台选择电脑、USB 或手机摄像头；上课展示时切为置顶浮窗。
- 停止循环：老师点击停止、禁用、卸载或退出教室端。
- 安装文件由本机系统选择器取得；班班不能提供任意可执行文件路径、替用户选文件或替用户确认安装。
- 启用和打开不自动启动摄像头；采集仍由老师在展台内操作。
- 禁用和卸载按钮应说明会停止当前展示；点击这个明确动作即执行，不再增加重复确认。

## 插件包与本机安装

第一版只实现 VideoBooth 插件所需的进程协议，不引入通用脚本引擎、第三方容器或 Cordis。插件包是 ZIP，根目录包含 plugin.json；示例：

~~~json
{
  "schemaVersion": 1,
  "id": "iceclass.video-booth",
  "name": "视频展台",
  "version": "1.0.0",
  "hostApiVersion": 1,
  "runtime": "win-x64",
  "entryPoint": "ICeClass.VideoBooth.exe"
}
~~~

- schemaVersion / hostApiVersion 固定为 1；第一版仅接受上述插件 ID。version 为三段非负整数；runtime 为 win-x64 或 win-x86，分别提供对应操作系统架构的包。
- entryPoint 为包内相对路径。所有解压项及入口必须解析到插件安装根目录以内；拒绝绝对路径、路径穿越、符号链接、目录联接和重复覆盖条目。
- 安装根目录使用现有教室端用户资料根目录下的 Plugins；不得写进源码、正式安装 EXE 目录或现有 VideoBooth 私人资料目录。
- 先在同一安装根目录的临时子目录校验、解压，再原子移入 iceclass.video-booth；安装状态最后保存。失败保留原状态，报告具体失败，不显示“已安装”。
- 包体只包含当前架构的运行文件、固定浏览器、清单及必要公共配置。不得包含私人 data、浏览器缓存、证书私钥、模型密钥或本机状态文件。
- 已安装相同 ID 时拒绝覆盖，提示先卸载再安装。第一版没有自动更新流程；卸载保留资料，因此重新安装可沿用资料。
- 新安装默认“已安装，未启用”；启用后显示“打开视频展台”。禁用状态跨教室端重启保留。

## 打开与实例归属

1. 宿主确认插件已启用、文件完整、当前教室绑定仍有效。
2. 若已有本宿主管理的展台实例，激活该窗口；否则启动包内 EXE，等待协议握手，最多 15 秒。hello 只表示进程已接入；新页面配置和同步方法就绪后才发送 ready，浏览器/手机准备另报进度。
3. 托管模式由新增启动参数 --iceclass-pipe 指定本次管道名；普通独立启动不受此参数逻辑影响。
4. 宿主创建 Windows 命名管道，限定当前 Windows 用户；使用随机名称，通过当前进程的启动记录绑定本次会话。插件在准备 WebView2 缓存和手机连接之前尽早握手；后续准备不计入 15 秒，但保留进度和取消。协议不监听 LAN，也不使用现有面向手机的 HTTP 端口传送学生图片。
5. 管道消息使用 4 字节小端长度加 UTF-8 JSON，每条不超过 3 MiB；包含 protocolVersion、requestId、type、payload。先校验消息大小、类型、来源会话和请求编号。
6. V1 消息只包含握手/状态、激活窗口、点评请求、当前帧与冻结、题目框选、展示结果、继续展示、停止和退出。它不提供 shell、任意文件读写或任意 URL 打开能力。
7. 学校服务地址、设备令牌和模型密钥由 ICeClass 管理；插件只能传送图像、动作和点评结果，不接收这些凭据。
8. 新插件不包含旧展台更新器；更换包在创意工坊完成，不自行覆盖或重启包内程序。

实例由教室端应用级服务管理；主页切换、主页隐藏或最小化不结束展示。宿主退出、教室改绑或绑定失效时必须结束该实例。管道断开后，插件自行执行停止和退出，不在后台自动恢复。

## 资料与摄像头占用

- 托管和独立预览默认使用 %LOCALAPPDATA%/ICeClass/Receiver/VideoBooth/data，支持显式 --data。本地教室端预览使用程序目录 PluginData/VideoBooth/data。旧展台资料不自动发现、复制或迁移，保持原位。
- 浏览器缓存位于新资料目录的 browser-profile。普通打开不自动申请公网证书；手机连接由老师按需准备。
- 新程序按规范化资料目录互斥。同目录的第二个实例清晰拒绝，不同隔离资料目录可并存；不按进程名阻断无关展台或结束其进程。
- 验收和自动检查使用隔离资料目录；不能借助自动配对、自动签发或重置正式资料获得通过。
- 停止摄像头后仍可保留展台操作窗口；关闭展台结束本次会话并清空临时题目、作答、结果与框选状态。
- 最小化窗口不停止采集。工作台和浮窗均保留明确的停止入口。

## 状态与失败处理

| 状态/事件 | 可见行为及状态变更 |
| --- | --- |
| 未安装 | 显示“安装插件”；不显示可用的展台打开按钮 |
| 已安装未启用 | 显示启用、卸载；不启动进程 |
| 已启用未运行 | 显示打开、禁用、卸载 |
| 启动中 | 防止重复启动；保留取消/停止能力 |
| 展示中 | 保留移动、缩放、旋转、镜像、最小化、停止；AI 状态独立显示 |
| 启动/摄像头/IPC 故障 | 显示实际错误及手动重试；不自动反复开摄像头 |
| 禁用 | 立即禁止新启动与新点评，取消点评，再有序停止、退出受管进程 |
| 卸载 | 先执行禁用和退出；确认进程已退出后才移除本插件运行文件及安装登记 |
| 退出未完成 | 最多等待 10 秒，显示“尚未停止”；保留文件、可重试停止，不假报卸载成功 |
| 锁屏、休眠、改绑、宿主退出 | 取消点评、停止展示、清空会话；恢复后由老师重新打开 |

禁用保留运行文件。卸载只删除本插件安装范围内已核验的文件，保留 VideoBooth 的配对、证书、连接设置以及 ICeClass 账号、设备绑定和班级数据。不能通过按进程名批量结束或递归删除父目录实现卸载。

## 接入位置与界面要求

- 将 web_controller/homework/classroom/home.js 的创意工坊占位入口改为实际插件页/对话框，保留现有原生 JS / CSS。
- 本机文件选择、进程管理与安装操作通过 Receiver/StudentVoiceWindow.cs 的可信主文档消息桥接入；校验来源、当前绑定版本和动作白名单，不开放任意路径执行。
- 不修改教师端入口；普通浏览器没有本机安装能力时明确提示需使用教室端。
- 沿用现有蓝白玻璃、字体、焦点及高对比度规则。键盘可完成安装、开关、停止和退出，错误有可访问的文字反馈。
- 产品界面显示“视频展台”和明确状态，不显示 IPC、会话 ID、内部路径或模型原始响应。

## 实现顺序与验收

按顺序完成可运行闭环：本机安装/启用/打开/停止/卸载；现有视频流的帧导出与冻结；再接入数学点评。每一步完成必要检查后保持普通展示可用。

| 验收情境 | 必须满足 |
| --- | --- |
| 干净配置导入正确架构包 | 安装可见，默认未启用；无相机、AI 或服务器配置修改 |
| 错架构、无效清单、缺入口、越界 ZIP | 拒绝安装，无部分可用状态，不改原资料 |
| 启用后反复点击打开 | 同一受管实例，无重复采集或第二个接收页面 |
| 本机摄像头、USB、手机 | 新工作台内选择，手机按需准备；实际硬件能力由用户现场验收 |
| 工作台、浮窗与最小化切换 | 使用同一采集源，摄像头不中断，恢复保留窗口尺寸 |
| 点评期间禁用/卸载 | 取消点评；迟到结果不再显示；摄像头实际停止后才报告完成 |
| 退出/改绑/管道断开 | 不遗留自动继续展示的受管会话 |
| 卸载后重装 | 账号、绑定、配对、证书和连接资料仍在；不自动重新办理 |
| 独立展台仍运行 | 同资料目录拒绝重复；新旧独立资料互不读取，不结束旧版 |
| 首次准备固定浏览器缓存 | 早期握手后持续显示准备状态，不把缓存复制耗时误报成握手失败 |
| 只关闭主页或切换页面 | 展台继续工作；进程生命周期不依附主页文档 |
| 低宽度、键盘、减少动态效果 | 关键操作可见可达，无文字截断或仅靠颜色表达状态 |

使用 scripts/package-video-booth-plugin.ps1 构建双架构自包含插件，并构建教室端；检查包内无私人资料。运行新插件原生及页面行为检查、宿主安装/握手/退出和数学点评检查。打开本轮最新本地构建供用户自行验收，不使用 Computer Use，不自动提交、发布或部署。

# 2.5.25 · 2026-11-25

## 纸卡打印与收答

- 班主任可从账号发放表直接打印个人纸卡，学生也可登录补印。每人一张黑白 A4，中央识别方块边长 170 mm。上沿印有编号、可折起的密码、学生报告二维码和备案号，页底列出教师查看入口、许斌的版式署名及获授权学校的教学打印范围。
- 教室安装包的“纸卡”目录提供 1-2、1-40、1-60 号通用卡。先用两张试卡在教室后排试扫，再按 A4、100% 实际大小打印需要的号段。
- 手机和白板能从高清画面中识别更小的后排纸卡，修复了斜拍时部分卡号漏收或串号的问题。教师可在“待收”查看缺号，在同一轮靠近补扫。模拟 60 人举卡时，白板和扫码手机分别收齐 60 张；实际可读距离取决于摄像头、对焦与教室光照。
- 单选、判断各收一轮，多选按所选项举 A，封存后按实际组合计人。整题未举卡记弃权，教师设置的免答单列。

## 截图备课与课后报告

- 教师在“纸卡答题”的“我的题库”上传或粘贴截图，由已配置的班班视觉模型提取题干、选项并建议答案和知识点。公式和几何图可保留题图，教师逐题核对后组题发布。
- 教师可在课堂报告中按本节知识点查看答错的学生和题号，学生登录后可查看自己的错题。

已安装的白板和 Windows 教师端可从学校平台检查更新。打印、备课和收答步骤见[纸卡答题](https://github.com/ICeCreamChat/ICeClass/blob/v2.5.25/docs/纸卡答题.md)。

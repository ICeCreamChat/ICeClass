# 班伴 2.3.0 本地验收

本页记录 2026-10-16 起的本地实现与验收过程。2.3.0 已于 2026-10-18 正式部署，平台、客户端下载和后续验证请以 [2.3.0 发布记录](发布记录-2.3.0.md)为准。

## 教室里有什么变化

四种活动、四段视频、图片、字体和笔画数据随 EXE 提供。已绑定的白板打开早读时直接载入本机资源，不再等待网络票据和网页下载。界面保持浅蓝色，原粒子浮雕内部场景和四种玩法不变；触屏长按空白处 2 秒退出全屏，窗口按钮保持原有行为。

首次绑定、读取班级、首次取得学校统计规则仍需要联网。Windows 10/11 x64 需要 Microsoft Edge WebView2；尚未安装时需提前安装运行组件。可以通过 U 盘分发客户端，避免每间教室首次下载大文件。

早读期间，声量采样和完成记录先写入本机文件。只有服务器确认收到的批次才从待传目录移除；中断、重复请求、关闭窗口和重新启动不会清空已确认写入的本机记录。服务器不能接受的异常时间或班级记录留在本机待核实，保留原因，不静默丢弃。

实时喊话、语音留言和远程操作仍依赖网络。断网期间无法即时接收；过期通知不会在重连后补播。远程音量仍按原有服务器保存的期望值在重连后应用。

## 统计怎样计算

1. ICe 在后台设置北京时间的星期、时段、统计声量门槛和到点提醒。在线客户端定期同步并缓存规则，断网期间沿用最近一次成功取得的规则；教师仍在各活动原本地面板调整玩法。
2. 客户端只在页面可见、活动运行时采样，在后台保存采样时间、声量数值、活动类型和完成事件，不保存或上传早读原始录音。
3. 恢复网络后，后台分批补传。服务器按**采样发生时生效的规则**计算有效发声秒数，按原日期归档；不会把昨天的早读算到今天。门槛或时段变化时，本机“约”计时可能与最终结果不同，以同步后的后台为准。
4. 同班同一秒继续只计一次，重复补传不会增加时长或完成量。改绑前已经记录的活动继续归原班级；无法核实归属的记录标为待核实。管理员清理记录后，迟到上传不会把清理时间之前的记录恢复。
5. 排名以已收到的记录计算。后台和 CSV 显示同步状态，长时间未同步的零记录显示“待同步确认”，不据此判断班级没有使用。比赛结算前，先让各班联网并确认待传记录已上传。

超过 366 天、明显未来时间、归属冲突等记录会保留待核实。停用或删除设备后，服务器拒绝其上传；离线电脑收到停用状态需要等到网络恢复。不要删除本机记录来处理待核实问题，应先保留原文件和原因交由管理员排查。

## 排行榜、年级对比与 XLSX

排行榜上方保留三个名次位置，有成绩时显示前三个班级；不足三班时，其余位置显示“待上榜”。同时长继续并列，不会用零记录班级补出成绩。下方班级从左向右排列，可触屏横向滑动或使用箭头；柱体改为简洁浅蓝色，高度收敛，所有班级共享至少 30 分钟的刻度，长周期随最高值扩展。

“年级对比”可单选高一、高二、高三，也可多选任意组合，或点击“全部年级”一起比较。不同年级用蓝色、浅蓝色、蓝青色区分，并显示文字图例。未按年级命名的班级在“其他”中，全部范围也包含它们。年级按当前班级名称识别，改名或年度升班后随名单更新。教师和主任的查询仍限于已有班级授权。

切换年级后，概览、前三名、名次、明细和导出一起更新；切换年级会清除之前的单班限制，之后可以再从班级下拉框选一个班。原日期筛选和本周查询保留。名次按当前所选范围重算，比较的是各班有效发声时长，不额外将年级总时长当作年级排名。

点击图中的班级、前三名卡片或数据表中的班名，会选择并滚动到下方对应班级早读日历。旧查询迟到不会覆盖新选择；切换数据表再返回时保留图表的横向位置。右上角头像中 `ICe` 完整显示，中文姓名显示姓，常见复姓保留两字。

“导出 XLSX”生成真正的 Excel 工作簿，包含“班级排行榜”和“每日记录”，只导出当前日期、年级、班级和权限范围。时长、百分比、日期和完成量为可筛选、可计算的数据，包含可编辑的原生柱状图及同步状态。图表可以随页面滚走，不固定占据屏幕；每日明细冻结表头。CSV 接口继续兼容。

## 文件和更新

| 内容 | 位置 |
| --- | --- |
| 班级绑定 | `%LOCALAPPDATA%\ICeClass\Receiver\config.json`，设备令牌继续使用 Windows DPAPI |
| 玩法偏好和 WebView2 数据 | `%LOCALAPPDATA%\ICeClass\Reading`，沿用原平台和设备目录 |
| 内置活动解包 | `%LOCALAPPDATA%\ICeClass\ReadingAssets`，按构建分目录 |
| 待传记录、缓存规则与待核实原件 | `%LOCALAPPDATA%\ICeClass\ReadingData`，按平台和设备分目录 |
| 未完成的客户端更新 | EXE 同目录的 `.updates` |

不要将本机用户数据目录作为清理缓存的对象，也不要把一间教室的绑定文件复制到其他教室。更新程序保留班级绑定、玩法偏好和待补传记录。

2.3.0 启动后随机等待 2–15 分钟检查更新，之后空闲时每 30 分钟检查。早读期间跳过更新；下载途中打开早读会暂停，之后从保留的文件继续。服务器忽略续传请求时重新下载；完整性检查通过后才允许安装，失败继续使用原版。实际替换与启动失败的恢复机制沿用原实现。

学校规则和班级名单通过后台同步；四种玩法内容已随 EXE 固定，修改玩法需要发布新的客户端。2.3.0 推广时应先更新服务端，再安装客户端，不能只替换 EXE 后仍用 2.2.4 服务端。旧服务器缺少补传接口时，活动仍可打开，本机记录继续保留，需升级服务器后才可确认统计。

## 本地验收步骤

本机已准备独立目录 `dist/local-review-2.3.0`，双击“开始本地验收.bat”打开本地网页和 `ICeClass-2.3.0.exe`。网页地址为 `http://127.0.0.1:8838/`，演示管理员 `ICe / LocalDemo2026`；客户端预绑定“弱网验收班”。“模拟断网.bat”使这个本地测试服务拒绝连接，“恢复联网.bat”恢复，不改电脑 Wi-Fi。目录只用于本机验收，包含独立演示配置，不发给真实教室；详细操作见目录里的“先看使用说明.txt”。

1. 先在隔离本地验收服务绑定测试班级，确认一次统计规则；不要用尚未升级的正式平台验证补传。
2. 断开网络，从教室首页打开早读，依次触屏进入四种活动并允许麦克风；确认视频、动画、声音进度可用，页面显示离线和待传状态。
3. 退出活动、退出测试客户端并重新打开，确认班级、玩法偏好和待传记录保留。长按屏幕空白处两秒退出全屏，主页仍能使用最小化、最大化和关闭。
4. 恢复网络，等待后台补传，刷新管理员统计，确认日期、原班级、完成量正确，待传数量归零；重启或重复请求不增加成绩。
5. 验收后再安排服务端和白板更新。正式服务器发布、真实白板触屏/麦克风、真实校园弱网和正式自动安装整条链路不计作本轮已完成的验证。

# 班班角色动作 · 本地验收

2026-10-16，基于 2.3.0 本地待验收版。入口为 `http://127.0.0.1:8838/`，正式学校服务器尚未更新。

## 这轮实际改变

保留用户提供的小书灵和完整 MAS 徽章。原来的分层平移与表情图片切换，升级为一套基于原画的 Canvas 2D 关节与网格动画，不引入新的外部运行库。

| 部位或情境 | 当前行为 |
| --- | --- |
| 双眼 | 眼球在眼白内独立移动，眼睑连续闭合并遮住圆形眼球，接近闭眼时融合原画闭眼素材 |
| 手臂 | 通过肩、肘、腕保持两段长度，沿弧线抬向脸颊；关节旋转过渡保留原画厚度 |
| 身体与书签 | 身体小幅弯曲与呼吸，脚底保持稳定；书签以较慢弹簧跟随 |
| 打开与点击 | 打开时轻轻侧身招手；点击欢迎角色会歪头、眨眼或闭眼笑 |
| 输入与请求 | 输入时轻微低头；请求时先转眼，再侧身、抬手；慢网保留等待状态和停止入口 |
| 文字与完成 | 仅在真实文字分块到达时短暂回应嘴部，停止到字后归位；完成后手臂落下并轻轻回应 |
| 拖动 | 身体随方向和速度小幅倾斜，放手后渐渐归位；原聊天内容与请求状态保留 |

欢迎、等待、顶部头像和收起入口共用一个画布，只显示一个角色。绘制上限约 30 fps，小尺寸降低网格细分，画布分辨率最多 2 倍且宽不超过 640 像素。渲染不读取摄像头、麦克风或教室录音。

关闭动效或系统启用“减少动态效果”时，状态变化只更新静态表情。所有角色位置隐藏、页面不可见或退出后停止绘制；素材无法加载时保留原画，聊天功能继续使用。

## 验证与证据

运行 `node --test scripts/test-banban-rig.cjs scripts/test-banban-motion.cjs`，共 28 项通过。其中 12 项新测试涵盖关节长度、不可达目标、原画对位、肘部不塌陷、抬手与落手连续性、眼睑中间态、眼神领先头部、脚底稳定、静态模式、文字停止后的嘴部归位，以及不同帧率与延迟帧稳定性。

实际 Codex 内置浏览器复查真实 DeepSeek 回答和来源卡片、单角色/单画布、聊天窗与入口拖动、键盘触发点击回应、手动/系统减少动效、角色隐藏暂停、纹理失败回退和 390×600 窄屏。记录位于本地 `output/banban/rig-checks.json`；最终动画来自实际浏览器画面采样，位于 `rig-final-motion.gif`，没有用离线渲染冒充页面运行。

本轮没有修改服务端逻辑。上一轮完整服务端 75 项测试与流式问答验证记录见 [班班智能交互说明](班班智能交互说明.md)。学校白板真机触屏与低性能设备的流畅度仍需现场验收，本机浏览器结果不能代替真机结果。

## GitHub 参考与局限

通过 GitHub 插件读取了 [PixiJS RopeGeometry](https://github.com/pixijs/pixijs/blob/dev/src/scene/mesh-simple/RopeGeometry.ts) 和 [AIRI 的参数平滑过滤](https://github.com/moeru-ai/airi/blob/main/packages/model-driver-magic-live2d/src/filter.ts)，参考网格变形和连续参数过渡的组织方式。没有安装这些项目的完整框架，也没有复制角色素材。

当前是定制 2D 原画动画，不是 Live2D、3D 或面部追踪。手掌轮廓和可转动角度受现有原画限制，不能表现真实人物任意转身、手指动作或完整口型。它的目标是让同一个小书灵有连贯、克制、符合当前交互的反应；外观是否足够自然仍以用户本地验收为准。

# Windows 教师端

> 2026-10-31：当前开发与本地验收候选为 2.5.1，版本说明见 [2.5.1 发布记录](发布记录-2.5.1.md)。下文带日期的 2.3.0 发布、安装与验证记录保留为历史，不代表本次已更新学校平台。

## 2.5.1 创意计划

ICe 登录后可在左侧“创意计划”查看各班提交的文字、纸条照片和语音，筛选班级/状态、填写回复并保存评审；其他教师角色不开放统一创意箱。需要全校展示时，单独填写公开标题与摘要并确认，不公开学生姓名、原稿和附件。右侧状态和回复框等宽，保存评审位于底部右侧并为班班预留空间；重新编辑后显示未保存状态，不保留上一次的成功提示。评审未保存时切换页面会提醒并保留当前编辑，退出登录则明确确认放弃；两处同时修改会提示核对最新版本。每天 18:00 的摘要使用既有反馈邮箱，详情见 [创意计划](千人创意计划.md)。

## 2.5.1 教室来音提醒

登录后，教师端每 10 秒检查本人有权查看的教室来音，不依赖正在打开哪个页面或网页计时器。新留言在桌面右下角显示班级、时间和时长；收到提醒不会自动下载录音或播放声音。时间紧接“教室来音”，右上角关闭按钮只收起本轮提醒，留言仍可在工作台查看。同一登录会话中已提醒的留言不会随轮询反复弹出。多条来音在班级下方显示当前位置和“上一条 / 下一条”，首尾禁用相应按钮；已收听或转写的留言仍可在本轮弹窗内返回查看。

提醒和图标右键菜单共用原生浮层外壳：微透明灰白底、8 DIP 圆角、细边框和轻阴影；语音区域保留浅蓝强调，操作文字沿用共享 SemiBold。“收听”后显示播放进度，可停止、重听或查看下一条；关闭提醒或切换账号会停止当前播放。

“转文字”与“收听”并排，点击后在两个按钮下方展开结果，原位置的按钮可收起文字，不再显示单独的整行转写操作条。复用班班的 SenseVoiceSmall 本地识别实现，优先校验和共用已有模型；缺少时只显示下载入口，由用户选择“下载并转文字”后下载约 230 MB，之后可离线识别已加载的录音。下载有进度和取消入口，失败可重试；不强制下载、不新增外部转写服务，不自动播放录音。转写结果可选择复制，切换留言再返回时保留已识别文字，关闭弹窗后不保留。播放或转写期间暂不能切换留言，可先停止或取消。下载后的模型缓存保留供下次使用。

为保持现有服务接口，本轮转写读取录音会产生原来的已收听回执，即使没有播放原音；直接关闭提醒或切换未收听的下一条不会产生该回执。转写可能出现同音词错误，需以原音核对。本轮为 2.5.1 本地验收候选，源码随本次提交归档，学校平台尚未更新。

## 2.5.1 登录页

登录页采用连贯的浅蓝与白色版面，左侧将原有班级陪伴插画、标题和功能文字组成一组，右侧将班班与“欢迎回来”并排，再接用户名、密码与“进入工作台”。只保留一处品牌名称，沿用原字体。窄窗口使用单列表单，保留键盘焦点、输入标签与错误反馈；初始化长表单可滚动，键盘定位控件时保留上下留白。

2026-10-31 整体排版按 congee-imagegen 生成的整页视觉稿落实，实际页面继续使用原课堂插画和已有班班素材，不把设计稿作为整页背景。已检查桌面、短窗口、平板及 320/375 像素窄屏、密码切换、键盘操作、减少动态效果和错误提示布局；具体边界见 [完整验收报告](完整验收报告-2.5.1.md)。

班班平时睁眼，密码框获得焦点时抬手捂眼；切换“显示密码”后偷看，回到用户名后放下手。交互只观察焦点与密码框显示类型，不读取用户名或密码的内容。动作可在中途改变方向，遵循减少动态效果偏好，页面隐藏时停止播放。

## 2.5.1 使用反馈

教师端右上角新增“反馈”，保留“刷新页面、桌面设置、关于”。必须登录工作台才能打开反馈表单，发送时重新核对登录账号和页面凭证；账号变化时不会将原账号草稿直接发出。

点击后立即显示“正在打开…”，登录检查期间不会重复打开。诊断日志在首次预览或发送时后台整理，同一草稿复用；关闭窗口后不再弹出日志预览。

2026-11-01 本地复查：首次打开由约 373 毫秒降至约 269 毫秒，随后三次为 41–55 毫秒；该计时来自独立原生检查宿主，不能代表所有电脑。13 项打开流程、144 项桌面检查及 14 项模拟表单检查通过；新版候选已实际检查打开、Tab 焦点、日志预览、关闭和重开。模拟表单检查包含 450×480 窄窗口及发送失败保留草稿，本轮未发送真实反馈邮件。

填写问题描述、可选联系方式，点击“发送反馈”后通过学校服务器发到开发者邮箱。默认附教师电脑本机诊断，发送前可预览或取消。2026-11-01 扩充为最近 24 小时的操作时间线、页面加载与接口耗时、HTTP 状态、脚本错误类型及来源、教室来音收听与转写失败、版本、系统、WebView2、窗口缩放和当前连接状态；同时附近期 `desktop.log` 错误详情。活动记录保存在资料目录的 `desktop-activity.jsonl`，重启后继续保留，后台写入，不在打开反馈时集中读取。

活动文件最多 4 MB，超过时裁剪较早记录，诊断附件只读取最近 512 KB 活动及 256 KB 错误日志，并说明覆盖时间与裁剪限制。重复成功查询会合并；不读取输入值、请求或响应正文、教室电脑日志、账号设置文件、录音或整个用户目录。日志隐藏已识别的密码、密钥、令牌、Cookie 和用户目录，页面去掉查询参数和凭据。新版本开始记录，不能补回升级前的操作。附件包含本次问题描述、反馈人和环境，收到邮件后可直接转发整封邮件及附件继续排查。

反馈表单收紧为 600×520 DIP，保留滚动与固定底部操作；标题和账号并排，减少描述框高度和区块空白。原生输入框统一为白底、细蓝边与淡蓝外圈，保留原字体；内部文本仍在自己的滚动区域内裁剪。窄窗中键盘聚焦会将控件滚动到页脚上方。

截图由教师主动选择“截取页面”或“添加图片”，不自动上传。截取范围是当前工作台网页，支持预览和移除；最多 3 张，单张 2 MB、合计 3 MB。发送失败保留填写内容和附件，邮件服务确认接收后才显示成功。

邮件包含登录教师、账号角色、联系方式、问题描述、发生时间、版本、系统、缩放及当前页面。首版仅收集教师端本机日志，不强制下载语音模型，不新增第三方依赖。服务端发信配置见 [教师反馈邮件配置](教师反馈邮件配置.md)。本地候选已接入，正式平台尚未部署该接口。

2026-10-31 根据用户“几帧切换”的最新选择，使用 congee-imagegen 新绘制的六个姿态：睁眼、抬手、闭眼、捂眼、偷看和放手。离线对齐书身与脚的位置，整理为透明 WebP 图集；浏览器通过 Canvas 按明确的姿态顺序播放，从偷看离开时直接放手，不再绕回捂眼。随后逐帧发现，原先固定书顶的横向拼接在左侧书脊产生小台阶；现将连续的上部书脊延伸至手臂遮挡处，并保留原画手臂在前景，当前图集为 209,086 字节，缓存入口为 `login-motion.webp?v=7`。六帧顺序和动作时间保持原样，没有新增动画库或运行时生图请求，视觉感受仍需用户验收。最终素材来源见 `web_controller/assets/banban/login-SOURCE.txt`，离线整理入口为 `scripts/prepare-auth-keyposes.py`；`python scripts/test-auth-keyposes.py` 检查帧间书脊一致性、姿态差异和透明边距，`node scripts/test-auth-mascot.cjs` 检查交互。

## 2.3.0 历史发布记录

2026 年 10 月 18 日已正式发布。[下载 Windows 教师端](https://iceclass.icecreamchat.top/download/ICeClass-teacher.zip)，正式网页、桌面更新接口和教室端均已升级至 2.3.0。

ICeClass 班伴现在提供三个入口，使用同一学校服务器：

| 入口 | 供谁使用 | 如何进入 |
| --- | --- | --- |
| 网页端 | 教师、主任、校长与管理员 | 用浏览器打开学校网址并登录 |

## 本地打开与安装

- 体验当前本地数据：先运行 8838 本地验收服务，再双击项目根目录的 `start-desktop-preview.bat`。使用独立本机资料，不影响浏览器或教室端的登录。
- 安装文件：`dist/release/ICeClass-2.3.0-desktop-windows-x64.zip`。完整解压后双击“安装到本机.cmd”，无需管理员权限。安装器将程序复制到当前 Windows 用户的 `%LocalAppData%\Programs\ICeClassDesktop`，创建桌面与开始菜单图标。
- 便携使用：将解压的文件夹放到固定位置，双击 `ICeClass.Desktop.exe`。
- 安装版与便携版默认连接正式平台 `https://iceclass.icecreamchat.top/`。本地验收入口明确连接 8838，与正式数据分开。
- 系统要求：Windows 10/11 x64。内置 .NET 运行环境，另需 WebView2 Evergreen Runtime；缺少时显示 Microsoft 官方获取入口。

关闭窗口默认收起到系统托盘。点击桌面“ICeClass 班伴 教师端”图标、托盘图标或托盘菜单“打开 ICeClass 班伴 · 教师端”可恢复已有窗口，不会多开。选择托盘菜单“退出 ICeClass 班伴 · 教师端”才结束程序。“桌面设置”也可改为关闭即退出。标准标题栏保留最小化、最大化和关闭按钮。

## 功能与设置

晨读统计、XLSX 导出、通知、教室来音、管理页面和班班直接使用现有工作台。网页内容随服务器更新，账号授权仍由服务器核实。

顶部“桌面设置”只配置学校平台网址和关闭方式。班班的服务地址、API Key 与模型 ID 继续在班班“连接设置”中管理；两种地址有不同用途。

2026-10-31：精简教师端顶部重复品牌，保留 Windows 标题栏的小图标和网页侧栏品牌区。原生工具栏左侧显示连接状态，右侧“刷新页面、桌面设置、关于”继续常驻，沿用原有字体、按钮尺寸和操作行为。

本轮已完成 Release 单文件构建并替换本地 8870 验收候选，保留原有登录资料和设置。实际 Windows 常规窗口已检查三个按钮的显示、设置与关于页打开、刷新确认提示和设置取消；最窄窗口的缩放检查未完成。本轮只修改教师端原生工具栏与本文档，未更新网页、提交源码或部署学校平台。

网页登录资料与桌面登录资料独立。桌面资料按学校平台的域名与端口隔离，切换平台不会把旧平台 Cookie 带给新平台。桌面端不自动保存密码到浏览器密码管理器。

下载文件会询问保存位置，不会自动执行。学校同源的新窗口在客户端中打开，外部网页经用户点击后交给默认浏览器。晨读预览的网页全屏会同时隐藏原生标题栏与工具栏，Esc 可恢复窗口。

工作台需要联网查询、发送、播放云端来音和分析。弱网会显示等待、失败与重试提示，不会清除登录资料；此工作台不提供离线发送或离线 AI。教室端的离线早读与统计补传属于另一客户端。

## 更新与卸载

托盘菜单或“关于 → 检查桌面更新”可检查学校服务器发布的桌面新版本。更新前询问确认，请先保存未提交内容。下载支持续传并核验文件，替换后重启；新程序启动失败会尝试恢复旧版。本机登录资料、学校平台地址和关闭偏好保留。

这不是静默自动升级。网页功能更新不要求更换桌面程序；桌面程序新增原生功能时才发布新的 EXE。

服务器包的 `desktop_release/` 包含桌面 EXE 和对应 `manifest.json`。桌面更新接口为 `GET /api/desktop/update?currentVersion=2.3.0`，下载接口为 `GET /api/desktop/update/download`；与需验证设备绑定的教室端更新分开。服务器未配置发布信息时返回无可用更新。

可从 Windows“已安装的应用”卸载，卸载保留本机登录资料。需要退出学校账号时，请先点击工作台右上角“退出”。完整许可与第三方说明已内嵌，在“关于”中查看。

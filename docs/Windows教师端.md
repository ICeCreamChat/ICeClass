# Windows 教师端（2.3.0）

2026 年 10 月 18 日已正式发布。[下载 Windows 教师端](https://iceclass.icecreamchat.top/download/ICeClass-teacher.zip)，正式网页、桌面更新接口和教室端均已升级至 2.3.0。

ICeClass 班伴现在提供三个入口，使用同一学校服务器：

| 入口 | 供谁使用 | 如何进入 |
| --- | --- | --- |
| 网页端 | 教师、主任、校长与管理员 | 用浏览器打开学校网址并登录 |
| Windows 教师端 | 在个人电脑上工作的教师与管理员 | 安装后从桌面或开始菜单打开并登录 |
| 教室端 | 教室一体机与白板 | 用绑定码选择教室，接收通知和运行早读 |

Windows 教师端使用网页原有账号与权限，不需要教室绑定码，不会把教师电脑注册成教室设备。教师只看到获授权的班级，其他角色也沿用服务器的原授权。

## 本地打开与安装

- 体验当前本地数据：先运行 8838 本地验收服务，再双击项目根目录的 `start-desktop-preview.bat`。使用独立本机资料，不影响浏览器或教室端的登录。
- 安装文件：`dist/release/ICeClass-2.3.0-desktop-windows-x64.zip`。完整解压后双击“安装到本机.cmd”，无需管理员权限。安装器将程序复制到当前 Windows 用户的 `%LocalAppData%\Programs\ICeClassDesktop`，创建桌面与开始菜单图标。
- 便携使用：将解压的文件夹放到固定位置，双击 `ICeClass.Desktop.exe`。
- 安装版与便携版默认连接正式平台 `https://iceclass.icecreamchat.top/`。本地验收入口明确连接 8838，与正式数据分开。
- 系统要求：Windows 10/11 x64。内置 .NET 运行环境，另需 WebView2 Evergreen Runtime；缺少时显示 Microsoft 官方获取入口。

关闭窗口默认收起到系统托盘。点击桌面“ICeClass 班伴 教师端”图标、托盘图标或托盘菜单“打开 ICeClass 班伴 · 教师端”可恢复已有窗口，不会多开。选择托盘菜单“退出 ICeClass 班伴 · 教师端”才结束程序。“桌面设置”也可改为关闭即退出。标准标题栏保留最小化、最大化和关闭按钮。

## 功能与设置

晨读统计、XLSX 导出、通知、教室来音、管理页面和班班直接使用现有工作台。网页内容随服务器更新，账号授权仍由服务器核实。

顶部“桌面设置”只配置学校平台网址和关闭方式。班班的服务地址、API Key 与模型 ID 继续在班班“连接设置”中管理；两种地址有不同用途。

网页登录资料与桌面登录资料独立。桌面资料按学校平台的域名与端口隔离，切换平台不会把旧平台 Cookie 带给新平台。桌面端不自动保存密码到浏览器密码管理器。

下载文件会询问保存位置，不会自动执行。学校同源的新窗口在客户端中打开，外部网页经用户点击后交给默认浏览器。晨读预览的网页全屏会同时隐藏原生标题栏与工具栏，Esc 可恢复窗口。

工作台需要联网查询、发送、播放云端来音和分析。弱网会显示等待、失败与重试提示，不会清除登录资料；此工作台不提供离线发送或离线 AI。教室端的离线早读与统计补传属于另一客户端。

## 更新与卸载

托盘菜单或“关于 → 检查桌面更新”可检查学校服务器发布的桌面新版本。更新前询问确认，请先保存未提交内容。下载支持续传并核验文件，替换后重启；新程序启动失败会尝试恢复旧版。本机登录资料、学校平台地址和关闭偏好保留。

这不是静默自动升级。网页功能更新不要求更换桌面程序；桌面程序新增原生功能时才发布新的 EXE。

服务器包的 `desktop_release/` 包含桌面 EXE 和对应 `manifest.json`。桌面更新接口为 `GET /api/desktop/update?currentVersion=2.3.0`，下载接口为 `GET /api/desktop/update/download`；与需验证设备绑定的教室端更新分开。服务器未配置发布信息时返回无可用更新。

可从 Windows“已安装的应用”卸载，卸载保留本机登录资料。需要退出学校账号时，请先点击工作台右上角“退出”。完整许可与第三方说明已内嵌，在“关于”中查看。

# 班伴 2.3.0

发布日期：2026 年 10 月 18 日。正式平台：https://iceclass.icecreamchat.top/ 。

## 使用入口

- 网页端：打开正式平台，使用原来的学校账号与密码。
- [Windows 教师端](https://iceclass.icecreamchat.top/download/ICeClass-teacher.zip)：完整解压，双击“安装到本机.cmd”，从桌面图标登录。也可直接运行解压后的 `ICeClass.Desktop.exe`。
- [教室端](https://iceclass.icecreamchat.top/download/ICeClass-classroom.zip)：完整解压到固定目录，运行 `ICeClass.exe`，选择并绑定本教室。已有设备在托盘或教室设置里点击“检查更新”，保留本机资料。
- GitHub 提供教室端、教师端、完整 Windows 交付包、服务器包与 SHA-256 校验清单。

## 更新内容

- 四种早读活动与视频随教室端内置，可离线运行；统计保存在本机，联网后补传。更新下载支持续传，活动进行时暂停客户端升级。
- 新增 Windows 教师端，与网页端共用学校账号、数据和权限，提供托盘、桌面入口与独立更新。教师端、网页侧栏、登录页及浏览器图标统一使用新的教师图标。
- 统一教室端、教师端的控件高度、表单对齐、卡片间距与按钮样式，压缩设置、关于页及早读顶栏中过多的竖向留白。
- 活动名称统一为“兔拔萝卜”“诗词镌刻”“粒子浮雕”“火箭升空”。
- 工作台提供 XLSX 导出、班级排行和日历，以及班班悬浮助手。AI 连接使用用户自行配置的服务。
- 应用改用“非商业学习参考许可”；第三方组件继续适用各自许可。许可与第三方说明可在应用关于页查看。

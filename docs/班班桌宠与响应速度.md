# 班班桌宠与响应速度

2026-10-28 本地验收候选。班班以原生透明小书灵贴在屏幕左右边缘，待机窗口为 64×80 DIP，角色约 52×62 DIP。上课时自动隐藏，语音收听不受影响，喊“你好班班”仍可出来办事。复用原来的语音、教师登录和电脑操作服务，以及原来的角色图层，未增加模型、浏览器实例或运行时依赖。

## 使用

| 操作 | 结果 |
| --- | --- |
| 说“你好班班” | 小书灵从边缘跳出，随后可连续安排任务；上课时同样可唤醒 |
| 单击小书灵 | 开始语音对话；尚未登录时打开原登录窗口 |
| 双击小书灵或右键“打开对话” | 查看完整对话、历史和操作卡片 |
| 拖动小书灵 | 松手后贴到最近的左右工作区边缘，不触发说话 |
| 聚焦后按方向键 | 上下调整高度，Shift + 上下键移动一个屏幕像素，左右切换停靠边，Home 复位 |
| 右键“停止操作” | 停止播报并取消当前任务；已完成的动作不回滚 |
| 右键“暂停语音” | 关闭收听和播报，再次启用时复用原有设置 |
| 右键“隐藏班班” | 收起角色，语音保持现有状态；从托盘“显示班班桌宠”恢复 |

待机时只留下小角色，不常驻状态标签或气泡。唤醒后展开，角色下面显示当前状态，识别到的话和正在播放的回答以短气泡显示，完整文字保存在原对话中。等待继续说话超过 12 秒后收回；处理、播报和等待确认时保持展开。拖动或打开菜单期间不会突然收回。锁屏和休眠时暂停语音并隐藏角色，恢复后仍重新检查登录状态。

课中隐藏直接沿用教室浮岛已同步的课表、单双周和临时调课，以课程开始时刻为包含边界、结束时刻为不包含边界。下课恢复贴边。没有可用课表时不猜测上课时间，正常贴边待机。手动“隐藏班班”仍优先，需从托盘主动恢复。

唤醒动作目标时长约 720 毫秒，使用原画图层完成边缘进入、轻微上跳、落地和挥手，弹簧会继续平滑收尾。动画与语音、任务执行同时进行，不增加动作等待；遵守系统减少动态效果的设置。

位置和显示偏好保存在本机用户目录的 `ICeClass/Receiver/banban-pet.json`。恢复时按当前显示器工作区和缩放比例限制位置，支持负坐标屏幕。隐藏、暂停及系统减少动态效果时停止动画计时器。角色外的透明区域可操作背后的应用。

## 响应速度

完整且目标唯一的单步短命令，如打开应用、最大化窗口、切换窗口、关闭窗口和放映翻页，在读取本轮真实窗口后直接进入原操作流程。歧义、条件、否定、多步任务及文稿内容编写仍交给模型。所有动作继续核查权限、绑定、输入、过期状态和实际结果，不根据预测中的半句话提前执行。

复杂电脑任务在首次模型请求前读取本机窗口，动作回执可提供本轮最新窗口，减少重复查看和模型往返。服务端复用 HTTP 连接，设备回执直接唤醒等待；本机窗口枚举在一次观察内复用进程身份。文字和演示文稿只复用经过应用路径验证的活动接口；外部 Office 兼容接口不能冒充被选择的应用。

语音终稿收尾使用一秒尾静音，并保留解码上下文。这个时间仍算在真实口述后的等待中。网络模型、冷启动、应用界面和复杂任务仍有各自的耗时，不能保证任意话语结束后立即完成。

本机热启动实测，输入来自已识别文字，未采集麦克风录音：

| 场景 | 开始实际动作 | 核验完成 |

| 最大化验收窗口，连续三轮独立会话 | 0.239 / 0.251 / 0.417 秒 | 0.345 / 0.358 / 0.524 秒 |
| 新建 Word 文稿并写入验收正文，复用已打开的 WPS | 1.490 秒 | 8.497 秒 |

简单命令三轮均无模型调用。文稿通过两次模型调用和真实 Windows 操作完成，正文读回正确，窗口最大化，未保存。早先冷启动最大化曾耗时 2.985 秒；微软 Word 的首次自动化启动曾超时，没有将该次失败当作成功结果，也没有重放那次被取消的请求。明确指定 Microsoft 时仍受本机 Office 安装和首次启动状态影响。

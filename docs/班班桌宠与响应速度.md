# 班班桌宠与响应速度

2026-10-30 本地验收候选。班班以原生透明小书灵贴在屏幕左右边缘，待机以斜身探头的姿态出现，透明窗口为 100×174 DIP，原画统一按 116×130 DIP 绘制，较上一版 150×168 DIP 再缩小约 23%，待机和唤醒使用同一尺寸；书身一部分藏在真正的屏幕边缘之外。上课时自动隐藏，语音收听不受影响，喊“你好班班”仍可出来办事。复用原来的语音、教师登录和电脑操作服务，以及原来的角色图层，未增加模型、浏览器实例或运行时依赖。

## 使用

| 操作 | 结果 |
| --- | --- |
| 说“你好班班” | 小书灵从边缘跳出，随后可连续安排任务；上课时同样可唤醒 |
| 首页“呼叫班班”或单击小书灵 | 召出班班并立即收听，不播报问候；首次连接显示准备状态并在关联完成后收听，连接失败时提供重新连接入口 |
| 双击小书灵或右键“打开对话” | 查看完整对话、历史和操作卡片 |
| 拖动小书灵 | 松手后贴到最近的左右工作区边缘，不触发说话 |
| 聚焦后按方向键 | 上下调整高度，Shift + 上下键移动一个屏幕像素，左右切换停靠边，Home 复位 |
| 右键“停止操作” | 停止播报并取消当前任务；已完成的动作不回滚 |
| 右键“暂停语音” | 关闭收听和播报，再次启用时复用原有设置 |
| 右键“隐藏班班” | 收起角色，语音保持现有状态；从托盘“显示班班桌宠”恢复 |

待机时只留下探头的角色，不常驻状态标签或气泡。启用语音后，首次约 6 秒出现小动作，后续每次动作结束再间隔约 8–14 秒；轮换向内探头、眨眼、挥手、摇摆、点头、托腮、侧耳、伸展、向外张望和打盹，打盹接着自然睡醒。动作结束后恢复睁眼静止，停止逐帧计时器。鼠标移到静止的贴边角色上时，会向桌面探头。唤醒后以相同的原画尺寸平滑转正并跳出，角色下面显示当前状态，识别到的话和正在播放的回答以短气泡显示，完整文字保存在原对话中。等待继续说话超过 12 秒后收回；处理、播报和等待确认时保持展开。拖动或打开菜单期间不会突然收回。锁屏和休眠时暂停语音并隐藏角色，恢复后仍重新检查班级与班主任关联。

课中隐藏直接沿用教室浮岛已同步的课表、单双周和临时调课，以课程开始时刻为包含边界、结束时刻为不包含边界。下课恢复贴边。没有可用课表时不猜测上课时间，正常贴边待机。手动“隐藏班班”仍优先，需从托盘主动恢复。

唤醒动作目标时长约 720 毫秒，使用原画图层完成边缘进入、轻微上跳、落地和挥手，弹簧会继续平滑收尾。动画与语音、任务执行同时进行，不增加动作等待；遵守系统减少动态效果的设置。

位置和显示偏好保存在本机用户目录的 `ICeClass/Receiver/banban-pet.json`。恢复时按当前显示器工作区和缩放比例限制位置，支持负坐标屏幕。隐藏、暂停及系统减少动态效果时停止动画计时器和待机动作安排。透明画布为旋转后的完整轮廓留出空间，按钮不再裁去伸出的书角和手；角色区域外的透明空间可操作背后的应用。

## 响应速度

完整且目标唯一的单步短命令，如打开应用、最大化窗口、切换窗口、关闭窗口和放映翻页，在读取本轮真实窗口后直接进入原操作流程。歧义、条件、否定、多步任务及文稿内容编写仍交给模型。所有动作继续核查权限、绑定、输入、过期状态和实际结果，不根据预测中的半句话提前执行。

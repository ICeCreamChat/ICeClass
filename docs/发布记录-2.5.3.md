# 2.5.3 班班对话隔离与课堂使用修复

2026-11-02 发布。包含教室端、Windows 教师端、网页和服务端，继续提供完整离线安装包及两端增量更新源。

## 教室端与教师端的班班

- 教室端继续关联本班班主任，复用对应的班班服务配置；教室端对话与教师私人对话分别保存。
- 学生不能读取、继续或删除教师端的私人对话，也不能访问其中的操作卡。各班对话、当前会话及取消回答的状态分别隔离。
- 保留既有聊天记录。旧记录继续留在教师端，不因教室端首次打开或切换会话而清空。
- 未配置班主任、连接失败或浏览器初始化失败时，显示明确提示和重试入口，避免只出现空白窗口。
- 教师端业务接口通过真实路由声明接入班班，沿用教师权限、内容校验、确认和版本检查。新增功能可通过相同声明纳入；设备协议、本人输入等受限功能仍有明确边界。

## 浮岛与早读

- 超级管理员和校长可批量设置全校、年级或所选班级的浮岛开关、作息、提醒与外观。先预览目标和变化，再统一应用；课表、值班安排及其他班级内容保留，版本冲突需重新预览。
- 按已选择的作息时段执行上课隐藏、下课恢复，即使当天尚未填写课程也能生效。保留旧配置的实际课程隐藏语义及临时停课规则。
- 早读资源准备移出界面线程，减少首次打开时磁盘处理造成的界面等待；实际教室设备的启动速度仍需现场检查。
- 包含值班安排在周课表中的显示、独立轮换周次及已保存安排的编辑修复。

## 从旧版更新

现有 2.5.2 的教室端和教师端可通过原有更新入口升级，不需要卸载或重新绑定。未变化的离线语音资源继续复用，变化文件按更新计划下载；有适用的更小差分时使用差分。后台下载遵循课间空闲规则，完成后在下次真正启动时安装，也保留主动“立即更新”。关闭到托盘不等于退出重启。

首次安装仍使用完整包。2.5.0 及更早的教室端受旧版更新大小上限影响，应退出托盘旧程序后运行完整包中的“安装或升级.cmd”，完成一次过渡升级。安装与更新说明见[客户端更新说明](客户端更新说明.md)。

## 验证范围

发布检查覆盖服务端权限和历史迁移、批量设置与冲突处理、网页交互、原生浮岛时段、语音错误提示、更新协议和安装包完整性。正式服务器部署与 GitHub 发布分别核对来源、文件校验值和实际响应。

学校电脑的动画、远场麦克风、摄像头及第三方软件交互仍需现场确认；本次不将本机动画测试或模拟设备结果表述为实际教室验收通过。服务器发布也不会替代各教室客户端完成安装。

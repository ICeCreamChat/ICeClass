# ICeClass 班伴 2.4.0

日期：2026-10-22。本版包含教室岛完整功能及本地试用包。源码提交和版本标签不等同于线上部署；本次没有更新正式服务器、正式下载或自动更新源。

## 教室岛

- 顶部细条展示日期、当前课程、下节课和倒计时；可展开今日完整课表及操作。
- 教师端维护作息、课程、单双周、临时调课，支持 Excel 导入预览和导出、跨班复制与设备同步状态。
- 课前、上课、下课提醒，文字与日期组件，课程或定时自动化；本机应用需先在教室端允许。
- 配置按服务、设备、班级隔离缓存，断网继续展示已保存的课表；联网后自动同步和回执。
- 普通、重要、紧急通知统一在岛内展示，班班分别提示。紧急通知可打断较低优先级通知，结束后恢复队列；不重复播放被打断的语音。
- 点击“已知晓”记录人工知晓时间；Esc 仅收起。教师端区分已展示与已知晓。
- 托盘和设置提供完整课表演示、三种喊话预览；预览不发往真实班级。

## 清晰度与设置

保留 Microsoft YaHei UI / Microsoft YaHei / Segoe UI，沿用已确认的加粗字重，增大岛条和展开区域字号。展开、鼠标移入和键盘操作时恢复完整不透明度。

教室岛设置与现有教室设置使用同一套浅灰背景、白色分组卡片、字段和固定保存栏；窄窗口转为单列。保留班班与用户提供的握持大喇叭素材。

## 打包

教室端、Windows 教师端与 npm 项目版本统一为 2.4.0。服务端包改为收集完整的生产 Python 模块，修复教室岛与权限模块漏装；更新脚本验证所需模块与岛条资源。

`scripts/verify-release.py` 会解压服务端包，在隔离进程中启动真实服务、初始化临时数据库并检查教室岛路由，同时验证各分发包及更新清单的版本、大小和 SHA256。

## 验收与使用

完整验证和复现命令见 [2.4.0 本地验收](本地验收-2.4.0.md)。功能说明见 [教室岛课表与自动化](教室岛课表与自动化.md)。

本地包位于 `dist/release/`，包含教室端、Windows 教师端、完整 Windows 包和服务端包。教室电脑试用前使用与服务端相配套的版本；教室岛课表和自动化需要本版 Python 服务端，旧 Cloudflare 后端不提供对应接口。

首次绑定使用管理员提供的有效绑定码。更新 EXE 保留原绑定与设置；试用包不携带任何教室绑定、账号会话或本机配置。

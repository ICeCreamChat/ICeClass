# 2.5.2 两端增量更新与完整离线交付

2026-11-02 发布。包含教室端、Windows 教师端、网页和服务端，继续使用 .NET 8 / Avalonia 与 WebView2。

## 更新方式

- 教室端和教师端按文件校验并复用本机内容；有适用且更小的 Windows MSDelta 补丁时下载差分，否则只下载变化的文件。弱网中断支持续传。
- 后台下载安排在课间空闲时。上课、早读、录音、创意窗口和班班对话期间暂停；教师端主窗口使用中也延后下载。无法确认课时则暂缓自动下载。
- 下载完成继续使用当前版本，下次真正启动安装。关闭到托盘不会安装；保留“立即更新”，供老师保存内容后主动重启。
- 替换前重新核验文件，安装失败或启动未确认时恢复原程序。保留账号资料、班级绑定、课表与本机设置。
- 2.5.1 及以前需先升级一次，后续才支持新的增量协议。2.5.0 及更早教室端有 250 MiB 旧更新上限，须先下载完整教室端包，退出托盘旧程序后运行“安装或升级.cmd”。

## 完整离线包

教室端完整包包含早读内容和全部随附语音资源，可下载一次后通过 U 盘复制到各班电脑。每台新电脑分别绑定所属班级，不分发任何已有绑定或账号配置。Windows 教师端提供单独安装包；四个 ZIP、Ubuntu 更新脚本和 SHA256 校验文件随发布提供。

精简核心仅供程序更新使用，必须配套 `VoiceResources`，不能代替完整离线安装包单独分发。第一份新协议发布计划没有前版新协议目录，差分列表为空；后续发布提供上一版目录后，才会生成适用补丁。未变化的资源仍可直接复用。

完整离线包不代表所有业务离线运行：首次绑定、学校数据同步、通知、创意提交及需要服务端处理的对话仍需联网；Windows 10/11 x64 需具备 WebView2 Evergreen Runtime。

## 语音与既有功能

- 保持唤醒与识别模型预热，释放已经完成或取消的音频引用，合并重复等待中的维护工作。没有用延迟加载模型换取待机内存，也不承诺整机内存降幅。
- 包含 2.5.1 的创意计划独立小窗、手写原稿、语音转文字、拍摄裁剪、两步提交、本班进度、待评审删除及教师评审。
- 包含登录后教师反馈与最近 24 小时诊断记录、教室来音提醒、五类教师身份和兼任班级权限、午间静校与值班课表联动、全校浮岛默认隐藏规则及相关界面调整。
- 服务端发布包保留全部现有 SQL 迁移文件，避免交付包遗漏历史结构。
- 新装 Ubuntu 时完整安装运行模块、迁移、两端更新计划和文件资源；发版检查加入实际安装复制和 Windows 更新回退验证。

## 验证与范围

本地两端发布构建、更新校验与实际 Windows 安装/回退、语音资源复用、服务端测试和解压包启动已验证。真实迁移检查复用约 414 MiB 语音资源，模型下载请求为 0。详细命令、检查数量与限制见[本地验收记录](本地验收-2.5.2.md)。

真实教室的远场麦克风、多人声音、摄像头纸张清晰度和第三方软件操作仍需现场试用。服务器发布不会代替各教室电脑的首次安装或旧版过渡升级。

GitHub 发版与学校服务器升级分别核验；实际运行版本以服务器接口和客户端“关于”显示为准。安装和更新步骤见[客户端更新说明](客户端更新说明.md)。

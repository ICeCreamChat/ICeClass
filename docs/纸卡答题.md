# 创意工坊：纸卡答题

纸卡答题支持学生举纸卡、教师用教室摄像头或手机收答。可配合现有 PPT、课本和口头提问，也可课前在教师工作台录入图文题、组题单并发布到班级。支持 2-4 个选项的单选、多选和判断题，不需要学生手机。

## 准备纸卡

教师登录工作台，在“纸卡答题 - 班级纸卡”选择班级。名单管理员可以分配缺失卡号、换号或留空解绑，再为学生批量生成账号；其他有本班权限的教师可以查看卡号。含密码的发卡和补印由有名单管理权限的老师操作。修改后先保存，再在教室端联网刷新名单。

纸卡沿用作业登记中的稳定学生编号。班级卡号固定对应学生；历史课堂保存当时的名单和映射，换号不改变历史归属。首版 `ice-v1` 使用 1-157 号，每班最多 157 名学生；名单缺卡号、重号或超出容量时不能开始课堂。

打印使用 A4、100% 实际大小，关闭“适合纸张”等缩放和浏览器页眉页脚。可保存为 PDF，每名学生一页；黑白识别图案约 144 mm，四边保留方向字母和白色间距。每张纸卡显示班级、编号（学生账号）、卡号、密码和使用说明，不显示姓名，名单中的真实姓名仍保留。使用 ICeClass 生成的新卡，不保证兼容现成 Plickers 卡。单选用 A / B / C / D 的字母朝上表示对应答案；判断题 A 为正确、B 为错误；多选逐项使用 A 表示选、B 表示不选。保持卡面平整，手指避开图案。理论卡号容量不代表相机同屏识别容量，正式发卡前须做本文末尾的现场验收。

## 学生账号与补印

班主任在纸卡答题的学生账号管理中核对入学年份、首次班级编码和已保存的卡号，批量生成账号及每人独立的六位数字密码。编号如 `2610903`，表示 2026 年入学、首次高一（9）班、3 号卡；登录时连续输入，不加空格。卡号 1-9 补足两位，100-157 保留三位。

账号生成只补充缺失项，重复生成不重置已有密码。生成和重置的密码仅在本次结果中提供，请及时下载发放表或打印；关闭页面后无法查询已保存的密码。老师代为补印需明确执行重置，新的密码印在卡上，旧密码及旧学生登录会话立即失效。打开打印预览本身不会重置密码。

学生在 ICeClass 登录页选择“学生”，输入编号和纸卡上的六位密码，进入“我的课堂”。原有的 `/student` 链接在未登录时也会打开同一登录页，并选中“学生”。学生可修改为新的六位数字密码；改密后重新登录。自行补印须再次输入当前密码，核对后生成本人纸卡。

升班、转班或换卡不改账号编号。有原班和目标班管理权限的老师可将原账号关联到目标名单，历史课堂身份继续保留；原班停用也可由有权限的管理者办理关联。不能按同名、同卡号或不同班级相同的名单编号自动合并学生。旧卡号分给新同学时不会继承原学生账号或成绩，遇到账号编号冲突须核对后调整，系统不覆盖旧记录。

仍有关联学生账号的班级不能直接删除，可先转班或停用。学生全部转出后，如明确确认删除原班，原班课堂和关联记录会随班级删除，已转出的账号、密码及其他班级的记录保留；需要保留原班历史时应使用停用。

## 配合课件上课

在 Windows 教室端“创意工坊 - 纸卡答题”打开控制窗，选择学科和“配合课件临时出题”。点击开始收答后开启本机相机；结束本轮后查看匿名选项分布，设置标准答案、题干或知识点。设置答案不会自动揭晓。

在“题目与答案”选择单选、判断或多选；题库发布的题目沿用已保存题型。多选的标准答案可勾选一项或多项，全部取消表示暂不设置，按选择集合完全一致判对，不计算部分分。

多选使用同一张原纸卡逐项收答。例如题目有 A-D 四项，先收 A 项：学生 A 朝上表示选 A，B 朝上表示不选 A。点击“收下一项”切换至 B，再到 C、D；系统自动合成 AC 等最终答案。当前项下拉框可回到某项改答，其他项保留。换项会停止相机并更新采集代次，学生调整卡面后须主动点击“开启相机”；白板换项后，配对手机获知新状态也会停止采集。上一项迟到请求不会进入新项。

多选同时显示当前项已收和整题完成人数，每个有效项均已确认才算整题完成。只扫过部分项显示“未完成”；一项都没扫到显示“未答”。明确对所有项回答“不选”属于有效空选择，区别于未答。结束本轮可保留未完成记录；未完成不算错误，也不进入已答正确率和最终选项分布。

长按原来的桌面班班约 0.6 秒，或聚焦班班后按 F4，展开直径 320 DIP 的课堂圆环；右键“课堂功能”和纸卡工作台中的“班班控制窗”也可打开。圆心沿用同一个动态班班，不创建另一只桌宠。指向或键盘聚焦的扇区稍微放大；方向键选择可用功能，Enter 或空格执行，Esc 或单击圆心收起并恢复原大小。原来的单击说话、双击对话和拖动贴边保持可用。

未开课时八个课堂功能暂不可用；下方“开始课堂”打开原工作台，核对学科与出题方式后手动开课，再返回原班班圆环。收答、相机和下一题操作后收起圆环，课堂记录与相机仍由同一工作台处理；配合 PPT 时可让课件覆盖工作台，最小化或关闭工作台仍会按原规则暂停收答。手机配对、题目答案、缺席免答、作答分布和结束课堂回到工作台处理，结束课堂仍需确认。多选时下方显示当前项和本项人数，可直接“收下一项”，换项后仍须重新开启相机。

当前轮次未结束时不能换题或切换采集来源；暂停仍属于未结束轮次。缺席或免答在当前轮次中按卡号标记，不修改考勤。封存后不能改免答或补写迟到作答。

同题重新收答会保留新旧轮次；默认结果取最近一次已封存的正式轮次。若已经通过 PPT 或口头讲解答案，先标记“已在课件讲解”；在 ICeClass 揭晓后也会自动标记。此后的重答属于练习，不替代正式结果。

手机采集时，在轮次之间点击“使用手机”，扫码或输入配对码。手机须通过 HTTPS 访问学校服务，使用有本班权限的真实教师账号登录。领取配对码后在白板确认切换，再在手机开启相机。手机和白板只需都能连接学校服务，可使用不同网络。每次只有一个采集来源；更换手机或换回本机须先结束当前轮次。

手机可以控制开始、结束、添加临时题、标记已讲解，以及在轮次之间单独修改本场题干、标准答案或标签。设置题目信息不会修改教师私有题库。题单翻题和结束课堂由白板操作。

手机的临时题同样可选三种题型；多选收答时可选择当前项或“收下一项”，相机只接受 A 选、B 不选。轮次之间设置多选标准答案使用复选框，未确认保存或版本冲突会保留已输入内容，核对后用“清空重填”重新绑定最新版本。

## 课前录题

在教师工作台“我的题库”创建私有图文题。题干最多 20000 字，选项各最多 2000 字，标签最多 50 个、每个最多 80 字。图片支持 PNG、JPEG、WebP，单图最多 2 MiB，实际文件内容须与格式相符。答案和知识点都可暂缺。

课堂单次修改的题干、选项、知识点及必要字段合计最多 64 KiB（按 JSON 的 UTF-8 字节计）。各字段都未超字数时，合计仍可能超限；此时保存前会明确拒绝，请缩短内容或用题目配图。

在“题单发布”选择本人题目、调整顺序并发布到授权班级。教室端联网选择题单并缓存图片后可离线授课；单题单图片缓存最多 32 MiB，超出时请拆分。修改源题不会改写已经发布或开始的课堂；需要重新发布。撤回影响未来使用，已经开始的本机课堂保留原快照。

关联题库的课堂快照固定题型和选项，课堂中仍可修订题干、答案和知识点。需要更改题型或选项时，请添加临时题或修改题库后重新发布。临时题在有作答前可改题型和选项数量；有作答后固定题型和数量，选项文字仍可修订。多选题开始过收答后即固定题型和数量；已有轮次的单选或判断也不能改为多选，需要添加临时题，避免改变历史轮次结构。

本班教师可把已发布题或课堂题另存为自己的私有题目，再独立编辑。版本冲突会保留草稿，重新载入前应先核对修改。

## 保存、断线与恢复

白板是本课堂的确认端。答案和控制命令先保存到本机，再显示已收；学校服务收到手机请求仅表示待确认。原始确认事件和请求回执保留在本机，后台独立补传，关闭答题窗口后仍可同步。

本机已有完整缓存时可离线扫描，保留原名单和题单。手机模式需要联网：断线、页面切到后台或授权失效会停止相机，不自动重放未确认的候选。恢复后核对白板人数和原请求状态，再主动开启相机；状态未确认时不会显示保存成功。

异常退出后重新打开，未结束轮次先暂停并更换采集代次，核对题目后恢复。旧轮次、旧来源和旧代次的候选不得进入新轮次。保存失败或回执不明时会停止采集，要求重新打开核对盘上记录。

结束课堂会封存当前轮次并同步。同步失败保留本机记录；遇到身份、内容或版本冲突会标记待核对，修复原因后使用重试入口。不要删除待同步或待核对记录。

## 教师报告

教室控制窗和配对手机只显示匿名班级状态，不展示姓名、逐人选项或个人排名。真实登录且有本班权限的教师可在工作台查看逐题、逐轮和个人结果，结束并完整同步后可补录题干、改答案或标签、关联本人题库版本、以本人身份认领课堂，并导出 CSV。

默认每题取本课堂最新已封存的正式轮次，不逐人向旧轮次补答案；完整轮次历史和练习仍保留。应答人数 N 排除免答，已答人数 R 排除免答且多选必须全部有效项均已确认，正确人数 C 仅来自有标准答案的正式作答：参与率为 R/N，已答正确率为 C/R。未完成、未答、免答、未判定、错误和练习分别展示，不能把未完成或未答直接当作错误。无分母时不显示零正确率。

多选的选项分布只统计完整作答，选择 AC 的学生同时计入 A、C，各选项人数之和可能超过整题完成人数。个人明细及 CSV 区分完整组合、全不选、各项部分作答和未答；课后更正标准答案重新计算结果，保留原选择。

练习轮的免答保留在该轮明细和导出中，默认正式统计不累计为免答。班级更名不改变课堂身份，已经确认的原请求结果仍按第一次成功的内容补传。

跨课按学生、同一题库题及同一版本选择最近有效正式作答，按课堂时间而非上传时间排序。最新作答未设置答案时显示未判定，不能回退选旧成绩；新课未答或免答不抹去旧课已有的有效作答。临时题未关联题库时保持独立题目身份。知识点按标签展示题数、作答数、已判定样本和正确率，多标签分别归类；总体不因此重复加权。

## 学生个人课堂分析

学生仅能查看本人已经结束并同步到学校服务的课堂，包含答题记录、正确率、错题回顾和知识点统计。题干尚未补录时显示相应提示；没有教师确认标签的题目不猜测知识点。首版不含 AI 个性化讲解。

正确率与教师报告采用同一正式轮次和跨课去重规则。未答、未完成、免答、未判定和练习分别展示，不当作错误计入判分样本；原轮次和练习历史仍可查看。教师课后修订答案或标签后，个人分析按修订内容重新计算。转班前已关联身份的课堂保留在本人历史中。

## 数据与接入

正式本机记录位于 `%LOCALAPPDATA%\ICeClass\CardQuiz\`，按学校地址、设备和班级隔离；预览记录放在独立预览程序目录。名单、题单、原始课堂事件、回执、同步进度和教师修订分别保留。改绑不会把原课堂带到新班级。

服务端沿用教师 cookie、CSRF、班级权限和设备认证；学生使用独立会话和 CSRF，接口在服务端限制为本人数据，不能取得教师管理权限或整班成绩。学生密码采用哈希保存，发放和重置结果不写入班班操作历史，打印所用密码不进入 URL 或浏览器持久存储。教师接口在实际处理器声明班班能力；摄像头、手机登录与配对等必须本人完成的入口注明人工操作原因。视频仅在扫描端本机处理，不上传学校服务。不增加服务器视觉依赖或公共中继。

## 开发检查和现场验收

自动检查入口见 README 的开发命令。图案测试覆盖 157 张卡的四个旋转方向；浏览器流程与模拟媒体只能验证软件路径。

现场分别检查目标 Windows 白板、摄像头和手机：

1. 用正式打印尺寸核对 A/B/C/D 和判断题方向，覆盖前后排、横竖屏、光照、斜视及遮挡。
2. 同时举多张卡、学生改答、同号重复卡和相反方向冲突，确认未稳定或有冲突时不误收。
3. 在结束、换题、切来源和断网瞬间举卡，核对迟到候选未进入封存轮次。
4. 核对已收后退出、重启、离线再联网、手机回执中断及课后报告，确认原记录和修订保留。

希沃品牌本身不代表系统、相机或后排覆盖满足要求。适用设备须能运行当前 Windows 教室端和 WebView2，并有可用相机；没有合适机位时使用手机采集。

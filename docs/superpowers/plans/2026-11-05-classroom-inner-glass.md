# 教室端内层液态玻璃正式接入

用户已批准 66 页完整样板并要求直接实施。本轮在现有真实窗口和状态中接入，不新增样板目录、虚构记录或演示开关，不提交、推送或部署。

## 覆盖与实现顺序

1. 共用网页玻璃：复用首页的边缘位移算法，支持动态弹窗和尺寸变化，清理已卸载节点。背景镜片与文字分层，无永久光学动画循环。沿用微软雅黑，主操作 17px、正文与辅助字 16px，紧凑辅助字最低 15px。
2. 创意计划：提交、录音、拍照/导入裁剪、预览、核对/署名、进度及评审/成果详情、删除与离开确认。保留草稿、授权、录制停止及服务接口。
3. 早读：四模式选择，诗词/粒子设置及侧边控制，兔子/火箭素材内的设置、结果、麦克风反馈，日历与记录。保留活动画布、素材、设置和统计。
4. 原生共用外壳：蓝白曲面、明确标记的玻璃容器，复用现有 Skia 边缘折射；只在布局变化时更新光学资源。教室设置、电脑权限、浮岛设置/演示、关于四页、资源/更新、权限与未保存确认、晨读提醒使用同套材料。
5. 班班与通知：仅原生教室会话网页接入共用外观，不改变教师网页；保留桌宠菜单的原生操作。普通/重要/紧急通知保留等级、倒计时和确认行为。
6. 首页、班级管理、作业/留言各状态同步清晰字号；保持四模块等权与工坊筹备状态。

## 验证与交付

- 网页脚本语法、实际静态资源/CSP、动态弹窗与窄窗/键盘。
- 教室端和教师桌面端构建，桥接/创意/早读已有关键路径检查；不以旧样板验证代替正式实现验证。
- 分批实窗检查桌面与最小窗口，统一修复发现的问题后作一次确认。

- 记录实际验证与未测硬件/真实设备行为。

# 班班桌宠实现与验收计划

目标：把现有 Windows 班班语音助手做成可常驻桌面的轻量小书灵；原有唤醒、连续对话、任务执行、打断与取消继续使用同一条链路。

依据：用户要求无人值守完成，沿用现有班班形象、字体、蓝白配色和 .NET 8 / Avalonia / WebView2 技术栈。本次选择透明原生窗口；不新增 Electron、浏览器实例、模型或声音引擎。现有原画分层足够，不需要重新生成角色素材。

- [x] 完成提速回归。保留实时授权、动作回执和结果核验；明确短语音指令可直接执行，复杂任务继续走模型。
- [x] 新增 `BanbanPetWindow`：桌面边缘停靠、拖动、键盘移动、菜单复位、显示/隐藏、位置恢复和暂停语音。透明区域不挡住其他窗口。
- [x] 新增 `BanbanPetMascot`：复用原画分层，待机、倾听、处理、播报有克制的动作；隐藏、静音和减少动态效果时停止不必要绘制。
- [x] `BanbanVoiceWindow` 持有桌宠，单击开始对话，双击或菜单打开完整聊天，菜单取消任务；只复用已有服务，不创建第二个麦克风或模型实例。登录、锁屏、重绑、退出时清理一致。
- [x] 在正式客户端与本地验收托盘中提供桌宠恢复入口。记录本地验收启动方式；不推送、不发布、不部署。
- [x] 验证透明原生窗口、角色素材、主要状态、点击和菜单、隐藏恢复、窄工作区、负坐标屏幕、位置恢复、减少动态效果以及语音整条链路。

验收重点：桌宠不抢应用焦点，不把隐藏当作退出，不在未登录或锁屏后继续接收任务；拖动不能误触发操作；隐藏后停止绘制；语音启停和任务取消必须到达真实服务。

已知边界：新增外观不会提升识别模型本身的准确率；仍需真人口述与学校教室噪声验收。只保留 8866 本地验收，保护既有文档和其他预览。

2026-10-28 验证记录：原生桌宠 20 项、语音链路联调 16 项、语音边界 55 项、服务端 264 项检查通过；真实鼠标与键盘验证单击、双击、拖动、移动和菜单。负坐标与缩放使用工作区边界测试，未代替实体多屏验收；语音联调向真实识别回调注入文字，未代替真人教室声学验收。新建普通 Word 文稿已实测复用 WPS，明确指定微软 Word 的首次自动化启动仍可能超时。详见 `docs/班班桌宠与响应速度.md`。

# 晚自习管理 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans in this session. 用户已要求完整开始实现；保留已有未提交改动，不提交、推送或部署。

**Goal:** 打通指定晚自习时段的自动观察、提醒、持续异常上报、单次附图和班主任查看，严格限制 AI 用量。

**Architecture:** 独立业务模块复用现有设备和教师权限。教室端本地 VAD/ASR 筛选；服务端维护预算、分类和事件状态；教师工作台使用已有 UI。

**Tech Stack:** C#/.NET 8、Avalonia、WebView2、NAudio、sherpa-onnx；Python aiohttp/SQLite；原生 JavaScript/CSS。

**Spec:** ../specs/2026-11-07-self-study-design.md

## Global Constraints

- 不修改既有绑定、设置和真实数据，不调用真实模型做付费测试。
- 原音频不上传、不落盘，转写不持久化。启用、授权、日程和版本均由服务器验证。
- 4 次/班/日、2400 token/班/日、单次输出 64 token；失败不自动重试。
- 值班老师无需确认事件。未知放行；真实展示提醒及后续独立异常窗口后方可升级。
- 保留原字体、共享控件、短横线范围连接符、操作反馈、键盘和窄屏可用性。

## Review Focus

- 配置关闭、改绑或跨时段期间在算的旧结果不得触发提醒/相机。
- 多设备并发、HTTP 超时与重复观察不得重复付费或重复拍摄。
- 老师讲题、短问答、识别失败和无法联网不得伪装成确定的违纪事件。
- 悬浮岛被其他重要通知占用时不得谎报已提醒。
- 教师登出、换班与照片过期后不得泄露上一班照片或覆盖未保存设置。

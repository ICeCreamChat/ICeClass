# 班班云端视觉本地试用

用户已选择调用厂商视觉 API，并授权先在本机试用。沿用现有 Python/aiohttp、C#/Avalonia、语音入口和设备操作通道；不部署服务器、不提交或推送、不下载视觉模型。

## 方案

使用现有 DeepSeek 连接。保留 UIA 和 Office 接口，增加所选允许窗口的限尺寸截图与绑定该截图的坐标点击、输入、导航、滚动、拖动。模型接收真正的图片内容，操作后重新截图核对，不把“输入已发送”写成“任务已完成”。无需新界面或额外常驻框架。

截图只进入短期内存与本轮模型上下文，不进入数据库、操作回执文件、日志、聊天历史。只保留最新截图，输入校验包含设备、账号、绑定、窗口、截图时效、坐标和实际前台窗口；每张截图只授权一次输入。保留现有取消、语音直接执行和审计。图片上出现的要求不是用户指令。

## 实现与验收

- [x] 用不含用户数据的合成图片验证现有 DeepSeek 图片接口。
- [x] Python：截图提取与短期转交、操作参数、模型图片消息、真实 token 用量；测试图片不落库、错误输入、过期和越权。
- [x] C#：指定窗口截图、限尺寸编码、坐标映射与输入；测试窗口变更、截图重放、取消和图像结果。
- [x] 实际模型通过完整产品通道操作本轮新建的测试窗口，独立读回结果并记录耗时和 token；不改用户已有文档。
- [x] 必要回归、构建和本机启动，报告实际成功与限制。服务端 250 项、默认原生 143 项、视觉原生 14 项通过；两组实际模型写操作与新版语音宿主截图只读验收通过，8866 与 `manual-v20` 已启动。

通过实际 DeepSeek 图片请求验证当前连接，参考 Microsoft UFO 的截图/动作/再观察模式，不直接复制第三方代码。项目无本地视觉推理，不新增视觉模型文件。实际模型联调中的失败与成功均保留记录，详见《班班通用电脑助手》的本次补充。

# 全新视频展台插件

用户已在 2026-11-14 明确纠正旧方案，并确认「完整工作台，开始展示后切置顶浮窗」；要求界面少文字。该决定取代旧规格中直接使用善忠 VideoBooth 桌面壳的部分，既有课堂点评、安装及额度约定继续有效。

采用独立工程 plugins/VideoBooth，产品名「视频展台」，进程 ICeClass.VideoBooth.exe。UI、窗口管理和工作流全新实现；旧项目只复用经过验证的传输、证书和图像/点评底层代码，保留来源记录及许可。工程不引用工作区外 csproj，不启动旧程序、不读取旧资料目录。插件仍通过现有 v1 管道与 ICeClass 对接。

完整工作台集中设备选择、预览和 AI 点评；置顶浮窗集中展示、点评、继续、停止与返回。新界面没有旧品牌、大段说明、独立更新器或旧连接设置面板。电脑和 USB 默认离线可用，手机按需准备，不能因为打开工作台就启动热点、申请证书或连接收费模型。AI 沿用已实现的宿主 WPS 取题与学校服务，结果仅会话内保留。

考虑过继续改旧主窗体，因用户明确否定而排除；考虑过把全部媒体与证书重写，收益不足且会放弃已验证的手机链路。选择新工程、新界面、有限复用传输内核，以实现用户可见的独立产品并控制风险。

初始版本 1.0.0；插件 ID 保持 iceclass.video-booth，以复用宿主管理协议。真实资料路径迁至 ICeClass/Receiver/VideoBooth/data，验收使用独立目录；旧数据保持原位。旧包和本轮新包分别保留，不自动覆盖安装。新安装仍默认禁用。

不在本轮增加学生画像、连续 AI 视频分析、持久化成绩、远程插件商店或线上发布。验证覆盖新页面真实行为、代次与图像边界、原生握手和退出、两架构构建及包校验；真实摄像头、手机和 WPS/AI 课堂效果由用户现场验收，不以模拟数据宣称通过。

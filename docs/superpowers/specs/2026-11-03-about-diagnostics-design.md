# 关于、诊断与教室通知动画

用户已确认“关于”同时需要故障诊断和版本更新记录；动画异常发生在教室大屏收到通知时，人物动作和通知条过渡都缺失。

在现有 Avalonia 关于窗口中增加“更新记录”和“诊断日志”页签，保留致谢、许可、字体及按钮样式。记录随程序分发，离线可读，内容只写实际交付的改动。教师端复用现有最近 24 小时诊断收集；共享关于窗口同时为教室端提供本机错误日志与运行状态。按需后台读取，支持刷新、复制与导出 ZIP。导出仅包含界面预览的脱敏报告和公开更新记录，不收集配置、登录、录音或业务数据。

新版使用 2.5.6，不覆盖已发布的 2.5.5。新增诊断包含系统动画偏好、版本、系统环境和语音资源状态，教室端补充最近通知的动画状态，供真实大屏排查。

动画先在隔离原生窗口复现真实通知的隐藏、显示、重复通知与系统动画偏好路径；找到可证实原因后做局部修复。未复现的问题保留明确限制，不以测试窗口替代学校硬件验证。

用户后续确认：两端自动上报错误和必要状态，完整近期诊断由“关于”手动提交。服务器在账号设置内为超级管理员提供客户端日志列表、筛选与详情，身份从有效设备绑定或教师登录解析，服务端再次脱敏。错误聚合并限量发送，失败继续保留在本机，避免递归上报上传错误。服务器每周一凌晨（上海时区）批量清理超过 7 天的客户端诊断；服务停机后补做该周清理，不影响业务记录。

验证覆盖两端构建、页签与键盘、正常及窄窗口、读取取消/失败、日志脱敏与 ZIP 内容、真实计时器驱动的动画，以及上报鉴权、权限、容量、重试与每周清理。完成后打开最新本地程序及关于界面供用户验收。本轮不含 Git 提交或推送；线上变更需按当前授权处理。

# 轻量安装与语音资源准备

用户已于 2026-11-02 确认讨论方案并要求完整实现，遵循根目录 AGENTS.md 和现有原生界面规范。

- 默认提供轻量教室端和教师端，另提供带齐各自语音资源的完整离线包。保留现有绑定、登录资料、设置和数据。
- 安装后在课间空闲自动补齐语音资源；上课、早读、录音和对话时暂停。教师工作台使用中延后自动传输，无法确认课时则等待。
- 两端都在设置内提供单一“下载语音资源”按钮，点击后补齐当前客户端需要的全部资源；教师主窗口不常驻下载底栏。手动传输允许跳过上课和课表未知的等待，早读、录音、对话等实际活动仍优先。暂停、断线、重启保留断点，失败可重试。资源下载完成即就绪，无须另行下载完整包。
- 资源未齐时文字通知、原声录音和其他不依赖模型的功能可用，明确显示尚未就绪的语音能力。自然语音播报优先补齐，随后准备识别等资源；不在准备完成前承诺唤醒可用。
- 校验大小、SHA256、相对路径和来源；下载校验完才使对应资源可用，资源补齐不触发程序安装或重启。复用已有本机资源，不反复卸载唤醒模型。
- 教室设置与教师端沿用 Microsoft YaHei UI、现有颜色、共享 SemiBold 按钮及进度样式。提供百分比、已下载/总量、准备/暂停/失败/就绪状态；窄窗可换行，支持键盘和无障碍名称，不添加装饰箭头。

## 实现选择

复用 Shared/IncrementalUpdates.cs 的可靠文件传输，语音目录与程序待安装记录分开。小型资源清单随核心内置，按当前程序要求的哈希下载学校平台的公开语音 payload，不让模型下载携带教师登录 Cookie，也不依赖境外上游首次下载。服务器复用已有 payload 校验和 Range 响应。

完整教室包继续使用已支持的内嵌模型；完整教师包随包携带 ASR 文件并在安装时校验复制。教师端复用已有本机识别缓存。只补齐资源的方案比让老师再次等待整包下载更符合本轮目的；两端仍各自保留完整包用于离线分发。

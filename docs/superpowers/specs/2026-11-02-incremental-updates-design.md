# 两端增量更新与待机内存

## 已确认的体验

- 教师端、教室端均支持增量更新；完整离线安装包继续提供。
- 未变化的语音资源不重复下载。新电脑使用完整离线包，旧版本允许一次完整过渡升级。
- 上课或早读、录音、对话等功能使用中暂停后台下载；课间空闲恢复，支持断点续传。
- 下载完成仅标记就绪，下次真正启动安装；保留老师主动选择的“立即更新”。
- “你好班班”响应优先，保留持续唤醒、同一句后续指令、连续对话与打断。内存收益实测，不预设数值。
- 保留班级绑定、账号资料、配置及离线数据，不触及线上部署。

## 工程选择

沿用 .NET 8/Avalonia/WebView2。完整离线 EXE 同时作为旧更新器过渡入口；额外发布不嵌入大语音资源的程序核心。新更新计划按文件校验并复用语音资源，首次从过渡 EXE 的内嵌资源就地准备外置资源，不必重新下载模型。

程序及有变化的资源可使用 Windows 自带 MSDelta RAW 差分；只在上一版内容与补丁来源完全匹配、补丁小于全量且发布端回建校验成功时提供。无适用差分则只下载该变化文件。此选择避免新增常驻运行时和自行实现差分算法。现有完整更新接口保留给现有调用方。

先在独立暂存目录验证整个计划，安装时在退出后替换变化文件并保留备份；新版确认启动才清理备份，失败恢复原文件。HTTPS同源、长度上限、SHA-256、路径限制同时约束完整文件与补丁。安装前再次校验。

内存只先消除已证实的重复分配与不必要的资源持有。不直接关闭当前承担授权的隐藏语音页面，不让定时器反复卸载/加载，不清空工作集制造虚假收益。

## 验收

覆盖未变文件零下载、真实差分回建、来源不匹配、断网续传、恶意路径、错误hash/长度、安装失败回退、重启前不替换、上课与功能活动时暂停，以及两端构建和既有关键测试。旧版/新版语音测试使用同一环境，报告实际进程树内存和可核对的唤醒表现；未能完成的硬件场景明确列出。完成后打开最新本地两端供人工验收，不自行提交、推送或部署。

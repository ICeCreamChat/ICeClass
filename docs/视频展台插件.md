# 视频展台插件

教室端创意工坊支持在本机导入视频展台 ZIP 插件包，启用、打开、停止、禁用和卸载。插件是本仓库 `plugins/VideoBooth` 中的独立程序，使用全新工作台与置顶浮窗；教师端与网页不安装本机插件。

## 安装与展示

1. 教室端首页打开“创意工坊”，点击“安装插件”，选择适合电脑架构的 `ICeClass-VideoBooth-win-x64.zip` 或 `win-x86.zip`。
2. 核对名称和版本后安装。新安装默认禁用，点击“启用视频展台”，再“打开视频展台”。
3. 在工作台选择电脑、USB 或手机来源，开始展示。展示时可切为置顶浮窗，恢复工作台仍使用同一采集画面。启用或打开插件本身不会开启摄像头或准备手机连接。

同一资料目录只允许一个实例使用，不同隔离资料目录可分别打开。安装和普通展示不调用 AI，也不消耗班班次数；电脑和 USB 摄像头保留离线展示能力。手机连接按需准备，依赖实际网络与证书配置。

隐藏教室首页不结束展台。“停止并关闭展台”“禁用并停止”“卸载并停止”会等待受管进程退出；失败时保留文件并显示错误，不报告卸载成功。禁用状态下次启动仍保留。

卸载只移除插件安装文件及启用登记，保留 `%LOCALAPPDATA%\ICeClass\Receiver\VideoBooth\data` 中的资料。本地教室预览使用程序目录下的 `PluginData\VideoBooth\data`。旧展台的配对、证书及设置保留原位，新插件不自动迁移。更换包时先卸载再安装。

## 数学课堂点评

在同一电脑开始 WPS 演示放映，并在班班电脑设置中允许查看。当前班级须关联唯一启用的班主任，沿用该账号选择的班班连接；模型需要支持图片输入。

1. 将学生作答清楚地放在展台中，点击“AI 点评”。系统先确定 WPS 题目窗口，再冻结作答并读取题图。首次只有一个放映窗口时自动使用，多个窗口时选择一次；已选窗口消失后需要重新选择。
2. 点评直接展示给全班，包含明确结论、简短的肯定与下一步提示，以及 1-2 个知识点。作答未完成或无法判断时，不会宣称正确。
3. 同页多题且无法确定对应关系时，在固定题图中框选完整题目续评。可拖动或输入坐标；方向键移动，Shift 加方向键调整大小，Ctrl 加方向键每次调整 10 像素。
4. “本次题目”查看点击时固定的 WPS 画面，后续翻页不会替换本次题图。点击“继续展示”清空本次点评并恢复实时视频，下一位学生再开始新点评。

首次双图分析被服务受理时计一次现有设备月度次数，预备、参数或权限拒绝不扣次。同一点评的框选续办不再扣次，最多两次模型分析；已受理后的失败、超时或取消保留本次计数。额度用尽仍可继续展示、停止和取消。付费分析不自动重试。

来源变化、旋转、停止、退出、改绑、锁屏、休眠或明确的设备身份失效会使旧点评失效。题图、作答、选区和结果只保留在本次内存会话，不建立成绩记录或长期图片档案；学校连接仍按原有规则向所选模型服务发送本次双图。

取图失败、画面过旧、两图间隔超过 2 秒或图片超限时显示反馈，继续展示后可手动重试。系统不使用整桌面截图或旧题冒充当前题目。每图最长边 1920、PNG 最大 2 MiB，只进行最长边所需的一次缩放，超限不继续降低清晰度。

## 构建与维护

学校服务更新后安装 `server/requirements.txt`。Pillow 负责受限 PNG 解码和原图裁切，点评接口独立于聊天历史：

- `POST /api/banban/math-reviews`：按唯一 `requestKey` 预备五分钟会话。
- `POST /api/banban/math-reviews/{reviewId}/analyse`：提交固定双图。
- `POST /api/banban/math-reviews/{reviewId}/selection`：提交原题图整数像素选区。
- `POST /api/banban/math-reviews/cancel`：按原 `requestKey` 取消。

接口限绑定教室端手动触发，复用设备认证、CSRF、班主任连接和月度额度；模型没有电脑工具权限。每设备最多一个活动点评，全局最多八个活动点评、256 个期限内记录。终态或服务重启前的 ID 不会重新受理。

清单 `plugin.json` 的 `schemaVersion`、`hostApiVersion` 均为 1，ID 为 `iceclass.video-booth`，声明名称、三段版本、架构与 EXE 入口。导入校验路径、重复条目、链接、入口架构和个人资料文件；确认与安装使用同一个只读 ZIP 句柄。清单不是发行者签名，请只安装可信来源的包。

在本仓库使用 PowerShell 7+ 运行 `scripts/package-video-booth-plugin.ps1`，显式指定 .NET 10 SDK 及 x64/x86 固定浏览器目录，构建 `ICeClass.VideoBooth.exe` 自包含包；宿主仍使用 .NET 8。构建不依赖旧 VideoBooth 源码，不纳入 data、配对、证书、设置或浏览器缓存。来源与分发许可见 `plugins/VideoBooth/NOTICE.md`。宿主通过限定当前用户的命名管道核验启动进程 PID，不把服务凭据交给插件。展台本地代次贯穿事件、冻结、状态及恢复命令，来源变化后拒绝旧命令。

相关检查：

```powershell
python -m unittest discover -s server -p 'test_banban_math_reviews.py' -v
dotnet run --project tests/WorkshopChecks
dotnet run --project tests/MathReviewChecks
dotnet run --project tests/ReceiverOfflineChecks/ReceiverOfflineChecks.csproj -p:EmbedVoiceResources=false -- --workshop-checks
dotnet run --project tests/ReceiverOfflineChecks/ReceiverOfflineChecks.csproj -p:EmbedVoiceResources=false -- --math-dialog-checks
node --test scripts/test-workshop-ui.cjs
```

这些检查使用隔离身份、合成图像和本地 HTTP 边界。真实 AI 数学准确率、WPS 遮挡取图及电脑/USB/手机手写识别效果仍需现场验收；不能把模拟模型和契约检查当作实际准确率。本地构建不代表提交、发布或部署。

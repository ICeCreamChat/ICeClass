# 2.5.9：批量设置与班班动画

日期：2026-11-03。教师端与教室端统一升级到 2.5.9。

## 本次变化

- 教师端和网页的教室浮岛合并“批量设置”与“复制到其他班级”，按内容同步或整套复制；支持年级分组、搜索、权限筛选、草稿保存继续、逐班预览和原子应用。未勾选的内容保留各班原设置。
- 修复 Windows 动画关闭时关于页班班鞠躬不播放的问题；保持原有有限鞠躬动作，支持点击和键盘重播，隐藏或离开页面时停止。
- 原生语音桌宠、通知条和浮岛人物默认播放动画，仍保留本机浮岛动画开关；网页继续遵循减少动态效果偏好。
- 保留轻量安装、手动补齐语音资源、诊断日志、自动错误上报和每周清理、立即更新及增量更新。

## 已完成验证与边界

动画行为及批量设置的本地验证见 [动画检查记录](动画检查记录-2026-11-03.md) 与 [批量设置实现说明](plans/2026-11-03-island-bulk-ux.md)。Windows 动画关闭场景使用隔离依赖模拟；学校 Windows 10 大屏需要更新后现场复测。

正式发布的包校验、服务器部署结果及公网验收记录保存在本机 `output/server-release-2.5.9-20261103/`，以实际回执为准。此次服务器发布不包含 Git 提交或推送。

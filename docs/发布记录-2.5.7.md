# 2.5.7 教室端发布记录

日期：2026-11-03。已完成本地构建、验证和上海服务器正式发布；教室端为 2.5.7，教师端和服务器业务代码保持 2.5.6。本轮没有 Git 提交或推送。

## 现场原因与修改

高一（17）班用户提供的 11:52 诊断报告显示，2.5.6 运行于 Windows 10，系统动画关闭。11:51 的普通、重要和紧急通知均记录系统、人物与通知条动画关闭、帧回调为 0，而素材正常载入，确认了程序跟随系统静态显示的原因。

用户随后明确要求其他人打开就能用、以后默认开启动画。本次将浮岛动画改为本机应用设置，默认开启，不修改 Windows 全局设置。

- 首次安装与旧版本地设置缺少动画字段时均默认开启；已有明确关闭选择时继续保留。
- “教室浮岛设置 → 外观与显示”顶部增加“播放浮岛动画”，独立于本机外观，保存后立即生效。
- 人物、通知条、拉开与展开过渡统一使用此设置。关闭后直接显示完整通知，停止持续动画回调。
- 正常通知与演示使用相同设置；诊断分别记录 Windows 偏好、浮岛设置和控件状态。
- 教室端版本为 2.5.7；教师端版本未改动。共享更新记录标明本次为教室端功能。

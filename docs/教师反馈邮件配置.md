# 教师反馈邮件配置

Windows 教师端的“反馈”使用已登录学校账号提交，服务器固定收件邮箱，客户端无法另选收件人。发信密码只配置在服务器环境，不进入 EXE、网页、Git 或分发包。

本项目复用开发者现有的 126 邮箱：`icexu330@126.com`，SMTP 为 `smtp.126.com:465`，使用 TLS。服务器进程需要以下环境变量：

| 变量 | 用途 |
| --- | --- |
| `ICECLASS_FEEDBACK_SMTP_HOST` | SMTP 主机 |
| `ICECLASS_FEEDBACK_SMTP_PORT` | 端口，默认 465 |
| `ICECLASS_FEEDBACK_SMTP_USER` | 发件邮箱 |
| `ICECLASS_FEEDBACK_SMTP_PASSWORD` | 邮箱 SMTP 授权码 |
| `ICECLASS_FEEDBACK_RECIPIENT` | 固定收件邮箱 |

部署时通过服务管理器的私有环境文件或已有密钥管理方式注入，限制文件读取权限。不要把真实授权码写进文档或部署包。未配置时接口返回明确的服务未就绪错误，不会假报发送成功。公网仍沿用原有 HTTPS 域名与登录凭据。

`POST /api/feedback` 接受 multipart：`report` 为描述和诊断元数据 JSON，`logs` 为可选 UTF-8 日志，`screenshot` 为最多三个 PNG/JPG/WebP 附件。登录及 CSRF 校验在读取附件前执行，教室设备凭据不能代替教师登录。服务器校验字段和大小，并统一附件名称；每个账号十分钟最多尝试发送三次，同时只允许一次发信。附件不落库、不在磁盘另存。

诊断附件为可独立阅读的 UTF-8 文本，包含问题描述、反馈人、发生时间、环境和近期错误；新版增加最近 24 小时的本机操作、页面与请求耗时、状态和错误来源，重启后保留。收到反馈后，可直接转发原邮件及“教师端诊断日志.txt”和已选截图，无需教师另行寻找日志。活动容量与脱敏范围见 [Windows 教师端](Windows教师端.md#251-使用反馈)，诊断从新版运行后开始积累。

只有 SMTP 确认接收邮件后返回 `201` 和反馈编号。失败只记录异常类型，避免输出账号、授权码和邮件正文；教师端保留草稿供重试。SMTP 接收不代表已经进入收件箱，首次验收仍需检查邮箱及垃圾箱。

# 2.5.0 班班语音助手与桌宠

2026-10-28 完整交付版，包含教室端、Windows 教师端、网页与服务器。GitHub 发版与学校部署分别执行；发布附件不会自动更新学校服务、正式下载或教室客户端更新源。

## 班班语音与桌宠

- 支持“你好班班”后台唤醒、连续对话、实际任务执行、神经语音反馈、插话停播、取消操作和结束对话。收起到托盘仍可唤醒，复用原有教师登录、班级权限与模型连接。
- 使用 SenseVoiceSmall INT8 整句识别、Silero VAD、MeloTTS 中英神经语音及 Windows 回声消除。未知词不直接作为任务提交；结合上下文和实际应用候选理解近音、同音及软件缩写，保留原始转写，不擅改指定正文、数字、否定词、班级或路径。
- 每次唤醒建立本次对话的临时说话人特征，减少旁人声音进入任务或触发打断。特征和声音仅在本机内存使用，对话结束后清除；不等同于身份认证或多人声音分离。
- 原班班书本形象成为原生透明桌宠。平时以小尺寸贴边，上课按已同步课表隐藏，语音唤醒时跳出；支持拖动、键盘移动、暂停与隐藏，闲置后收回。
- 24 种连续动作包含倾听、托腮、点头、讲解、眨眼、探头、跳跃和打断后停下倾听。动作切换保留当前姿态与速度，遵守系统减少动态效果设置，隐藏和待机时停止不必要的动画计时。
- 修复小尺寸网格采样导致的身体错位，以及实际窗口遮罩导致瞳孔消失的问题。眼白、瞳孔和睫毛在同次原生绘制中合成，保留眨眼遮挡与视线变化。未更换原角色；绘图设定稿和预览 GIF 不嵌入安装包。

## 电脑操作与响应

- 用户通过对话安排打开、切换、最大化或关闭应用，浏览窗口和控件，操作课件放映，以及创建、读取和填写支持的文字或演示文稿。打开应用默认切到前台并最大化。
- 明确的语音指令直接执行，继续核对已登录账号、设备绑定、权限、真实目标和结果；普通文字任务保留原确认规则。缺少目标、正文或密码时仍需补充，不凭猜测执行。
- 支持教室端本机所有当前 Windows 用户可访问的文件夹，并保护系统目录和敏感路径；文件删除进入回收站，不永久删除。教室端与本地验收沿用同一套策略。
- 在控件接口不足时可使用配置的厂商视觉 API 查看所选窗口并操作，动作后重新观察并核验；服务端不部署视觉模型。截图过期、窗口遮挡或结果无法核实时明确反馈。
- 完整且目标唯一的单步命令在观察真实窗口后直接进入原操作流程，减少不必要的模型往返。复杂任务继续由模型规划，回执提供最新观察；不根据尚未说完的半句话提前执行。
- 数学公式先转成适合中文朗读的语句，再由神经语音播报；未覆盖的复杂表达提示查看屏幕。对话文字、操作卡和状态反馈精简，修复思考头像、消息气泡及滚动布局。

## 教室岛与教师工作台

包含课表、默认作息、循环值班、单双周、临时调课、Excel 导入导出和本地自动化改进。修复教师工作台切换时的布局跳动，沿用已有字体、权限和移动端布局。

## 完整交付与构建

附件提供四个 Windows x64／服务器 ZIP：教室端、Windows 教师端、完整 Windows 交付包、服务器包；另附 Ubuntu 更新脚本与 SHA256 校验文件。教室端自带 .NET 和离线语音资源，学校电脑无需安装 Python、Node.js 或额外下载模型；WebView2 Evergreen Runtime 仍需可用。

模型及语音数据不放入 Git 历史。干净源码构建先运行 python scripts/prepare-banban-voice.py，下载固定上游版本并校验 SHA256；build.bat 与 GitHub Actions 已接入该步骤。构建需 Python 3.11+、.NET 8 SDK、Node.js 和首次准备依赖时的网络连接。最终程序仍为独立交付，不依赖这些开发工具。

唤醒、识别、说话人比对和声音合成在教室电脑完成，无需新增语音 API 密钥或服务器音频模型。仅携带当前使用的离线模型；旧模型、实验依赖、个人配置、密钥、数据库、绑定信息及本地运维资料不进入附件。模型、字体和组件的第三方许可随客户端及服务器交付。

## 验证与使用边界

发版前服务端完整测试 270 项、发布工具检查 20 项、语音及课表 JavaScript 检查 40 项、旧 Cloudflare 检查 7 项通过，TypeScript 检查通过。原生连续动作与画面检查 55 项、桌宠交互检查 34 项及教室端离线检查 144 项通过；实际预览窗口确认眼睛恢复。发布包另检查 CRC、版本、SHA256、两端程序一致性，并从解压后的服务器启动独立数据库和 HTTP 服务。

已有用户真人验收覆盖中文唤醒、完整句子识别、实际改字和口令打断。本次没有以自动测试代替真实教室远场、多人重叠声音或所有第三方软件版本的现场验收。SenseVoice 的部分合成英语、数学语句仍有转写误差；模糊理解不能补回真正丢失的语义。复杂控件、管理员权限隔离、未保存提示及不提供核验接口的应用仍有边界，不能保证任意软件或任意命令都可自动完成。

完整使用和范围见[语音助手](班班语音助手.md)、[桌宠与响应速度](班班桌宠与响应速度.md)、[通用电脑助手](班班通用电脑助手.md)、[语音防串声](班班语音防串声.md)。

升级学校现有 Ubuntu 安装时，使用配套 update-ubuntu-2.5.0.sh 或 scripts/update-ubuntu.sh，先备份程序、数据库与配置；不要用演示数据库覆盖学校数据。替换教室端 EXE 保留原绑定。学校应先在一台教室电脑完成麦克风、课表、课件与远程操作验收，再推广。

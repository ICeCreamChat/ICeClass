# ICeClass · 班伴本地验收

身份验收（2026-10-19 更新）：校长管理全校；主任管理高一、高二、高三；年级部长管理负责年级；班主任教师使用本人班级。全校规则由校长与超级管理员维护，用户与班级管理按职责逐级授权。旧账号密码、班级授权、设备绑定和历史记录在升级后保留。详细分配步骤见 [用户权限与管理](用户权限与管理.md)。下方旧版本安装包记录仅作历史参考。

## 本地演示

当前验收服务地址为 `http://127.0.0.1:8838/`。新版程序位于 `dist/local-review-2.2.1`，同目录的 cloud-url.txt 预置这个地址。已有绑定时，只替换原目录的 EXE，保留配置。关机再开机后，双击验收包中的“开始本地验收.bat”即可启动网页服务并打开网页；保留该服务窗口，再打开客户端。也可从源码目录运行：

```powershell
scripts/start-preview.ps1 -Port 8838
```

源码目录双击 `start-preview.bat` 时默认使用 8837 端口；改用默认端口后，也需要相应修改教室端平台网址。

| 身份 | 用户名 | 密码 | 权限 |
| --- | --- | --- | --- |
| 演示管理员 | `ICe` | `LocalDemo2026` | 全部班级、规则和远程控制 |
| 演示教师 | `teacher1` | `LocalTeacher2026` | 仅高一（1）班的通知与统计 |

演示中预设 44 个班级（高一 16 班、高二 14 班、高三 14 班），其中两个保留原示例成绩，原三个演示白板默认离线。示例成绩不是学生的真实数据。演示全日启用方便体验，正式平台首次安装默认关闭统计，需要管理员配置。

演示数据库位于 `.tools/preview/demo.db`，关闭窗口停止服务。需要重新初始化时先停止服务，删除该文件再启动。正式数据库与演示数据库分开。

“预览早读陪伴”可体验四种模式，但不会累计成绩。若要在本机验证真实计时，打开桌面验收文件夹里的 EXE，输入 `mas22`、读取班级、依次选择年级和演示班级后绑定，再从教室端打开早读。绑定码过期时，ICe 可以在“班级管理 → 全校快捷绑定”重新开放。连接 localhost 的验收副本不会修改 Windows 开机启动设置。

## 推荐验收顺序

1. 检查登录页、标题、托盘和 EXE 名称均为班伴/ICeClass，登录后首页为早读统计。
2. 管理员新建班级，再切换早读统计和教室控制，班级选择框应立即包含新班级。
3. 校长或 ICe 配置一个包含当前时间的短时段。教师只能查看和控制本人班级；年级部长只管理负责年级；主任覆盖高一、高二、高三；校长管理全校。分别验证用户管理、班级管理、设备、通知、来音、报表和越权请求，确认新班级自动进入对应年级管理范围。
4. 从本机绑定的教室端打开早读，应在班伴内铺满屏幕显示四模式入口；选择模式并点击开始后允许麦克风，页面显示正确班级名称。长按屏幕空白处 2 秒退出全屏，再点击“教室首页”返回。键盘 Esc 仍可用。粒子浮雕封面为原图，内部动画与操作保持原样。
5. 分别运行拔萝卜、诗词镌刻、粒子浮雕、火箭升空，检查有效时长增长和对应完成量增长。在原操作面板修改玩法目标、时长和速度，刷新后仍应保留。后台不提供玩法设置；这些本地参数不改变 ICe 的统计规则。
6. 暂停、降低声量或切到后台，确认有效时长停止增长；恢复后继续。到统计结束时间后继续练习，后台成绩应保持不变。
7. 同班开两个运行页面，确认累计时长不会以双倍增长。切换“今天/本周”、展开按天查看，并导出 CSV 对照。
8. 真实白板在线时发送 30%/50% 音量命令，检查 Windows 音量、后台当前音量和“已应用”状态；断网设置后重新连接，检查最新音量应用。
9. 在真实教室远程打开早读；检查客户端麦克风权限和音频输出设备。系统播放音量不等于外置功放旋钮。
10. 发送文字/教师语音通知、从教室给教师留言，检查历史与删除，确认原有通信功能正常。
11. 在演示环境新建测试班级，通过“年度升班”更新几个年级，确认编号、设备和教师授权保留；名称冲突时整个批次不会部分保存。换教室时使用设备“核实 / 改绑”，旧成绩仍归原班级。
12. 使用全校码把两台测试电脑选到同一班，后台应提示核对，并显示不同设备编号、电脑名和地址。填写实际位置、核实归属，检查客户端同步新的班级名和设备备注。
13. ICe 新建并删除测试用户，停用/删除测试设备，清理测试班级记录。删除需输入完整名称，不能删除 ICe 自身。只操作专门创建的测试对象。
14. 首次运行 EXE 后检查桌面“班伴教室端”快捷图标与系统托盘图标。点首页和设置窗口“×”应收起到托盘，后台仍在线、能接收通知；再点桌面图标应打开已有窗口且不增加第二个进程。托盘“退出”才真正退出。
15. 在“班级早读日历”切换班级和年份，点击有颜色的日期与原始报表对照。手机在图内左右滑动，页面本身不应横向溢出；Tab 进入后可用方向键切换日期。没有软件记录不代表没有早读。
16. 在全校统计规则中启用到点提醒，设置今天一个即将开始的短时段，保持新版教室端运行。到点检查“开始晨读 / 暂不开始”，分别验证开始能打开陪伴、拒绝和重启不会反复提醒、时段结束弹窗自动关闭。提醒本身不自动采音或计分。演示库的 00:00—00:00 是全天，不是关闭。
17. 检查早读日期、班级选择、快捷切换与查询按钮齐平；在教室控制、历史记录、教室来音、班级管理及创建用户弹窗检查同排控件对齐。手机换行后每排应保持一致。

18. EXE 输入全校码、读取班级，两个下拉框应为年级和班级；分别检查高一 16 班、高二 14 班、高三 14 班。切换年级不应沿用上一次班级。
19. 在后台增加一个专用测试班级，EXE 点击“刷新班级”后能选到它；停用后刷新应从列表移除。操作完成后仅清理该测试班级。
20. 检查托盘和设置中的“检查更新”入口、当前版本与提示。正式发布新功能时版本号递增；本地服务未配置更新发布文件时显示无可用新版。更新方法及实际测试范围见 [客户端更新说明](客户端更新说明.md)。

## 开发阶段验证范围

服务端自动测试覆盖时间边界、门槛、暂停、重复上报/同班去重、四模式完成量、教师权限、CSRF、一次性打开链接、离线音量和执行回执、视频 Range 请求、用户/设备/班级删除、全校码、升班原子性、电脑身份上报、改绑及旧统计保留，以及原有通知功能。

浏览器测试以模拟麦克风检查四种模式、本地设置保存、后台权限和桌面/手机布局。Computer Use 已实际检查首次绑定、桌面快捷方式、托盘图标和菜单、关闭窗口后在线与通知回执、重复启动唤起、改绑/更名，以及本机 30%/50% 音量；音量已恢复为原来的静音状态。托盘“退出”的进程结束与 EXE 打开早读后的网页内部核对未完成，具体工具限制见 [本地验收报告](本地验收报告.md)。真实白板扬声器、实际麦克风和正式 HTTPS 环境仍需要现场验收。

## 界面字体与布局约定

后续 UI 修改沿用已确认的字体与文字层级，先检查共享样式和实际渲染，再处理局部差异。以下是开发与验收方法，不代表每次修改都已完成这些检查。

- 原生教室端和教师端保留 `Microsoft YaHei UI, Microsoft YaHei, Segoe UI` 字体链。优先复用 `Receiver/NativeControls.axaml`、`ClassroomStyle` 和 `DesktopStyle`；网页沿用自身已有的共享样式，不另行替换字体。
- 原生普通操作按钮使用共享的 `SemiBold`。说明文字、页脚和未选中的文档页签保留常规字重，选中文档页签保持半粗，悬浮岛专用按钮保持已有 `Bold`。不将所有文字统一加粗，也不为单个按钮另造一套样式。
- 文字已明确表达操作的按钮和链接不追加装饰性方向箭头，例如导出、预览、打开日历、发送和返回。下拉选择、展开收起、翻页等需要方向或状态提示的控件保留相应图标；删除图标时同步检查动态状态和窄屏样式，确保文字始终可见。
- 页面标题、字段和按钮已表达用途时，不再添加重复副标题、口号或逐项操作说明；页签内不重复展示同名大标题。通过分组、对齐和操作位置表达关系，精简文字后同步收拢留白。离线行为、有效期、权限范围、修改生效范围和删除后果等必要信息仍需保留；低频规则可放入明确命名的折叠区，不全局隐藏说明样式。
- 字号、间距、控件和区域高度沿用用户已确认的设计。文字加粗后检查按钮内容是否居中、同排是否对齐、长文是否换行或截断，以及页脚是否挤压内容；不要通过随意增高区域来掩盖问题。
- 检查实际窗口中的中文、数字和中英文混排，不能仅凭 `FontFamily` / `FontWeight` 的配置值判断效果。2026-10-24 本机检查发现：Microsoft YaHei UI 的 `Medium` 实际使用常规字体，而 `SemiBold` 使用粗体字形；顶部操作按钮因此曾比其他重点文字偏细。
- 修改共享样式时检查相关调用窗口，覆盖正常与窄窗口、常用显示缩放，以及受影响的默认、悬停、禁用和选中状态。字体修改可先检查 100% / 150% 渲染；涉及缩放或边界问题时再补充相应档位。原生渲染截图与实际 Windows 窗口截图应分别说明，不能将渲染截图写成实机或教室大屏验收。
- `Receiver/NativeControls.axaml`、`Receiver/DesktopStyle.cs` 等由两端共享，修改后构建教室端与教师端，并检查受影响的关键窗口。网页样式修改另行运行构建或语法检查，并在实际浏览器中检查相关页面。

交付时写明改动范围、实际检查的窗口与尺寸，以及未完成的验证。没有必要为低风险样式修改新增截图冻结、hash、baseline、gate 或重复实现样式的测试。

## 2.2.1 内嵌早读验收补充

新版验收文件位于源码目录的 `dist/local-review-2.2.1`，压缩包为 `dist/release/ICeClass-2.2.1-local-review.zip`。现有客户端及班级绑定保留。体验新版前，请从托盘菜单退出旧版，再将新版 EXE 复制到原目录替换程序，保留 `config.json` 和 `cloud-url.txt`；操作步骤见新版包内“使用说明.txt”。

全屏后应看不到客户端和网页的两层顶栏，内容接触屏幕四边。用手指在空白处按住 2 秒，进度圆环出现后继续按住，直到退出全屏；松手、滑动、双指和长按滑块均不应意外退出。拔萝卜、火箭的嵌入画面同样支持。退出全屏时早读应继续，点击窗口里的“全屏”可恢复，再退出并点“教室首页”才会停止本次早读。

已在隔离的实际 Windows WebView2 窗口检查全屏、绑定票据、麦克风拒绝和重新授权、暂停、返回首页、异常重连、重复打开和改绑收尾；并用单文件测试 EXE 验证运行组件能被载入。四模式使用模拟麦克风验证启动、结束采音和统计收尾，未使用真实学生录音。测试不修改桌面现有绑定。学校白板实际麦克风和正式 HTTPS 仍需现场验证。

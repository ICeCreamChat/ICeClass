## 复现

需要 .NET 8 Windows SDK，以及安装了 `server/requirements.txt` 的 Python 环境。

```powershell
dotnet build tests/ReceiverOfflineChecks/ReceiverOfflineChecks.csproj -c Release
dotnet tests/ReceiverOfflineChecks/bin/Release/net8.0-windows/ICeClass.ReceiverOfflineChecks.dll
python -m unittest discover -s server -p "test_*.py" -v
python scripts/test-island-acceptance.py --dotnet dotnet --output output/island-lifecycle-new-run
dotnet run --project tests/DesktopChecks/DesktopChecks.csproj -c Release
npm run typecheck
```

生命周期输出目录必须是新目录。该测试会短暂显示原生设置、全屏测试和早读窗口，需要可交互的 Windows 桌面及 WebView2。

打包后验证：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package-release.ps1 -SkipBuild
python scripts/verify-release.py --version 2.4.0 --output output/release-2.4.0-verification.json
```

校验会检查 ZIP 内容和 CRC、分发包与更新清单的一致性，并在新进程中仅使用解压后的模块启动服务及教室岛路由，防止工作区模块掩盖漏装问题。

- 桌宠在真实对话中使用挥手、左右指引、点头、成功反馈、失败摇头和结束鞠躬。展开等候时可以探头、伸展和短暂打盹；平时贴边只短暂播放偶发小动作，静止和上课隐藏时停止逐帧绘制。沿用原形象与已修复的眼睛合成。
- 操作完成反馈只接收当前语音回合的实际终态，去掉重复通知，不把历史聊天或失败操作当作新成功动作。
- 修复新版 WPS 文字将主窗口与编辑器放在不同进程时无法定位文稿的问题。文稿仍绑定所选窗口，不通过全局活动文稿猜测目标；替换保留格式且不自动保存。
- WPS 放映统一使用绑定窗口的原生放映操作，避免连续开始、退出时 COM 查询与 Esc 干扰其内部运行；开始与退出根据放映窗口实际出现、消失回执。本机版本的页码仍需查看屏幕确认。
- 服务器更新脚本生成的教室下载包与本地教室包使用相同的安装入口和使用说明，包含旧版一次安装升级的提示。

## 整体验收范围

包含教室顶部悬浮岛、全天课表与默认作息、单双周和临时调课、循环值班、Excel 导入导出、保存下发与离线缓存、自动化和通知回执；同时包含教师工作台、早读、班班后台唤醒与连续语音、电脑及文件操作、桌宠和 Windows 教师端。

交付附件应包含教室端、Windows 教师端、完整 Windows 包及服务器包，并配套 Ubuntu 更新脚本与 SHA256 校验文件。本轮实际检查结果和未验证项以随候选提供的验收报告为准，不沿用旧版本的通过数量。

## 旧版升级

2.5.0 及更早版本仍限制 250 MiB 自动更新文件，不能直接接收本次包含完整语音模型的程序。必须先退出教室端，使用本次“安装或升级.cmd”完成一次安装升级；不能只更新服务器后等待旧版自动升级。安装到本次版本后，后续不超过 1 GiB 的程序可使用原自动更新流程。

服务器与客户端需要配套。学校升级仍需备份并保留账号、班级、绑定、连接设置和历史，不能用本地演示数据库覆盖正式数据。

## 使用边界

本地自动检查不能代替教室现场的远场收音、多人重叠语音、功放回声、真实识别准确率和第三方软件版本验收。电脑操作仍受 Windows 权限、目标应用接口、登录状态和遮挡影响；不能保证任意软件、任意命令都能自动完成。真人未重新测试的内容会在候选验收报告中明确标示。

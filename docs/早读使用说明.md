# 早读陪伴与比赛

## 管理员

“早读统计”是登录后的首页。ICe 展开“全校统计规则”，勾选启用，设置星期和时间、统计声量门槛并保存。教师、主任和校长都看不到这项后台设置，接口也拒绝读取和修改。

例如周一到周五 07:20—07:50，声量门槛 30：教师 07:05 打开也能使用，但只有 07:20:00 起到 07:50:00 前的活动计入。当某秒声量达到 30 且页面可见、正在运行，该秒累计一秒有效时长。暂停、低于门槛、隐藏页面和结束后的时间不增加有效成绩。

比赛时选择日期范围，比如“本周”，查看有效发声排名；按天展开每班的使用次数和完成量。“导出 CSV”下载同一筛选范围的数据。

“班级早读日历”按单个班级、年份显示全年记录，范围与上方排行榜的日期筛选独立。每格是一天，按有效发声时长使用统一的浅蓝色阶：不足 5 分钟、5—10 分钟、10—20 分钟、20 分钟及以上。没有软件记录显示浅灰；运行过但没有达标发声，显示浅蓝描边；未来日期不可选。点击格子或选择日期查看运行时长、有效发声、使用次数和完成量。可用方向键移动日期；手机上日历区域左右滑动。底部“原始明细”仍跟随上方日期筛选。

## 到点提醒怎么设置

1. ICe 展开“全校统计规则”，勾选“启用早读统计”和“到点提醒教室开始晨读”。
2. 选择星期与开始、结束时间，例如周一至周五 07:30—07:53，然后保存。可添加多个时段。
3. 已绑定、联网并运行新版 EXE 的白板，通常在 15 秒内同步规则；到点显示“晨读时间到了”，教师可选择“开始晨读”或“暂不开始”。开始会打开本班的陪伴页面，仍需教师选择模式并允许麦克风。提醒不会自动开始采音或形成成绩。
4. 选择暂不开始、关闭弹窗或重启程序，都不会在同一时段反复提醒；如果晚开机但仍在时段内，会补一次提醒。时段结束自动收起，错过的时段不再补弹。相接或重叠的时段合成一次连续提醒。关闭提醒开关不影响统计。

教室程序退出、电脑关机或断网时无法弹出提醒；联网恢复后重新核对当前有效时段。设备被停用后无法读取提醒规则。该功能需要同时更新服务端与教室 EXE，旧 EXE 不具备提醒功能。

时间统一按北京时间，包含开始时刻、不包含结束时刻。结束时间 `00:00` 表示当天 `24:00`；开始和结束都是 `00:00` 就是全天统计，不是关闭统计。跨夜时段拆成两段。当前本地演示库预设周一至周日全天；实际学校需由 ICe 改成需要的晨读时段。

规则只作用于后续上传的活动，不按新门槛重新计算已保存的历史成绩。保存规则也不会替教师启动软件或更改本地玩法目标。

目标、每颗萝卜/能量格的时长、诗词与粒子速度继续由早读陪伴的原本地操作面板设置，保存后刷新仍保留。平台后台不提供这些设置，也不会覆盖本地值。本地玩法的声量门槛影响动画推进；后台统计声量门槛单独判断有效发声，与玩法目标无关。

比赛不要求各班完成同一种目标，不以不同模式的完成个数直接比较。播放音量 30%/50% 是白板扬声器音量，与麦克风声量门槛是两项不同设置。

在“教室控制”可统一播放音量 30% 或 50%，以及远程打开在线教室的早读页面。

## 教师与学生

1. 从已经绑定班级的班伴教室首页点击“开始早读陪伴”，直接在客户端内全屏打开；托盘、晨读提醒和远程控制也使用同一入口。
2. 先选择模式和内容，点击开始。首次询问时允许麦克风，可勾选在本机记住选择；拒绝后可重新点击开始。
3. 看页面底部的班级名称、统计状态和本次有效时长。显示“当前不在早读统计时段”时仍可练习。
4. 可以暂停、换模式，在原操作面板设置玩法。白板长按屏幕空白处 2 秒退出全屏，按住时显示进度，松手取消；退出全屏不会结束早读，可点窗口“全屏”恢复。退出后点击“教室首页”才会停止采音并返回，通知连接继续。键盘 Esc 仍可用。比赛统计只采用 ICe 配置的时间范围和统计门槛。

管理网页的“预览早读陪伴”供体验玩法，预览活动不会计入班级成绩。直接打开未绑定的网页同样不会形成班级成绩，要从教室端打开。

## 数据怎么理解

| 数据 | 含义 |
| --- | --- |
| 有效发声 | 统计时段内、运行中且声量达标的累计秒数，是比赛排序依据 |
| 运行时长 | 统计时段内页面可见且正在运行的时间 |
| 达标占比 | 有效发声 / 运行时长，仅供参考 |
| 使用次数 | 在统计时段内产生运行数据的模式会话数 |
| 完成量 | 各模式内的萝卜、诗词、徽章、发射和能量格 |
| 未使用 | 没有软件记录，不能据此认定该班没有早读 |

声量只能近似表示参与，不能评价朗读的准确性。项目按约定接受设备差异，优先采用简单、统一的规则。

## 桌面版运行与更新

2.2.0 起，早读内容从平台加载并在班伴内显示，不再另开默认浏览器。Windows 10/11 64 位需要 Microsoft Edge WebView2，缺少时按窗口提示安装运行组件，再重新打开班伴。第一次使用须联网；本地验收连接 localhost，正式环境使用学校 HTTPS 地址。

粒子浮雕仅更换外层封面，直接显示去除方形底框后的原始徽章；内部粒子动画、深色场景和原操作方式保持原样。各模式的本机设置保存在当前 Windows 用户的客户端浏览器资料目录，更新 EXE 后继续保留。首次从外部浏览器切换到客户端时，原浏览器中的玩法偏好不会自动迁入。

# 班班操作与电脑控制

2026-10-27 更新：通用控件、多步任务、窗口回执及最新 8864 本地验收入口见 [班班通用电脑助手](班班通用电脑助手.md)。下文保留首次实现记录。

2026-10-25 本地实现，沿用 Python/aiohttp、原生 JavaScript 与 Windows/Avalonia 教室端。本轮没有更换框架，也没有部署正式服务器或提交 Git。原有 8857、8847 验收服务保留；本功能使用独立入口 `http://127.0.0.1:8860/` 和演示数据库。

## 现在可以做什么

| 范围 | 可执行内容 |
| --- | --- |
| 班级通知 | 发送文字通知、查询显示回执；禁言时段先人工确认 |
| 班级管理 | 创建、批量创建、更名、升班、启停、删除，以及清理指定范围记录 |
| 账号管理 | 创建、修改授权、启停、重置密码、删除；沿用原管理层级和班级范围 |
| 学校设置 | 修改禁言时段、晨读时段与门槛、教室岛配置；更新课表先读取原配置和版本 |
| 设备与记录 | 维护设备备注、绑定与启停，删除指定通知或来音记录 |
| 应用与窗口 | 查看允许的应用和窗口，打开应用，切换、最大化、最小化和关闭选定窗口 |
| 课件 | 在允许文件夹查找、打开课件；开始、结束放映，前后翻页和跳转页码 |
| 网站 | 打开 HTTPS 教学网址，控制选定浏览器的前进、后退、刷新、标签切换与全屏 |
| 文稿 | 读取支持的所选文稿，在确认后替换普通文字或保存 |
| 应用控件 | 读取选定窗口公开的可访问控件，确认后操作按钮或填写文字 |
| 教室 | 调整系统播放音量、打开早读陪伴、停止当前电脑操作 |

“整个系统”指平台已有业务及本机允许应用的这些操作。没有开放任意命令、脚本、SQL、坐标点击或任意组合键；未公开可访问控件的应用仍需人工操作。

## 使用方法

教师端打开班班，在“更多 → 连接设置”选用已有学校连接或个人连接。模型需支持流式回复和工具调用；本轮没有新增外部插件依赖。Vercel、GitHub 插件不承担教室电脑执行，实际执行由绑定的 Windows 教室端完成。

可以直接说：

- “给高一（1）班发一条重要通知：请带上数学练习册。”
- “把高一（1）班明天第三节改为数学，其他课不变。”
- “查看高一（1）班的电脑，打开允许文件夹中的函数课件。”
- “切换到刚才的 PowerPoint，从第 3 页开始放映。”
- “查看当前文稿，把‘一次函数’替换为‘二次函数’，先让我确认。”
- “把刚才选定的教室音量调整为 35。”

目标含糊或同一班级有多台电脑时，班班应先明确目标。窗口和控件编号只采用本次读取结果，过期后需重新查看。存在待确认步骤时，对话等待人工确认，收到实际执行结果后自动继续后续步骤。取消或确认过期后停止本轮后续操作。

聊天只提供自然语言对话。班班在后台核对设备、读取窗口、查找课件和控件，不提供手动电脑控制面板；更多菜单保持“新对话”和“连接设置”。涉及修改时显示具体目标与内容供人工确认，完成后给出核验过的结果。未启用有效模型连接时只提供数据速览，操作请求会明确说明未执行，不引导用户寻找不存在的控制入口。

### 教室电脑设置

在新版教室端托盘打开“班班电脑控制设置”：

1. 根据课堂需要启用电脑控制，以及是否允许操作。关闭“允许操作”后仍可查看窗口、课件、控件和文稿。
2. 核对自动识别的 PowerPoint、Word、Excel、WPS、浏览器和希沃。未识别的软件可在本机增加完整 EXE 路径；也复用教室岛已允许的应用。
3. 添加允许查找课件的文件夹。首次只采用已存在的“文档\课件”和“桌面\课件”，不会扫描整台电脑。
4. 保存后保持教室端在线。旧版客户端或未回报能力的设备会提示需要更新。

配置保存在 `%LOCALAPPDATA%\ICeClass\ComputerControl\settings.json`。应用白名单只允许启动 EXE，不接受模型传入启动参数。课件限定文档、图片及音视频扩展名；目录外文件、脚本和通过链接跳转到目录外的文件均拒绝。网站入口只接受无内嵌凭据的 HTTPS 地址。

托盘“停止班班电脑操作”可立即取消适配器。聊天中的操作卡和“停止”按钮也可停止当前任务。停止不会关闭教学应用或撤销已完成的输入。

## 权限、确认与回执

查询与操作分别校验权限。主任的全校分析权限不会扩大班级操作范围；账号管理仍受原有管理层级约束。执行前重新检查登录状态、角色、目标和设备当前绑定，不能通过模型参数扩大范围。

修改配置、删除数据、关闭窗口、保存、文字替换、控件点击和填写等操作先显示目标与内容，人工点击“确认执行”后才发送。确认默认五分钟过期；目标或配置已被其他操作改动时拒绝覆盖。修改密码和创建账号的密码只在确认卡内填写，不进入模型工具参数、操作记录或回执。

| 显示状态 | 含义 |
| --- | --- |
| 待您确认 | 还没有执行业务修改或电脑输入 |
| 正在执行 | 已发送到指定教室或进入业务处理 |
| 已完成 | 收到对应的可核验业务或设备结果 |
| 结果待确认 | 输入可能已发生，但未能核实实际效果 |
| 未完成 | 返回失败；文字说明原因和下一步 |
| 已取消、已过期 | 未执行的确认已取消或过期；运行中停止的结果另以回执说明 |

通知只有收到教室“已显示/已知晓”回执才算完成；送出消息不等于显示。快捷键只能证明输入已发送时，保持“结果待确认”。文稿替换不自动保存，修改后需要在应用中核对，再另行保存。

电脑命令只发给一台明确选定的设备，不向整个班级广播；断线不会排队或重连补发。服务端限制短有效期，客户端在产生效果前记录操作编号，重连、重启或重复调用不会重放同一指令。COM/UIA 在独立隐藏适配器中运行，卡住或取消时只结束适配器，不结束 Office、WPS 或浏览器进程。

窗口选择包含进程和窗口身份校验，控件还需匹配选定窗口。密码控件不参与读取；无法核对焦点或目标已关闭时拒绝输入。应用自己的未保存文档、登录或权限提示交由使用者处理。

## 实际兼容情况

### 指定文件回收（2026-10-28）

明确要求删除磁盘文件时，班班先从本机允许的文件夹查找，核对名称和相对位置，再将指定文件移到 Windows 回收站。文件编号只对应本次观察，执行前重新核对目录权限、文件大小和修改时间；不能通过猜路径删除文件，不提供永久删除、目录删除或批量清空。

明确的语音要求沿用直接执行，不再重复确认。若同名文件有多份，先问清目标；“删除文稿中的一道题”仍使用文稿编辑，不能误删整个文件。Office/WPS 中路径完全匹配且没有未保存修改的目标文稿可以正常关闭后回收；其他文稿保持打开。存在未保存修改、无法核实所属文稿、文件仍被占用或文件发生变化时停止并说明原因。

本轮仅在 8866 本地验收。手工验收沿用并实时重读本机文件权限；自动化检查仍使用独立测试文件夹。原用户文稿保留，由用户再次明确操作时验收。

### 访问本机所有文件夹

教室端默认开启“允许访问本机所有文件夹”，适用于每台教室电脑的新安装，以及旧设置中尚未包含该选项的升级。桌面、文档、实际下载位置、各磁盘和用户明确指定的绝对文件夹路径均在执行任务的那台教室电脑上解析，沿用该电脑当前 Windows 账号的权限，不依赖验收电脑的路径或配置，也不会更改 Windows 权限。若已明确保存为关闭，升级继续保留指定文件夹模式；可在托盘“班班电脑控制设置”的“文件访问”中调整，关闭后恢复原先保存的指定文件夹列表。关闭电脑控制或设为只读的选择仍然有效。

`inspect` 的 `fileAccess` 和 `fileLocations` 回报实际范围与位置；`folders` 同步回报位置名称。`list_files(folderPath, query, recursive, offset)` 将位置与文件名分开：空查询或 `*` 浏览本层，返回文件与子文件夹；有名称查询默认搜索子目录，可明确指定是否递归。每页最多 80 项，继续使用 `nextOffset`，单次最多检查 5,000 项；未覆盖全部范围时如实回报 `searchIncomplete`，需要缩小位置继续搜索，不能宣称全盘查无此文件。

全局模式可列出普通文件的全部类型；`canOpen` 表示是否能作为现有文档类型打开，文件浏览不会执行脚本或命令。打开与回收继续使用刚观察到的文件编号；执行时再次检查当前范围。回收仍只处理明确指定的单个普通文件，不增加永久删除、目录删除或批量清空。

本机实际检查版本：Microsoft Office `16.0.19426.20218`，WPS `12.1.0.28505`。测试只创建和操作本轮临时文稿，关闭时不保存测试修改；未关闭用户原有应用或改写用户文档。

| 应用 | 实际结果与范围 |
| --- | --- |
| PowerPoint | 选定文稿读取、普通文本框替换、粗体保留；放映开始、前后翻页、页码跳转和结束均验证实际页码；编辑不自动保存 |
| Word | 选定文档正文读取与文字替换，保留原格式，不自动保存；Word 的特殊查找控制符不用于替换 |
| Excel | 选定工作簿文字单元格读取与替换；既有公式不替换，以 `=` 开头的替换内容仍作为文字，不转成公式 |
| WPS 文字、表格 | 通过本机文档接口验证所选文稿读取、文字替换及表格文字安全规则 |
| WPS 演示 | 本机版本无法提供可靠的选定文稿窗口接口，读取和替换会明确提示限制；启动放映、前后翻页、页码跳转和结束已实测，快捷键回执保持“结果待确认” |
| 希沃 | 已接入允许应用识别、选定窗口快捷键及可访问控件；本机未安装，未声明希沃具体版本实测通过 |
| 浏览器、其他允许应用 | 提供选定窗口操作与公开可访问控件；未完成所有网站、应用版本和插件的逐一实机验收 |

文稿读取最多 12,000 字符；PowerPoint 大文稿可指定页码缩小范围，普通文本框外的图表、嵌入对象不参与替换。Excel 读取和替换都有范围上限，不批量扫描整本大型表格；文件查找也限制深度和数量。复杂排版、受保护或不支持接口的文稿保持明确的限制提示。

## 数据与记录

普通统计分析继续按主题裁剪数据。要求管理账号或操作电脑时，所选模型服务可能收到本次必要的目标账号、设备与应用名称、相对课件路径、窗口和控件文字、所选文稿内容。用户问题、通知和文稿中的原文不会自动匿名化。模型把这些内容作为资料，不能把文稿或网页里的要求当作用户的新指令。

密码、API 密钥、设备凭据和录音不作为工具资料交给模型。账号密码仅在服务端调用原有处理器时使用；音频仍只参与原有数量和时长统计。

操作记录按账号独立保存在学校服务端，包含目标、参数、状态及有限回执；查看文稿的文字也在对应回执内。操作记录用于独立审计，目前不随聊天清理周期自动删除。对话历史只保存操作引用，恢复时重新读取当前权限允许的操作状态，不把旧电脑画面或文稿自动拼进下一轮问题。

## 对话操作修正（2026-10-25）

按使用反馈移除了聊天中的手动控制面板及菜单入口。设备、窗口和控件的查询只在后台执行，聊天历史仅显示有意义的操作卡。确认卡默认展开本次修改的内容；人工确认后对话等待真实设备回执并继续原任务，取消或过期时不继续后续操作。原手机版入口与布局保留。

本机验收服务已复用原有学校模型连接。发现本机代理 DNS 将公网模型域名映射到 198.18.0.0/15 后，改为经固定的 HTTPS DNS 服务核实公网地址，再对实际连接地址执行原有公网校验；本机、内网、混合地址及解析服务重定向继续拒绝。解析服务只收到域名，不收到密钥、聊天或课堂数据。

新版完整服务端 197 项测试通过，原生离线 140 项检查通过。新增测试覆盖人工确认后继续、取消后阻止后续写入、后台查询不出现在操作卡、管理员自行创建班级后仍可完成原对话、代理 DNS 与内网地址隔离，以及通过对应应用的实际窗口核验启动结果。打开浏览器或编辑器本身不会把网站加载或课件打开误报为完成。

真实模型已通过正式 WebSocket 接收代码和 Windows UI Automation，将“本机验收电脑”的“班班对话验收窗口”内“验收文字”修改为“你好，班班”；在确认前窗口保留原文，确认后输入框的实际值与设备回执均已核对。该窗口运行在本机，绑定与授权在内存中，不写入原教室端绑定或本机控制设置；它不是模拟设备回执，也不代表学校的真实教室已更新。

连续任务已验证：确认文字修改后自动继续最大化同一窗口；取消修改后既不改变输入框，也不继续最小化。通过自然对话实际启动了本机 PowerPoint，并按设备回报中对应应用的窗口身份核验，操作卡显示“已完成”。这里只证明应用窗口已出现，不表示已经打开课件或进入文档编辑界面。

最新检查证据位于 `output/banban-control-20261025/dialogue/`、`dialogue-server-tests.log` 和 `dialogue-native-tests.log`。此前 Office/WPS 兼容性检查沿用上文的实际范围，不重复计为本轮新增实测。

## 对话界面精简（2026-10-25）

班班的回复、思考状态、停止与重试提示共用左侧头像和浅色气泡；用户消息保留右侧蓝色气泡。消息中不再重复作者与模式标签。等待只显示一条状态，进入人工确认后由操作卡直接表达待确认状态。原字体、字号和手机版窗口布局保留。

普通回复取消最低字数要求，简单操作优先用一句话说明实际结果。工具执行前的过渡文字在进入工具调用后清除，不进入最终回复与保存的历史。已完成操作收成默认折叠的单行记录，完整目标、参数与设备回执在展开后查看；待确认的内容与影响、失败原因、取消和结果待确认状态仍直接显示。精简依靠回复规则与内容分层，不截断回执或伪造完成。

本轮完整服务端 198 项测试通过，新增回归覆盖工具过渡文字清除、最终文字逐段流式输出及历史只保存最终结果。浏览器检查覆盖桌面 949×871 和手机 390×844：实际模型回复、Windows 验收输入框回执、确认与取消、停止与重试、历史恢复、键盘展开详情与焦点。隔离交互页另外验证长目标、失败、结果待确认、模拟轮询保留输入及确认失败后的恢复；这些模拟回执不计为真实电脑操作。未改动原生代码，未重复原生与 Office/WPS 测试，未更新学校正式服务。

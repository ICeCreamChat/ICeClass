# 2.5.18 · 2026-11-24

## 纸卡课堂

- 开课盘、“更多”、课堂工具及阅读页底弧沿用相同的外圈边距。切换菜单、显示收答进度时，扇面位置保持稳定。
- 收答时点“待收”查看缺少的卡号，点“全班”核对所有卡。需要设置本轮免答时，先点进卡号明细，再点该号码。封存后可以回看本轮记录。
- 手机扫白板发出的课堂二维码即可参与收答。老师可在圆环上方查看取景，也可收起画面继续扫码。
- 教室端支持用 `ICeClass.exe --paper-classroom` 直接打开纸卡课堂。重复打开同一入口会唤回原圆环。需要使用另一个班时，可在命令末尾指定该班已有的白板绑定文件。

操作步骤见[纸卡答题指南](纸卡答题.md)。

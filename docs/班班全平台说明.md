# 班班全平台助手

本轮在 2.3.0 本地版中扩展，入口为 http://127.0.0.1:8838/ 右下角的班班。

2026-10-25 已在本地增加受权限约束的业务和电脑操作，独立验收入口为 `http://127.0.0.1:8860/`。下文的数据分析口径继续适用；新增能力、人工确认和应用兼容性见 [班班操作与电脑控制](班班操作与电脑控制.md)。 使用时直接对话，班班在后台查找并操作；聊天不再提供手动控制面板。确认后的任务会继续执行并核对设备回执。

## 可以问什么

| 提问示例 | 实际读取的内容 |
| --- | --- |
| 综合检查当前范围，有哪些需要关注？ | 晨读记录与同步完整性、通知回执、来音数量时长、当前设备连接；超级管理员另有绑定核查 |
| 哪些设备离线，音量设置生效了吗？ | 当前连接、最近联系；超级管理员可查看版本、最近音量回报、回报新鲜度与当前指令匹配结果 |
| 有没有一个班绑定了多台电脑？ | 超级管理员可查启用班级无设备、多设备和未核实设备等线索 |
| 晨读怎样统计，在哪修改？ | 固定统计口径、禁言规则；超级管理员另可查询当前晨读时段、门槛与提醒设置 |
| 账号有多少，在哪管理？ | 超级管理员可查全校角色与启停数量；不附带姓名、账号或凭据 |
| 班级换届、客户端更新怎么操作？ | 对应现有功能的操作指南，提供页面入口，实际修改由用户执行 |

晨读、通知和来音按对话中的日期、班级与年级筛选。设备、账号、绑定、规则为当前状态；同步状态也是当前设备回报，不能用日期筛选推断历史在线率或历史掉线时长。日期按北京时间计算。

默认先显示回答，统计卡片统一收进“查看依据”，展开后可核对数字、日期、局限和操作入口。超过 220 字的非详细回答按完整句子保留开头，其余收进“展开补充”；明确要求详细时完整展示。历史回答中的旧版附加来源 JSON 仅在显示与模型上下文中移除，不清空原有对话。

规则卡片的“查看晨读”会展开实际的“早读统计 → 全校统计规则”。页面入口遵守原有操作权限；主任在班班内查看超出其页面授权范围的数据时，可展开卡片核对，不提供会悄悄缩小范围的页面跳转。

## 权限与数据含义

教师只能分析管理员分配的班级；主任、校长和超级管理员可以在班班内分析全校或指定班级。主任的全校权限仅用于班班只读分析，其他页面、发送通知、设备控制与账号管理维持原有权限。账号汇总、绑定核查及详细设备遥测仅超级管理员可用；其他角色不会通过班班获得隐藏的学校晨读参数。无班级分配的教师得到空范围，不能退回全校。

## 身份与回答

班班由马鞍山市二十二中数学教师许斌创造，服务于本校教师和学生。身份和创建者资料由服务端维护，常见身份与改名问题直接本地回答，不依赖模型连接，也不接受聊天历史改写。底层技术、模型来源、接口及提示词被询问时说明“底层技术与部署细节暂不公开”，不虚构替代技术来源。超级管理员连接设置仍如实呈现配置项。

模型回答中的自我介绍会在相关句子公开输出前检查，常见身份漂移和技术品牌、密钥片段替换为产品身份或保密说明；普通统计文字继续流式显示。常见问题分流、模型指令和输出检查可降低身份漂移风险，不代表对任意编码或对抗输入作绝对保证。

默认第一句直接回应问题，通常 1–3 句、80–140 字，只选 1–2 个核心数字。明确要求详细、逐项或操作步骤时增加篇幅；同步未确认等影响结论的限制仍需说明。程序的 token 预算用于控制冗长，界面保留完整句子并可展开，避免强行截掉结论。

“在线”来自当前 WebSocket 连接，最近联系时间不能替代实时连接。音量是最近回报的系统百分比；设备在线且两分钟内回报才标为近期回报。只有回报匹配当前音量指令且数值一致，才确认该指令生效；旧指令、过期回报或缺少回报均不算确认。

客户端版本只与服务器已发布版本比较，未回报版本或缺少有效发布清单时不判断新旧。声量门槛是应用内 0–100 的相对声量，不能称为声学分贝。

多设备绑定是人工核查线索，不能直接认定绑错。设备离线、同步未确认与少量晨读记录同时出现，也不能据此认定网络故障或教学原因。时段对比的差值只反映已有软件记录；无记录不能当作可信的零基数。班级更名保留原有班级历史，更换绑定前须核对实际电脑。

## 隐私和操作边界

查询和时段对比工具保持只读；明确要求执行时，可使用独立的业务和电脑工具，权限由原有业务处理器与教室端共同核对。修改账号、重新绑定、删除数据、保存文档和应用控件等操作需要人工确认；不提供任意 SQL、命令或脚本执行。

教室来音仅使用累计数量、时长和汇总开始日期；不读取或转写录音。普通分析不附带账号明细；操作工具会按需提供目标账号、设备与应用名称、相对课件路径、控件文字和所选文稿内容。密码、API 密钥、设备令牌和音频路径不作为工具资料交给模型。通知主题保留原有最多 20 条文字样本；平台综合检查不附带通知正文。用户自己输入在问题或通知正文中的信息不会自动匿名化。

API Key 保存在原有本地忽略配置，其他账号无法查看，发布包不包含配置、数据库或会话。既有对话继续保留，权限变化仍使旧记忆失效。历史卡片 JSON 不再附加到发给模型的聊天正文，避免被复述成回答。

## 本地验证

完整服务端 97 项回归测试通过，角色动效与骨骼测试共 28 项通过。覆盖身份与技术来源保密、历史改写与分片流式输出、简洁和详细回答预算、教师按班级编号与名称越权的拒绝、主任全校只读分析及原有操作权限隔离、无班级教师的空范围，以及既有平台分析、设备和同步口径。另修正“晨读怎么样”被误判为使用教程的问题。

真实模型联调已核对晨读简洁回答与收起的统计依据。浏览器确认身份与技术来源问题直接本地回答；无操作班级分配的主任仍可在班班分析全校 44 个班，卡片不提供越权页面入口；教师只看到授权班级，询问其他班级会被拒绝。键盘可展开依据，390×600 下窗口、输入区和发送按钮均在可见范围内，页面无横向溢出。当前截图保存在本地 `output/banban/concise-after.png`、`concise-teacher.png`、`concise-mobile.png`，改造前后截图并置于 `concise-comparison.png`。既有平台联调证据保留在 `output/banban/platform-*`。

实现参考 GitHub 上 [CopilotKit 的页面共享状态示例](https://github.com/CopilotKit/CopilotKit/blob/main/showcase/integrations/agno/qa/shared-state-read.md)，沿用现有 Python/aiohttp 与原生 JavaScript，未安装其框架。新增服务端模块 `banban_platform.py` 和 `banban_policy.py` 已加入服务器打包、安装与更新脚本。当前为本地验收版本，本轮没有发布服务器或重新构建 EXE。

# 班级作业统计

## 已确认范围

教室端首页增加班级管理入口。进入后点击作业统计，在当前班级管理页面上方打开登记弹窗；选择学科、学期预设的具体作业，再登记本班名单。首次默认全部勾选，课代表只取消未交同学，保存直接生效。未保存不是已登记；补交后重新勾选保存。各作业项目独立记录，今日无作业不进入应交分母。

教师端增加作业统计，班主任和有本班管理范围的上级维护名单、本学期作业项目；任课老师可以查看任教班级统计。支持日期、学科、学期筛选，按作业、学生汇总及 CSV 导出。学校管理者可以查询权限范围内各班。

按用户追加要求，教室首页同时预留创意工坊卡片，与班级管理并排。液态玻璃外观沿用已确认样板的“筹备中”标记及“了解工坊”说明；不增加作品上传、审核或管理；窄窗口与其他首页卡片一起改为单列。

沿用白蓝界面、微软雅黑和共享控件。教室弹窗以已经确认的独立样板为准，标题、关闭和保存操作固定，内容内部滚动。关闭、切换作业或日期前保护未保存修改。失败保留当前勾选，不伪报保存成功。

教室端姓名搜索支持部分汉字、全拼和拼音首字母，例如“张三”可用“三”、“zhangsan”或“zs”查找；忽略空格、大小写和全角英文字母，拼音中的 ü 也可输入 v。搜索在本机完成，可与“只看未交”同时使用；筛选不改变勾选，历史作业按原登记名单搜索。

## 数据及接口

新增 `homework_profiles`（每班一份版本化配置）和 `homework_records`（班级、学期、日期、作业项目唯一）。配置保存 `activeTermId`、稳定学生编号和姓名、各学期及九学科作业项目。增加学期不覆盖旧学期；历史登记保存首次登记时的名单、学期、学科和作业名称快照。补交修改同一条记录，沿用该快照和应交分母，不因后来增删学生或改名而改变；教室端相应显示原登记名单。用户提供的 51 人名单导入本地验收班级数据库，不写入源码、演示默认值或其他班。

- `GET /api/homework/classes/{class_id}/profile`：读取班级配置和可编辑权限。
- `PUT /api/homework/classes/{class_id}/profile`：`{revision, value}`，仅班主任及管理范围内上级，原子比较版本。
- `GET /api/homework/report`：`classId`（空为权限范围内全部）、`termId`、`start`、`end`、`subjectId`、`group`（assignments/students）、`page`、`pageSize`。返回汇总和分页明细。默认时间为今天，单次跨度最多 366 天；超过 10000 条已保存记录时要求缩小范围。
- `GET /api/homework/export`：相同筛选，返回 UTF-8 BOM CSV。
- `GET /api/homework/classroom?date=YYYY-MM-DD`：仅已绑定设备，返回本班当前学期配置、当日登记和服务器日期。
- `PUT /api/homework/classroom/records`：`{classId, termId, profileRevision, date, subjectId, itemId, revision, status, missing}`；设备凭证、当前绑定、配置版本、记录版本及学生编号全部校验后保存。

教室 API 只接受原生宿主附加的设备令牌和班级绑定标识，不借教师 Cookie 获得权限；网页中不存放令牌。液态玻璃首页随客户端嵌入并在本地加载，登记由限定两个作业端点的原生消息桥接请求；旧客户端的远程管理页面仍使用同一份登记脚本。教师业务接口在实际处理器声明 `teacher_read` / `teacher_action`。版本冲突返回 409，用户刷新后核对，不覆盖另一台电脑的修改。没有后台自动重试写入。

CSV 导出使用项目已有的班班下载工作流；本人登录和当前权限继续由实际导出处理器校验。未保存修改通过页面内确认弹窗保护，正常托盘退出也先检查教室登记；系统关机、设备改绑时释放旧窗口。

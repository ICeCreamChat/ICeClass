# 教室端 2.5.8：立即更新

2026-11-03。

## 修复

- 将更新后启动标记的保护限定在程序启动入口，避免整个会话中的“立即更新”被直接跳过。
- 用户主动检查更新后，下载、校验完成便启动安装助手，退出旧程序并自动打开新版；已下载的更新无需再次下载。
- 自动下载继续遵守课间限制。手动操作不受课表未知或上课状态限制；早读、录音、对话、电脑任务和资源下载正在进行时给出明确提示。
- 显示安装状态、禁止重复点击；失效的安装计划会显示错误并允许重新检查。记录手动请求、下载就绪和安装助手启动，便于后续排查。
- 安装助手固定使用系统 Windows PowerShell，避免继承 PowerShell 7 的模块路径后无法校验文件。
- 两端启动入口均调整了共享安装保护；本次正式发布仅升级教室端，教师正式版本仍为 2.5.6。

## 本地验证

- 更新公共检查 70 项通过，包含真实 Windows PowerShell 安装、失败回退、配置和语音文件保留，以及带更新启动标记的会话再次安装。
- 教室端检查 186 项通过，新增隔离子进程验证：已就绪时立即安装、手动下载后直接安装、自动打开新程序、再次打开仍为新版，并保留绑定、偏好与语音资源。
- 手动与自动更新活动检查 23 项通过，包含上课边界及录音期间暂停。
- 原生更新界面检查 30 项通过，覆盖下载、校验、就绪、安装状态、重复点击限制、键盘焦点、无障碍状态和 760/640 像素窗口。
- 教师端检查 220 项通过；两端构建无警告、无错误。教室轻量及完整发布程序文件版本为 2.5.8.0。
- Impeccable 本次涉及界面扫描未发现问题，沿用原字体和布局。

以上安装验证使用隔离的本地程序和替代新版本，不代表学校 Windows 10 电脑已实际安装成功。线上部署与下载核验另记于本机发布目录。

## 旧版一次性升级

2.5.6/2.5.7 中已存在的按钮缺陷无法通过服务器改文件直接修复。可先从托盘真正退出并重新打开，让已下载更新在启动时安装；也可解压本次轻量包运行“安装或升级.cmd”，保留原教室绑定与资料。升级到 2.5.8 后，手动更新会直接完成安装和重开。

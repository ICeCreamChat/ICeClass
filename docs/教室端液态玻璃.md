# 教室端液态玻璃

2026-11-05 内页接入与最新验收入口见 [教室端内页液态玻璃](教室端内页液态玻璃.md)。以下保留首页接入时的范围和验收记录。

## 视觉依据

以用户确认的 `iceclass-classroom-glass-preview.html` 样板为准。正式页面直接继承其 HTML 结构、CSS、蓝白曲面背景和玻璃光学算法；移除样板演示工具条，显示实际班级、学期、课程和登记数据。字体保留 Microsoft YaHei UI、Microsoft YaHei、Segoe UI。

- 正文 `#193c59`、辅助文字 `#4e6c83`、操作蓝 `#0064d7`。
- 四模块两列，窄窗单列；日期和全天课表保持双胶囊。
- 模块圆角 28px，登记弹窗 30px；窄窗 24px。文字及按钮沿用样板字重、尺寸和间距。
- `assets/classroom-glass.js` 只变形独立背景层，文字与控件不变形。SVG 位移图只在尺寸变化时生成，最大 760×560；无持续折射计算或背景动画。
- 默认液态玻璃，设置内可切换白色、降低透明度。设置保存在按服务、设备、班级隔离的 WebView2 本地配置中。
- 减少动态效果、减少透明度和高对比偏好继续使用样板对应样式。

## 功能与边界

`StudentVoiceWindow` 复用已有 WebView2，嵌入页面位于 `web_controller/homework/classroom/`；资源由已有的 `ReadingLocalAssets` 解包。首屏可离线打开，不从线上下载首页。早读、创意计划、班班、绑定、关于和浮岛调用原方法；录音仍由 NAudio 负责，不向网页开放麦克风权限。设备令牌始终留在原生端。

作业统计在班级管理上方打开模态弹窗，继续使用真实名单、按学期预设项目、首次默认全选、补交覆盖同一记录、无作业排除分母、历史名单快照、版本冲突和未保存确认。关闭主窗口收到托盘时保留登记；正常退出先检查未保存选择。登记弹窗打开或保存期间阻止自动更新。

首页课表与临时喊话复用 `ClassroomIslandService` 的当前状态，通知结束后恢复课表。“已知晓”校验消息序号后交给原通知处理器，避免确认已经换掉的消息。创意工坊保持筹备说明，没有作品提交功能。

样板里的姓名、日期与课程不作为正式默认数据。正式改动没有新增依赖，没有更改教师端共享原生样式，没有提交、推送或部署。

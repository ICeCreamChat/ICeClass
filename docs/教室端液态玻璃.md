# 教室端液态玻璃

教室端从 2.5.13 起使用轻量静态材质，优先保证教室测试机的流畅性。内页范围见 [教室端内页液态玻璃](教室端内页液态玻璃.md)；文末早期验收记录只代表当时版本。

## 视觉依据

以用户确认的 `iceclass-classroom-glass-preview.html` 样板为准。正式页面保留其 HTML 结构、CSS 和蓝白曲面背景，玻璃效果改为静态轻透材质；移除样板演示工具条，显示实际班级、学期、课程和登记数据。字体保留 Microsoft YaHei UI、Microsoft YaHei、Segoe UI。

- 正文 `#193c59`、辅助文字 `#4e6c83`、操作蓝 `#0064d7`。
- 四模块两列，窄窗单列；日期和全天课表保持双胶囊。
- 模块圆角 28px，登记弹窗 30px；窄窗 24px。文字及按钮沿用样板字重、尺寸和间距。
- 教室网页不生成 SVG 位移图、Canvas 纹理或实时背景模糊。`assets/classroom-glass.js` 仅为动态内页应用静态材质，教师端从 2.5.14 起同样不再生成光学贴图。
- 默认液态玻璃，设置内可切换白色、降低透明度。设置保存在按服务、设备、班级隔离的 WebView2 本地配置中。
- 减少动态效果、减少透明度和高对比偏好继续使用样板对应样式。

## 教室测试机的外观与诊断

首页尚未保存外观时遵循系统的减少透明度偏好；“教室设置 → 液态玻璃”是明确的外观选择，会同时取消旧的“降低透明度”，立即恢复玻璃并记住选择。原版白色和手动降低透明度仍可单独使用；系统高对比度始终优先，减少动态效果只停止动画，不取消玻璃。

浮岛采用静态渐变、轻微透明度和一层柔和阴影，保留双胶囊、展开和喊话几何。不再启动 Windows Graphics Capture、D3D11 背景取样、折射计时器或额外模糊窗口；没有等待采样成功才显现玻璃的阶段。原生教室内页同样不再使用折射滤镜，教师原生内页从 2.5.14 起采用同类静态材质。

“关于 → 诊断日志”保留实际外观、选择来源、Windows 透明效果、高对比度和桌面合成、WebView2 版本、页面实际滤镜与视口，并明确记录“轻量静态”、背景采集关闭、实时折射关闭和模糊窗口为零。页面快照按刷新读取，有两秒超时，不读取页面正文或学生姓名。开发机的合成窗口和浏览器检查不代替教室显卡、驱动和实际大屏验证。

## 功能与边界

`StudentVoiceWindow` 复用已有 WebView2，嵌入页面位于 `web_controller/homework/classroom/`；资源由已有的 `ReadingLocalAssets` 解包。首屏可离线打开，不从线上下载首页。早读、创意计划、班班、绑定、关于和浮岛调用原方法；录音仍由 NAudio 负责，不向网页开放麦克风权限。设备令牌始终留在原生端。

作业统计在班级管理上方打开模态弹窗，继续使用真实名单、按学期预设项目、首次默认全选、补交覆盖同一记录、无作业排除分母、历史名单快照、版本冲突和未保存确认。关闭主窗口收到托盘时保留登记；正常退出先检查未保存选择。登记弹窗打开或保存期间阻止自动更新。

管理摘要使用当天数据。日期变化、返回班级管理或页面恢复可见时检查日期；编辑、保存及未保存确认期间延后刷新，关闭登记后恢复当天摘要。历史登记继续使用所选日期，手动刷新摘要读取当天；失败保留已有数据并显示错误，后续可重试。同日浮岛更新不重复请求。

首页课表与临时喊话复用 `ClassroomIslandService` 的当前状态，通知结束后恢复课表。“已知晓”校验消息序号后交给原通知处理器，避免确认已经换掉的消息。创意工坊保持筹备说明，没有作品提交功能。

样板里的姓名、日期与课程不作为正式默认数据。正式改动没有新增依赖，没有更改教师端共享原生样式，没有提交、推送或部署。

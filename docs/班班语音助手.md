# 班班语音助手

2.5.0 包含后台“你好班班”唤醒、连续对话、真实任务执行、分句语音反馈、打断和取消。Windows 教室端内置唤醒、SenseVoice 整句识别、中英神经语音、语音活动检测与说话人比对；班班对话已替换原来的 Windows 系统播报声音。GitHub 交付与学校部署分别执行，学校使用前需部署配套版本。

2026-10-27 新增[班班桌宠](班班桌宠与响应速度.md)：可直接在桌面点击说话、拖动停靠、双击打开对话，右键停止操作或暂停语音。

## 第一次使用

1. 学校服务端和教室端需使用配套版本。升级时保留原班级绑定、本机设置、账号与历史。
2. 单击桌宠，或从教室首页“班班”及托盘“班班语音助手”打开窗口，登录有权管理本教室的教师账号。
3. 沿用班班已有的学校连接或教师个人模型连接，模型需支持流式工具调用；无需另填语音 API 密钥。
4. 点击输入框左侧麦克风，看到“等候‘你好班班’”即可关闭窗口。教室端保持运行时，在托盘也能唤醒；后续开机恢复后台待机。登录过期需重新登录。

需要 Windows 10/11 x64、WebView2、默认输入麦克风和扬声器，以及 Windows 对桌面应用开放的麦克风权限。模型随包携带并校验后解压到本机用户缓存，首次准备需要几秒，不依赖首次联网下载。班班对话无需安装 Windows 中文声音包；普通通知仍可使用系统声音。断网时本地唤醒、识别与停播仍可工作，平台查询和新任务需要网络及可用的模型连接。

本地开发验收使用独立演示数据库和文字窗口，不连接学校正式数据。

## 直接说话

| 说法 | 行为 |
| --- | --- |
| “你好班班” | 回答“我在，请说”，开始听安排 |
| “打开数学课件” | 查找允许的课件；多个同名文件时先澄清 |
| “打开 Word 文档”“Open PowerPoint” | 支持英文软件名与中英混说；应用仍需已安装并在允许范围内 |
| “下一页”“音量调到四十” | 对话期间无需重复唤醒，默认目标为已校验的本教室 |
| “把这个窗口里的标题改成今天的作业” | 查找允许的窗口和控件，按这次明确要求直接修改并核对结果 |
| “确认执行”或“确认这项操作” | 有当前唯一、未过期的待执行卡片时确认该操作；明确语音任务直接执行 |
| “班班停一下”“等一下”或“别念了” | 停止播报和本轮后续自动播报，继续听安排 |
| “班班取消操作”或“取消操作” | 取消本轮等待中的任务，向正在运行的电脑操作请求停止 |
| “再见班班” | 结束连续对话，回到待机 |

待机只运行本地关键词检测，不转写课堂谈话。连续对话空闲 90 秒回待机，正在处理或播报时不按空闲退出。说“停一下”只停止声音；电脑任务仍按真实回执显示。已完成的动作不会被取消回滚，未拿到回执不会声称完成，也不自动离线补做。

“好的”“嗯”“知道了”等简短接话不会替换正在处理或等待确认的任务，也不会视作同意。待确认时仅补充一次简短确认提示。语音回答默认先给结果、用一两句话说明；需要详细讲解时可以直接要求展开。问候不主动重提旧任务，数学与普通知识问题直接回答，涉及校园实时数据或实际操作时仍核对工具与回执。

不必先选择中英文。最终识别可能使用英文大写，原文内容仍按识别结果提交；比较回声和重复话语时忽略字母大小写。口头确认继续使用表中的中文明确短语。识别含未知词或损坏字符时，班班简短要求重说；原生、网页及服务端均拒绝将这类不完整话语提交为任务，不删除未知部分后猜测执行，也不因此取消已有的待确认操作。

Windows 回声消除与 Silero 语音活动检测均可用时，可以在班班播报中直接说新的完整安排。新话语先停止播放，保留当前识别的开头，整句结束后再交给任务引擎；不会仅凭有人声就执行。播报中的确认词不会自动确认，请等播报停止后重新说“确认执行”。回声消除不可用时保留停止、取消和唤醒口令，普通插话不启用。现场效果不佳时，先说“班班停一下”再安排。

口头确认绑定当前任务、参数、账号和有效期，超过 45 秒需要重新听取提示并确认。密码仍由教师在窗口填写。没有声纹识别，唤醒后的其他人声也可能被麦克风收到；实际教室需检查误唤醒及旁人插话。

## 能做的事情

复用[班班操作与电脑控制](班班操作与电脑控制.md)中的权限与工具：通知、统计、课表、允许的应用与课件、放映翻页、教学网站、文稿、普通可访问控件、系统播放音量及早读入口。软件没有可访问控件或不在允许范围时，班班说明限制。

语音绑定只提供默认教室，不扩大教师班级权限。服务端每次核实教师会话、设备启用状态和实际归属。改绑需重新打开对应教室的授权会话；锁屏、注销、休眠暂停采音并请求停止，恢复后只在有效会话中待机。更换默认音频设备会重建采集、回声参考和播放，回到待机，不重放旧指令。

## 声音与资源

| 环节 | 本地组件 |
| --- | --- |
| 唤醒 | sherpa-onnx wenetspeech 3.3M 关键词模型 |
| 中英识别 | SenseVoiceSmall INT8 整句识别，模型及词表约 228.45 MiB |
| 语音活动检测 | Silero VAD v5，约 2.2 MiB |
| 回声消除 | Windows Voice Capture DSP，同步默认麦克风与扬声器参考 |
| 班班播报 | MeloTTS 中英 VITS 神经语音，CPU 推理，单一女声 |

神经语音包约 152 MiB，解压约 169 MiB。未把不使用的词典、研究模型或云端语音框架放入产品。模型由教室电脑运行，CPU 较慢时首句生成可能延迟；本机性能数据不能代表所有教室电脑。默认使用最多两个合成线程，已缓存唤醒回应。

教室端启用 .NET 单文件压缩后，当前 EXE 为 500.97 MiB；未压缩构建为 615.79 MiB。2.4.0 的 EXE 为 206.39 MiB，当时尚未携带这套本地识别和神经声音；上一个双语流式识别 2.5.0 候选 EXE 为 480.54 MiB，本轮净增 20.43 MiB。这里均比较 EXE，不能将旧版 ZIP 的 99.89 MiB 与新版 EXE 混比。清理实验缓存不会减掉当前离线语音需要的模型。

识别模型固定到维护者提交 `2365baeacb507f821a0c8120fcee3d484dba7a07`，准备脚本 `scripts/prepare-banban-asr.py` 校验 SHA-256 并移除被替换的 Zipformer 文件，只保留一套 ASR 模型。普通麦克风取消固定三倍放大。Silero VAD 配合约 800 ms 开头缓冲和 1.25 秒尾静音等待保留完整句子；最多保留 30 秒，超长安排要求重说，不截取前半句执行。语言自动检测，保留默认文字规范化，避免对照中出现的英文百分数单位漏词。

整句推理使用独立线程，最多两个 CPU 推理线程和两个排队片段；关键词唤醒、停播与取消不等待整句模型。播报期间最多用一次短预览判断新话语，实际任务仍等待整句终稿。回声消除可用时，临近播报结束开始说的话也保留开头；延迟终稿仍记录原本在播报中采集，不能冒充播报后的明确确认。取消、重新唤醒、停播、退出或会话代次变化后，旧的在算结果和排队音频不会变成新任务。SenseVoice 不支持直接套用此前的 Zipformer 热词配置，未将近音字替换或大模型猜测冒充准确转写。

服务端等待当前上游回合完整结束、确认没有工具调用后，直接复用该回合的答案并按句发送给播放队列，不再额外请求模型重写一次。工具规划草稿和未完成的回复不朗读；问候和感谢可直接简短回应。答案需等待该回合生成完成才开始播报，长答案的首句仍有等待，不能等同于逐字生成时同步播报。停止会同时丢弃待合成、待播放和晚到的旧句子；句子序号缺失或流结束异常时停播并保留文字。

常见代数公式在送入语音引擎前单独转换，屏幕和历史保留原公式。支持四则运算、明确的括号、下标、平方与立方、一般幂、带明确范围的平方根、比较符号和 LaTeX 分式；字母按读音播报，不让声音模型跳过单独的 n、S 或 Unicode 下标。公式内部的换行不会提前截断播报。超出支持范围的标记公式提示看屏幕，不猜测积分、矩阵或未识别记号的含义；这不是通用数学朗读引擎。

音频只在有界内存队列中处理，不写入或上传麦克风录音。最终识别文字进入原有班班会话、历史和模型连接，任务记录仍在学校服务端。播报期间的短预览只用于打断判断，未完成的普通话语不提交。开发验收可记录本地识别文字、音量和状态，正式应用默认不保存这类诊断。

服务端仍是现有 Python/aiohttp 任务引擎，没有新增 GPU、音频转发或常驻语音模型服务。2 核 2G 服务器不承担上述语音模型推理；全校同时调用文字模型和执行任务的容量仍取决于网络与模型供应商，本轮未做全校并发压测。

网页教师端麦克风使用浏览器支持的 SpeechRecognition 与 speechSynthesis，隐藏页面后暂停。新版本地神经语音和真正的后台唤醒运行在 Windows 教室端。

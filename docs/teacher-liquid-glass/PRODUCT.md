# ICeClass 教师端产品范围

本文件记录正式教师端液态玻璃改造所依据的既有产品事实，来源为仓库 README.md、docs/Windows教师端.md、已确认样板和本轮用户要求；不扩展业务范围。

ICeClass 班伴是班级伴学与管理平台。教师和学校管理员通过网页工作台维护早读统计、作业统计、课表浮岛、班级通知、教室来音、控制、创意计划、班级、用户及平台设置，并使用班班助手。Windows 教师端承载同一工作台，增加桌面来音、本机设置、语音资源、反馈、关于和更新入口。教室端是独立使用场景。

教师和管理员的可见功能、班级范围和操作权限来自既有授权。此次改造保留登录、校验、确认、状态反馈与真实数据行为；菜单深度按现有实现覆盖，不新增业务路由或放宽权限。

用户已认可完整教师端交互样板，并于 2026-11-06 授权正式实现。界面延续蓝白液态玻璃、微软雅黑、清晰小字、同类操作一致和浅色玻璃按钮配深蓝文字。折射作用于背景，正文、图标与输入保持清晰；桌面与窄窗口都应可操作。

本地验收使用仅监听 127.0.0.1 的独立演示服务及既有演示数据库。演示班级和成绩不代表学校真实资料。本轮不提交、不推送、不部署线上，不自动发送通知、反馈或诊断，不调用真实 AI 或麦克风。

# ICeClass 教师工作台

## 范围与目标

访问者模式为 Operate：教师查阅班级情况、调整规则、发出通知并处理待办。沿用蓝白、微软雅黑和班班形象；让可操作内容清楚、同类控件对齐。适用于正式教师网页和 Windows 教师端内嵌工作台，包括班班网页面板。教室首页和原生悬浮岛分别维护自己的规范。

当前实现以 [工作台材料](../../web_controller/teacher-liquid-glass.css)、[顶部导航](../../web_controller/teacher-header.css)、[页面结构](../../web_controller/index.html)、[外观偏好](../../web_controller/teacher-appearance.js)和[静态材质运行时](../../web_controller/assets/classroom-glass.js)为准。本目录历史提取样板记录的是此前的全玻璃版本，不能代替当前代码或验收结果。

## 材料

默认外观为液态玻璃。蓝白背景、顶部导航、账号菜单、筛选、统计、课表编辑、自习监测、表格和班班正文使用一致的冰蓝玻璃。大内容面板以约 40% 不透明度的冰蓝底色叠加很轻的静态高光，白色细边与轻微下投影表达层次；从 2.5.14 起取消背景模糊和饱和度滤镜。背景曲线降低亮度，避免穿过正文时显得刺眼。

每张表格只使用一层外部玻璃，内部滚动区和行不再叠加模糊或白底；表头略实，行分隔线清淡，悬停有明确反馈。输入框约 86% 不透明度，普通按钮半透明，主操作使用较深的蓝色玻璃渐变并保持白字对比。粘性课表工具栏和弹窗使用更实的冰蓝材料，防止背后的内容干扰阅读。文字、图标和焦点不参与折射。

顶部导航、临时浮层、内容面板、表格和按钮均使用静态材质，不分配位移图或背景滤镜。玻璃模式与原版白色模式共享同一几何、间距和交互，不通过改布局表达材料差异。

“账号设置 → 工作台外观”提供液态玻璃、原版白色和降低透明度。白色模式使用浅灰白画布、白色导航与面板，不显示装饰曲面、折射和模糊。外观保存在当前浏览器或桌面 WebView 的本地存储，同一来源的已打开页面会同步；不写学校配置，不改变其他设备。

偏好键为 `iceclass.teacher.appearance`，版本为 1。读取失败使用默认值；保存失败仍应用选择，并明确告知下次需重新选择。页面在样式和正文解析前应用偏好，避免已选白色时先闪过蓝色背景。

## 布局和文字

顶部保留品牌、当前位置、连接状态和账号操作。宽屏保留侧栏，880px 及以下使用已有导航抽屉。不同模块共享页面标题左基线，标题为 28px；760px 以下收为 26px。模块名称、权限组织及业务入口保持既有含义。

普通操作和字段高度为 44px。筛选字段、日期快捷项与查询按钮共用底基线；分段控件外层 44px、内部选项至少 36px。标准内容面板内距 24px，窄屏 20px；面板圆角 16px，字段和按钮 10px，弹窗 20px。

不靠给每个模块增加说明文字来解释布局。保留必要的权限、同步、保存失败、未保存修改、AI 额度、照片有效期和破坏性操作提示。状态不能仅用颜色区分。数字与时间使用等宽数字。

自习管理使用紧凑的标题、班级选择和保存区。当前运行状态与处理流程独占上方一行，下方以较宽的识别规则和较窄的监测选项组成等高两列，窄屏按相同阅读顺序排列。常用规则直接展示，灵敏度使用原生单选分段；AI 额度仍折叠。底部集中呈现最近七天的待核实与已处理记录，晚自习安排通过具名弹窗查看并进入原有周课表编辑。页面底部与焦点滚动为悬浮班班留出操作空间。

流程高亮只反映已保存配置与教室端的最新同步状态，未保存的开关不充当运行状态。AI 暂停时，桌面和窄屏均保留声波继续显示的说明。状态文字、照片时效、保存失败、版本冲突和离开确认沿用真实业务；轮询时不重建未变化的记录，避免打断键盘操作。

### 账号设置

账号设置分为“账号与安全、工作台外观、班班次数、教室电脑、应用致谢、客户端日志”六个工作区，一次显示一个主内容面板。个人设置与管理设置分组，入口按当前账号权限显示；窄内容区以具名原生选择器替代分区链接，额度、设备和日志按可读列表排列，保留身份、状态、操作和键盘入口。班班沿用原有悬浮入口、提醒气泡和交互，允许覆盖设置内容；分区导航靠左紧凑排列。

外观即时预览；次数和致谢切换分区时保留草稿，并明确保存。次数区分别管理教室设备与教师账号，将默认规则与个别例外分开；行内“确定调整”暂存修改，底部“保存更改”提交。失败和版本冲突保留草稿，重新载入、退出和刷新保留未保存保护。设备绑定、停用和删除沿用具名对话框与返回焦点；日志保留筛选、分页、可关闭详情和失败反馈。

本页沿用现有字体、44px 控件、共享焦点与单层静态冰蓝面板。批准样板的局部透明度和面板内距只作用于账号设置，不改变全局令牌；白色、降低透明度、减少动态效果和强制颜色保持同一结构与操作。实现见[账号设置样式](../../web_controller/account-settings.css)、[分区与设备交互](../../web_controller/account-settings.js)和[次数交互](../../web_controller/banban-quota.js)，行为回归见[账号设置](../../scripts/test-account-settings.cjs)与[班班次数](../../scripts/test-banban-quota.cjs)。

## 内容、交互与无障碍

表格在自己的区域横向滚动，班级、通知记录、设备和用户表均保留键盘入口与可访问名称。小屏不把整行字段挤成碎字；用户搜索独占一行，筛选项成对对齐。长名称和动态内容应能换行或截断，并保留可访问的完整内容。

班级管理的表头、班名、状态、教师数、连接时间和操作组共用列中线，行内垂直居中，年级分组名称靠左。列宽按内容职责分配，操作按钮保持 44px 最小高度并在一行居中；表格最小宽度 1040px，窄屏通过具名滚动区域查看完整列。设备、教室控制及用户表的状态、数字和操作列保持表头与内容居中；用户身份列的表头与实际角色标签组共用中线，多身份换行后每行仍居中。设备最近连接的时间和“从未连接”保持单行，由表格滚动区承接宽度。设备身份、权限范围等较长说明保留左对齐。

早读排行与原始明细、作业统计、通知记录、客户端日志、年度升班和作息编辑沿用同一规则：日期、名次、次数、时长、完成量、学生姓名、状态、选择项和操作与对应表头居中，长班名、作业名称、通知正文及设备说明保留左对齐。作业明细行在垂直方向居中，按作业汇总至少 1100px，班级和作业名称保留合理列宽；长内容通过表格区域滚动查看，避免被挤成单字。按钮和状态标签的左右内距须为内容留足空间，不能因固定列宽而向一侧溢出。

外观使用原生单选和复选控件；键盘可切换，选中和焦点均可见。现有弹窗继续使用浏览器模态语义、Esc 及返回焦点。浮岛编辑的粘性工具栏避让顶部导航。分页、保存、刷新、录音、照片查看和权限边界沿用真实业务逻辑。

玻璃只绘制在独立背景层，文字、表单值、图标和焦点从不参与折射。支持减少动态效果、减少透明效果和强制颜色。辅助偏好影响材料，不改变操作是否可用。

## 性能约束

两端共用静态材质脚本。顶部导航、菜单和动态浮层只添加现有材料类；不创建 Canvas 纹理、SVG 位移图、光学 ResizeObserver 或材质动画循环。表格、弹窗、原生选择器浮层、导航遮罩和浮岛预览均不使用背景模糊。

白色、降低透明度、系统减少透明效果和强制颜色仍改变底色、边框与对比度，不再需要释放或重建光学资源。窗口隐藏与恢复均不会重新分配材质贴图；业务轮询仍遵循现有可见性门控。

不新增 UI 框架、字体下载或生产依赖。项目是原生外壳和原生网页脚本，不采用 React 专属组件或 Hook 优化。独立数据请求、分页、隐藏页轮询门控和已有 DOM 保留策略继续工作。

账号信息与基础刷新不等待辅助列表全部返回。网页读取设置 15 秒超时，保留调用方取消与明确的失败重试；不对写入自动重试。浮岛编辑器在首次进入该页时载入，复用页面 CSP nonce，载入失败后重新进入可重试。原生来音与晚自习收件箱各自按 10 秒间隔串行轮询，彼此独立，保留各自的请求超时与会话校验。

班班保留原形象、眨眼、视线、回应及拖动反馈。交互和工作状态按原节奏绘制，空闲过渡结束后保留已绘姿态并停止持续绘制；新交互、可见性恢复和尺寸变化按需唤醒。页面隐藏和减少动态效果继续停止动画。

全校早读规则的未保存修改保护页面切换、退出账号和窗口刷新。确认层沿用具名原生 dialog 及共享样式，提供继续编辑、放弃修改和保存并继续；保存失败保留草稿，保存期间避免重复写入。窄屏导航抽屉的键盘处理让位于当前模态弹窗。

## 原生辅助窗口

Windows 桌面设置、来音、确认和自习通知等 Avalonia 窗口继续使用已有 TeacherStyle、DesktopStyle 和 ClassroomGlassHost。原生共享背景按几何缓存静态蓝白场景，不再为面板绘制折射或模糊层；网页外观偏好仍只控制内嵌工作台，不改变原生窗口的 Windows 系统透明开关绑定。原生字段、焦点、取消和执行结果按各自窗口验证。

## 验证方法

[页面回归](../../scripts/test-teacher-appearance.cjs)覆盖两种外观、三个宽度、标题基线、键盘切换、本地保存失败、跨页同步、静态材质零贴图、零背景滤镜与系统偏好。其他教师、自习、课表、班班和教室页面测试覆盖实际业务关键路径。

[性能脚本](../../scripts/measure-teacher-ui.cjs)使用隔离 API 数据、同一 Edge 和视口重复测量。贴图数量、像素量、主线程时间和资源使用应与改前数据比较；这是本机实验数据，不能称为真实用户 Core Web Vitals 或真实教室设备验收。

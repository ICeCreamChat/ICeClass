# ICeClass · 班伴部署与使用

当前本地验收版本 2.2.1。完整平台使用 Python 国内服务器版；原 Cloudflare 通知实现不包含新增功能。本轮先完成本地验收，正式服务器尚未更新。

## 一、准备新平台

准备一个已解析到服务器的专用域名（支持 `iceclass.icecreamchat.top` 这样的子域名）、Ubuntu Server 24.04 LTS 服务器，以及服务器登录账号。腾讯云安全组允许 TCP 22、80、443。正式页面必须通过 HTTPS 使用，浏览器的麦克风权限依赖 HTTPS。

不需要重装正在使用的旧平台服务器。班伴使用自己的系统服务、目录和 8865 本地端口；如果共用服务器，使用独立域名并保留原服务的目录和数据库。

新平台默认新建数据库。已有平台的数据迁移是另一个操作，不会自动读取或覆盖旧平台数据库。

## 二、安装方式

### 方式 A：从源码一键部署

在管理员 Windows 电脑上下载 `ICeCreamChat/ICeClass`，例如放在 `D:\ICeCoding\ICeClass`。安装 .NET 8 SDK，并确保 Windows 的 OpenSSH 客户端包含 `ssh.exe`、`scp.exe` 和 `tar.exe`。

双击 `deploy-tencent-server.bat`，依次填写新域名、服务器公网 IP、SSH 用户名和管理员密码。脚本构建教室端、打包网页与早读素材、上传、安装 HTTPS 和服务、初始化 `ICe`、生成 `dist\delivery` 交付目录。

脚本会识别已部署的班伴平台，更新时保留其数据和账号。若域名已经指向其他平台，脚本要求换用独立域名。

### 方式 B：从服务器发布包安装

使用本地生成或验收后发布的 `ICeClass-2.2.1-server.zip`，上传到服务器并解压。进入解压后的 `ICeClass-server` 目录。生成一个至少 32 位的随机初始化密钥，执行：

```bash
sudo bash server/install-ubuntu.sh YOUR_DOMAIN YOUR_RANDOM_BOOTSTRAP_TOKEN
```

安装完成后访问 `https://YOUR_DOMAIN/`，在首次初始化页面输入刚才的初始化密钥，设置 `ICe` 密码。部署包没有默认正式管理员密码。

服务器安装包内的 `receiver_release/ICeClass.exe` 与 `manifest.json` 用于教室端自动更新；应一起更新。服务端沿用已有更新文件完整性校验。

## 三、服务器位置

| 内容 | 位置 |
| --- | --- |
| 程序 | `/opt/iceclass/app` |
| Python 环境 | `/opt/iceclass/venv` |
| 数据库和临时语音 | `/var/lib/iceclass` |
| 数据库每日备份 | `/var/backups/iceclass`，保留 14 天 |
| 服务配置 | `/etc/iceclass.env` |
| 系统服务 | `iceclass.service` |
| 本地监听 | `127.0.0.1:8865`，通过 Nginx 转发 |

```bash
sudo systemctl status iceclass
sudo journalctl -u iceclass --no-pager -n 80
```

不要把数据库、正式设备 `config.json`、初始化密钥和账号密码上传到公开仓库。

## 四、班级、教师和教室绑定

1. 使用 `ICe` 登录新平台，在“班级管理”创建班级，或批量创建连续班级。“创建预设44班”准备高一 16 班、高二 14 班、高三 14 班，已有班级自动跳过；以后可按实际数量增减。
2. 在“用户管理”创建教师、主任或校长账号。教师和主任分配一个或多个班级；校长自动拥有全校范围，也能查看以后新增的班级。
3. 在“班级管理 → 全校快捷绑定”开放全校码 `mas22`，选择有效天数。各班使用同一码、自行选班级，无需逐班生成；可随时关闭快捷绑定，已绑定设备继续使用。单班一次性码（15 分钟）仍是备选。
4. 解压 Windows 发布包，把整个 `教室端` 文件夹复制到普通用户可写的目录，例如 `D:\ICeClass`。
5. 双击 `ICeClass.exe`，正式平台网址已内置。填写全校码，点击“读取班级”、依次下拉选择年级和本班，再点击“绑定并开始陪伴”。2.2.3 起绑定资料保存于 `%LOCALAPPDATA%\ICeClass\Receiver\config.json`，设备令牌继续由 Windows DPAPI 保护。旧版配置首次迁移成功后自动移走，不要提前删除。
6. 首次运行会创建“班伴教室端”桌面快捷图标，同时显示系统托盘图标。点窗口“×”只收起到托盘，通知连接继续；再次双击桌面图标打开已有窗口。要真正退出，请使用托盘菜单“退出”。默认支持开机后台连接，从首页或托盘打开早读。

源码部署后运行 `prepare-delivery.bat`，会生成教师端入口和教室端使用说明。2.2.3 起正式平台网址已内置，正式分发包无需 `cloud-url.txt`；部署到其他平台时仍可指定自定义 HTTPS 地址。

若将旧接收器替换在同一目录，可保留现有配置；它仍会连接配置中保存的原网址。要加入新的独立平台，应退出旧程序，在新目录运行班伴并用新平台重新绑定。单独安装班伴不会删除其他目录的旧平台自启动项。

### 四种身份

| 身份 | 班级范围 | 可用功能 |
| --- | --- | --- |
| 教师 | ICe 授权的班级 | 早读统计、排名、通知和教室来音 |
| 主任 | ICe 授权的班级，可授权整个年级 | 对应范围的早读统计、排名、通知和教室来音 |
| 校长 | 全校，自动包含新班级 | 全校早读统计、排名、通知和教室来音 |
| 超级管理员 ICe | 全校 | 以上全部功能，以及统计时段和声量门槛、账号权限、班级及设备管理 |

只有 ICe 可以创建、停用、删除账号，修改身份或授权范围。教师、主任与校长都看不到后台全校统计规则。身份变更后该账号需要重新登录，已有统计与通知记录保留。用户管理中点击“身份与权限”即可修改，ICe 自身不会出现在可停用或删除的用户列表里。

### 升班与电脑归属

- 单班更新：在“班级管理”点击“升班 / 更名”。同一届学生升班时直接更名，原班级编号、教师授权、设备绑定和历史记录都保留。
- 年度更新：点击“年度升班”，可预填高一→高二、高二→高三、高三→指定年份毕业班；检查并勾选后一起保存。多个年级可同时更新，名称冲突时整批不会部分保存。毕业班保留绑定，如不再使用可停用；新一届学生另建班级。
- 换教室：在“账号与设备 → 教室电脑”点击“核实 / 改绑”，选择该电脑实际所属的班级，填写位置备注并勾选已核实。在线客户端重连后自动同步新班级，不需要重新输入绑定码；该电脑此前的成绩仍归原班级。
- 同班多台：后台提示“同班 N 台 · 请核对”，查看电脑名称、设备识别编号、局域网地址及系统版本，与教室端显示的编号核对。编号标识绑定设备，电脑名和地址帮助定位。同名电脑或同一局域网地址不能单独作为唯一身份依据。
- 停用/删除：停用设备立即断开，可重新启用；删除设备撤销身份，重新使用需绑定。删除班级会一并清除其授权、设备和记录，需要输入完整班级名称确认。清理记录可选择类型及日期范围。

## 五、早读规则与比赛

ICe 打开“早读统计 → 全校统计规则”：

1. 勾选启用统计，选择星期、开始和结束时间。时间固定为北京时间。可以设置多个时段，跨午夜时段拆成两段；结束 00:00 表示当天 24:00。
2. 设置统一声量门槛，范围 5—90，默认 30。数值是软件相对强度，不是校准分贝。
3. 保存后已打开的教室页面约 15 秒内同步统计规则。

平台后台不管理玩法参数。目标、时长、动画速度和影响玩法推进的门槛继续在早读陪伴的原本地操作面板设置，刷新后保留；这些本地设置不改变后台统计时段和统计声量门槛。

比赛按所选日期的有效发声秒数累计排名，相同秒数并列。运行时长只包括统计时段内、页面可见且正在运行的秒数；达标占比是有效时长除以运行时长。未使用表示没有本平台记录，不据此判断学生有没有早读。

使用次数指在统计时段内实际产生运行记录的模式会话；切换模式或新开一轮可形成新会话。同班多个窗口的时长合并去重，使用次数和完成量保留各会话记录。完成量是过程信息，不把不同模式的萝卜/诗词/徽章直接相加作为比赛分数。

比赛没有必须达到的统一总目标，也不自动识别文章正确率。早读检测只上传时间、相对声量和完成事件，不上传原始麦克风音频。

规则修改从后续上报生效，已经累计的成绩保留。一次比赛期间建议保持同一套规则。

## 六、远程白板控制

`ICe` 在“教室控制”选择单班或“全部启用班级”，点击“设为 30%”“设为 50%”或输入 0—100 后应用。这里仅包含绑定了启用设备的班级；正式平台不会生成演示白板。它改变 Windows 默认播放设备的主音量，0% 同时静音；其他值取消静音。

离线班级会保存期望音量，重连后应用。设备回报实际音量和应用状态；若本地有人调整，后台显示当前音量变化，管理员可以重新应用。它不调节麦克风增益。

“在教室打开早读”需要教室在线，客户端仍需要允许麦克风。白板外接独立功放的物理旋钮不由软件控制，第一次部署时在真实设备上检查 30%/50% 是否满足需要。

## 七、原有通知和维护

“班级通知”保留文字、原声、普通/重要/紧急显示；“教室来音”接收学生留言。教师只能操作授权班级；管理员可维护班级、设备、禁言时间和教师账号。历史记录支持删除和导出。

更新服务器时再次运行部署脚本，或安装新版服务器包。系统会保留 `/var/lib/iceclass` 中的数据，接收器从自己的平台后台下载新版。教室端日志位于 `%LOCALAPPDATA%\ICeClass\logs\receiver.log`。

验收项目与本地演示账号见 [验收指南](验收指南.md)。


教室端自动更新、新版发布、后台班级名单变动后的刷新和测试范围见 [客户端更新说明](客户端更新说明.md)。

## 客户端内的早读空间

2.2.1 点击“开始早读陪伴”直接在班伴内全屏显示，隐藏两层顶栏并铺满显示器。托盘、到点提醒和远程打开使用同一窗口，重复打开会回到已有早读页面。没有键盘时，长按屏幕空白处 2 秒退出全屏，进度圆环会提示；松手、移动、双指触碰会取消，按钮和滑块不会触发退出。退出全屏不会结束早读，窗口中的“全屏”按钮可以恢复。键盘 Esc 仍可用。退出后顶部“教室首页”停止采音、提交剩余统计并返回，通知服务继续运行。

运行于 Windows 10/11 x64，需要 Microsoft Edge WebView2 Evergreen Runtime（多数电脑已有）。缺少时有安装入口；安装后重新打开班伴即可。网页内容和班级名单由学校平台提供；今后网页变化可随平台更新，原生功能仍通过 EXE 自动更新。

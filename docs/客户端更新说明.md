# 教室端绑定与后续更新

本文说明教室端绑定和客户端更新。2.5.2 的发布包增加文件级更新计划与 Windows MSDelta 差分；打包完成不代表已经上线，正式版本以部署验收为准。首次安装可下载完整离线[教室端](https://iceclass.icecreamchat.top/download/ICeClass-classroom.zip)或 [Windows 教师端](https://iceclass.icecreamchat.top/download/ICeClass-teacher.zip)。更新保留本机班级绑定与玩法设置。

2.3.0 把四种活动和媒体内置到 EXE，统计保存本机、联网补传，并支持更新断点续传。正式服务器及两端发布文件已在 2026 年 10 月 18 日更新；现有账号和设备绑定保留，详见 [2.3.0 发布记录](发布记录-2.3.0.md)。

2.2.4 优化了首次打开的资源体积，增加连接超时与触摸重试，修复等待时页面发白和活动被禁用的问题；主页按屏幕工作区适配，显示完整 Windows 窗口按钮。发布与公网验证结果见 [2.2.4 发布记录](发布记录-2.2.4.md)。

## 首次绑定

输入平台网址和全校绑定码，点击“读取班级”，依次选择“年级”和“本教室所属班级”，再点击“绑定并开始陪伴”。两个选择框均支持鼠标和键盘操作；切换年级后需要重新选择班级，避免误绑。

学校初始预设为高一 16 班、高二 14 班、高三 14 班，共 44 班。本地验收已准备这些班级；正式平台可由 ICe 在“班级管理”点击“创建预设44班”。已有班级会跳过，不覆盖编号、设备绑定、教师授权和历史，也不会自动删除额外班级。

## 班级数量或名称变化

ICe 在后台创建、批量创建、升班、更名或停用班级。教室端的名单来自平台，未在 EXE 中固定班级数量。在绑定页点击“刷新班级”，即可读取最新的启用班级。例如后台新增高一（17）班后，高一下拉列表会增加该班，无须重装 EXE。

刷新时，仍然有效的班级按原编号保留选择；已删除或停用的班级会失去选择，必须重新核对。班级按班号排序，例如 2 班排在 10 班前。已有的其他名称教室可在“其他班级”中选择。

已经绑定的电脑不用每次开机重新选择班级。年度升班和更名保留原班级编号，在线设备同步新名称；更换归属时，ICe 可在后台“核实 / 改绑”操作，不必逐班重装程序。

## 发布客户端新功能

管理员完成验收后，将新版本的服务端发布包部署到平台。版本号必须高于已安装版本；同版本不会反复安装，旧版本不会覆盖较新版本。包内两套文件需要完整保留：

- `receiver_release/ICeClass.exe` 与 `manifest.json` 继续提供嵌入全部语音资源的完整程序，供离线安装和旧客户端过渡使用；现有“安装或升级.cmd”仍安装这个完整程序。2.5.0 及更早教室端有 250 MiB 自动更新上限，超过上限时须先用完整安装包升级。
- `receiver_release/update-plan.json` 的第一项是精简的 `ICeClass.exe`，其后将 `Receiver/Assets/Voice/` 下的全部原始语音文件映射到 `VoiceResources/`，包括各级 manifest、模型及 TTS 分片包。`desktop_release/update-plan.json` 只有 `ICeClass.Desktop.exe`。两端各自在 `payloads/{sha256}` 保存全量文件与可用补丁，不把精简核心当作完整离线 EXE 分发。

计划格式为 `{ "version": "项目版本", "files": [{ "path": "相对路径", "size": 123, "sha256": "目标文件SHA256", "deltas": [{ "sourceSha256": "旧文件SHA256", "size": 45, "sha256": "补丁SHA256" }] }] }`。未变化的文件保持相同 SHA256，新客户端校验并复用本机资源，无须重新下载。补丁仅适用于 `sourceSha256` 匹配的旧文件；没有适用补丁时取目标文件的全量 payload。精简核心必须与计划内的 `VoiceResources` 一起安装，不能只手动替换这个 EXE。

在 Windows 上运行 `build.bat`，会先校验语音资源，再分别生成 `dist/receiver/ICeClass.exe`（`EmbedVoiceResources=true`）和 `dist/receiver-core/ICeClass.exe`（`EmbedVoiceResources=false`）。每次构建、每个变体使用独立的 .NET 8 artifacts 目录，避免共用 obj 导致 full/core 串包；既有绑定和配置文件不会因构建被删除。两个客户端的发布版本分别从原有 `.csproj` 的 `Version` 读取。

`scripts/package-release.ps1` 默认构建两端并打包。使用已验收的产物时传 `-SkipBuild`，也可加 `-DistributionDirectory` 指定包含 receiver、receiver-core、desktop 的目录。可选 `-PreviousServerDirectory 'D:\Releases\previous\ICeClass-server'` 指向上一版解压的服务端根目录，其中两端都应有 `update-plan.json` 和 `payloads/`。脚本对同一路径的变更文件调用系统 `msdelta.dll` 生成 RAW 补丁，先用 ApplyDeltaW 还原并验证目标 SHA256，只有补丁小于全量文件才列入计划；验证失败会中止打包。未提供前版仍生成完整可用的文件级计划，`deltas` 为空；首次旧完整 EXE 过渡到精简核心不要求生成旧完整 EXE 的补丁。

2.5.2 起，两端后台只在课间空闲时下载。教室端沿用本机同步的真实课程；早读、录音、创意窗口和班班对话期间暂停。教师端登录后读取授权班级的课程状态，主窗口使用中、录音或对话期间暂停；无法确认课时的情况下暂缓自动下载。教室端启动后随机等待 2–15 分钟，空闲时每 30 分钟检查；课堂开始时取消当前传输，保留断点，之后课间重试。

下载校验完成后只显示“已就绪”，继续运行当前程序，下次真正启动时再安装。关闭到托盘不算退出，也不会触发安装。需要主动安装时，在托盘或更新设置里选择“立即更新”；教师端会提示先保存页面内容。安装重新打开后，班级绑定、登录资料、配置和本机数据保留。替换前重新校验目标文件，安装使用恢复日志；新版未确认启动时恢复旧文件。

两端均从当前学校平台下载更新，校验版本、文件大小、SHA256 与补丁还原结果。旧完整教室端升级到精简核心时，先从自己的内置资源提取、校验模型，无须重复下载相同模型；资源发生变化时才下载对应文件。完整离线安装包仍包含全部模型，不依赖首次启动下载。2.5.1 及以前客户端继续沿用旧更新逻辑，需要先升级到支持新协议的版本，后续才能使用上述增量与等待安装机制。

班级绑定、设备身份、桌面图标和开机启动设置保留。2.2.3 起，正式绑定资料保存在 `%LOCALAPPDATA%\ICeClass\Receiver\config.json`，不随分发目录复制到其他电脑。旧版相邻的 `config.json` 在首次启动时验证、迁移成功后自动移走；迁移失败则保留原文件继续使用。断网或下载失败时继续使用原版本，下次从断点继续。

2.3.0 的未完成下载保存在 EXE 同目录的 `.updates`，重新启动后也可续传。服务器不支持续传时会重新下载，文件完整校验通过后才安装；服务端更新包变化时不会混用旧下载片段。早读资源与统计分别保存在 `%LOCALAPPDATA%\ICeClass\ReadingAssets` 和 `ReadingData`，不要删除待补传数据。新增或修改玩法需要发布新版客户端，单独修改服务器网页不会替换已内置的活动；学校时段、统计门槛和班级名单继续由服务器同步。

若程序位于不可写目录，请将 EXE 移到普通用户可写的固定位置，例如 `D:\ICeClass`；2.2.3 迁移完成后的绑定由同一 Windows 用户自动读取。尚未运行新版迁移的旧客户端，要先保留原 `config.json` 完成迁移。不要把其他电脑的绑定资料复制过来，每台新电脑各自选择并绑定所属班级。

## 2.3.0 本地验收范围

实际 Windows WebView2 离线、跨进程补传与活动中暂停更新 23 项，本机磁盘与更新续传 19 项，服务端 41 项，浏览器四模式、触摸布局与连接恢复共 64 项检查通过。新增接口只接受已绑定设备身份；测试覆盖重复补传、历史规则、跨天归属、改绑后的原班记录和管理员清理后不被迟到记录恢复。详细范围见本地验收说明。触摸由 Chromium 输入协议模拟，麦克风使用模拟音源，学校白板触屏硬件和实际网络仍需现场验证。正式部署与后续增加的验证见发布记录。

## 2.2.1 全屏早读

全屏时隐藏客户端和网页的两层顶栏，内容占满显示器。没有键盘的白板，长按屏幕空白处 2 秒即可退出全屏，按住时显示圆环进度，松手、移动或双指触碰会取消；按钮、滑块等控件不触发长按退出。退出全屏后早读继续，可再次点击“全屏”恢复；点击“教室首页”才会结束采音并返回。键盘 Esc 仍然可用。

模式选择页统一浅蓝色按钮、等高卡片和清晰中文字体。封面继续使用原始徽章，内部粒子动画和玩法保持原版本。Windows 10/11 x64 需要 WebView2 运行组件；缺少时会提示安装，EXE 自带 .NET 运行环境。

客户端本机玩法设置位于 `%LOCALAPPDATA%\ICeClass\Reading`，按平台和设备分开保存；更新程序保留该目录。旧外部浏览器中的玩法偏好不会自动迁入新客户端，可在各模式原设置面板重新设置一次。班级绑定从 2.2.3 起迁入上文的本机数据目录，不需要重新绑定。

正式平台网址已内置，无需 `cloud-url.txt`。四份完整应用许可和第三方说明已嵌入 EXE，可在系统托盘菜单“关于班伴”查看。分发包不携带设备配置。

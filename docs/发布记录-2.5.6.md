# 2.5.6 验收与发布记录

## 本轮行为

- 两端“关于”增加离线更新记录与诊断日志。支持刷新、复制、导出 ZIP，以及手动提交近期脱敏日志。读取按需进行，关闭窗口取消未完成操作。
- 自动上报错误和必要环境状态，每分钟合并为有界批次。未确认批次保留同一个编号，服务端幂等保存；脱敏后的待发数据保存在本机，重启后继续重试。
- 待发错误绑定当前教师登录或教室绑定。切换账号、改绑后不发送旧身份的记录；同一教室重连保留积压错误。身份文件只保存身份摘要，不保存 Cookie 或设备令牌。

- 服务端按设备 Bearer 或教师登录与 CSRF 鉴权，读取完报告后再次核对身份。设备请求不回退教师 Cookie；普通教师及教室模式不能读取汇总日志。
- 上海时区每周一 03:00 起，在原每小时维护任务的首次执行时，删除超过 7 天的客户端诊断。维护周次保存在数据库，停机后补做当周清理。另有 64 MiB 正文或 2000 条的存储上限，用于限制错误风暴；不清理业务记录。

真实原生窗口验证了通知首显、隐藏后再次显示、已显示时重复通知、人物帧回调、重绘和通知条变化。当前电脑上 Windows 动画已开启，未复现学校大屏“两部分都静止”的现场问题。

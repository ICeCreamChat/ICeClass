# 午间静校与晚自习循环值班

用户于 2026-10-24 确认实施：午间和晚自习分别配置循环周数、第一周周一，按循环内各周填写学科与教师。当前仓库没有采用 OpenSpec，沿用本方案记录已经确认的范围。

## 使用方式

教室浮岛设置增加“值班安排”，分为“午间静校”和“晚自习”。两组独立设置 1-20 周循环及第一周周一。选择循环周后按天填写学科和教师；可只填教师，学科为空时显示对应值班名称。地点默认本班教室，特殊地点在折叠选项中填写，不要求先创建教师账号。晚自习默认每天填写一次、应用到两节；已有分节差异则显示“分节安排”，统一前提示确认。支持复制其他循环周。

作息时段沿用现有列表：晚自习复用学校已有两节；午间静校由老师选择已有时段，或填写学校实际起止时间新增，不猜测时间。改变时段和缩短周期时提示受影响内容，确认后仅移除对应排班；停用循环保留内容。

循环从所选周一开始，按自然周连续计算，节假日不会自动暂停或改变周序。个别日期换老师、换学科或取消，用现有“临时调课”；该日期的调整优先于循环，循环优先于普通周课表。循环接管的时段不能同时保留固定周课表，避免两套安排冲突。循环开始前不产生值班，空格不生成虚构教师或课程。

白天课程继续使用原有每周、单双周设置。高一（9）班照片只提供 40 节白天课，不包含教师、午间时间或值班名单；这些字段不编造，值班默认停用。

## 实现范围

在现有 JSON 配置中增加 `dutyRotations`，包含 midday、evening 两组。每组包含 enabled、cycleWeeks、weekAnchor、slotIds、lessons；课程用 cycleWeek、weekday、slotId 定位。继续使用现有版本冲突检查、班级权限、保存和设备同步，不新增数据库表、依赖或权限。

服务端、网页预览和教室端使用相同优先级和周次计算。教室端缓存完整循环，断网后继续计算；“下一节”覆盖最长一个循环，避免空白循环周使后续课程消失。已有客户端能够忽略新增字段，但要计算循环值班需使用新版教室端；不以网页设置已保存代表旧程序已具备该能力。

Excel 主表按日常课程、午间静校、晚自习顺序展示，采用黑白细线，不重复填写作息时间。默认每组学科、教师两行，已有地点才保留地点行。相同安排的两节晚自习合并填写，导入自动展开；已有分节差异的循环周分节导出，保留全部差异。兼容旧三行模板和旧四表、六表文件；旧四表保留现有值班设置，如果旧文件删除了值班引用的作息则要求先处理引用。保留公式、宏、压缩包大小及 XML 防护。旧编辑器保存时未发送新增字段，服务端保留已保存的循环。

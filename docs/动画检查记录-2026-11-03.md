# 动画检查记录（2026-11-03）

## 原因与修复

高一（17）班 2.5.8 的 19:28 诊断报告记录了“Windows 动画：关闭”和“浮岛动画：开启”。通知历史已经记录实际帧回调与重绘，说明上次的浮岛设置生效；这不能证明独立的关于页也在播放。

`AboutThankYouMascot.Play` 仍以 Windows 动画开关作为播放条件，自动播放和点击重播都会被跳过。继续检查发现，原生语音桌宠 `BanbanPetMascot` 的默认值也沿用相同开关。独立测试直接编译生产控件与原素材，只把系统查询依赖设为 false，分别复现了这两个问题，没有修改本机 Windows 偏好。

- 关于鞠躬默认播放，保留原来的 8 帧、约 2.4 秒有限动作，点击或键盘激活可重播；切页、隐藏、最小化、关闭继续停止。
- 原生语音班班默认播放。用户隐藏、暂停语音、锁屏、休眠和关闭后的停止与恢复逻辑保持。
- 通知人物、通知条的控件默认值统一为开启；实际浮岛仍使用保存的 `AnimationsEnabled`，用户明确关闭时显示静态终态，不重新打开用户已关闭的设置。
- 删除不再使用的 `ClassroomIslandReveal.AnimationsEnabled()`，修改旧测试中根据 Windows 关闭状态跳过动画验证的分支。
- 只读环境脚本不再把 Windows 查询值误写成当前客户端动画状态，改为标明客户端默认开启；实际浮岛设置仍以客户端诊断为准。

未更换角色素材、字体、布局、动画曲线或计时频率，未新增产品依赖。

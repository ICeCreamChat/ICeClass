# 教室岛课表与自动化

本地开发版本，使用 ICeClass 自有界面及 Avalonia 原生窗口。已接入当前 Python 服务端、教师工作台和 Windows 教室端；尚未发布到正式下载及自动更新。本版不包含插件扩展和天气。

## 教师配置

登录教师工作台，在“早读统计”下方打开“教室岛”，选择有权限的班级。Windows 教师端使用同一工作台和接口。

| 配置页 | 功能 |
| --- | --- |
| 周课表 | 科目、教师、地点；每周、单周、双周课程；第一周周一起点 |
| 作息 | 上课与下课时间；课程关联时段，修改作息后一起生效 |
| 临时调课 | 按日期替换某节课，或临时停课 |
| 提醒与外观 | 课前、上课、下课提醒，提示音、语音、音量和展示时长；岛的位置、宽度、主题、不透明度和隐藏规则 |
| 信息组件 | 日期、倒数日、自定义文字；开关、排序与轮播间隔 |
| 自动化 | 指定时间、课前、上课、下课触发；显示提醒、打开 HTTPS 网页、本机应用或早读 |

修改后点击“保存并下发”，教室端在正常联网时每 15 秒同步。右侧显示所选日期的实际课程，以及本班各设备的配置版本、同步时间和最近执行结果。“已同步”表示设备已将该版本写入本机缓存；不表示全部自动化已执行。离线设备会在重连后获取配置。

每次保存检查版本；其他教师先保存时，页面提示重新载入，保留当前未保存内容供核对。重新载入或切换班级会确认是否放弃修改。“复制到其他班级”只列出当前账号可配置的班级，先保存本班配置，再选择目标班级下发；目标配置会被替换，部分失败会分别报告。

作息最多 32 个时段，不能重叠；课程最多 448 条，临时调课最多 500 条，信息组件最多 16 个，自动化最多 40 条。科目或组件内容为空、日期无效、周次冲突等情况会在保存时给出错误。

## 课程与时间

时间按北京时间运行，联网时沿用早读服务校准后的服务器时间，断网后继续本机计时。第一周周一所属周为单周，之后交替；早于起点的日期也按完整周推算。

临时调课只影响指定日期和时段。停课会取消该节课的课前、上课、下课提醒及关联自动化；独立的定时规则仍执行。上课开始时刻属于本节课，结束时刻进入课间。倒计时最后一分钟显示秒数。今日结束后仍能查到下一天或下一周的下一节课。

教室端展开后点击“课表”查看今天完整课程，再点一次隐藏列表。没有课程时明确显示空状态；未配置作息时继续展示原有早读状态与入口。

## Excel

先点击“导出 Excel”获得模板，再编辑其中的数据。导出为当前已保存的课表。

| 工作表 | 列 |
| --- | --- |
| 作息 | 时段标识、名称、开始、结束 |
| 课程 | 星期(1-7)、时段标识、周次(全部/单周/双周)、科目、教师、地点 |
| 临时调课 | 日期(YYYY-MM-DD)、时段标识、科目、教师、地点、停课(是/否) |
| 学期 | 第一周周一(YYYY-MM-DD) |

保留工作表名和表头；时段标识须唯一，课程及调课引用相同标识。星期一为 1，星期日为 7；日期填写文本 `YYYY-MM-DD`，时间使用 `HH:mm` 或 Excel 时间值。当天结束可写 `24:00`；网页结束时间的 `00:00` 也表示当天 `24:00`。

导入只替换作息、课程、调课及学期起点，保留提醒、外观、组件和自动化。导入后先预览，检查无误再点击“保存并下发”。支持不超过 2 MB 的 `.xlsx`；不执行公式或宏，公式单元格须先粘贴为值。不支持将任意第三方格式直接当作此模板导入。

## 提醒和外观

常驻内容保持 48 DIP 单行，以日期和课表两个胶囊显示；全天课程按顺序保留，非当前课程使用首个完整 Unicode 字符缩写，已结束课程淡化。当前课程以留白的冰蓝圆角底显示全名、时间与进度，长名称省略并保留全文提示，课间较长时显示分隔线。轮播信息沿用已有配置。手动展开后显示课程详情、组件、连接状态和已有班级通知。新建配置默认为浅色、最大宽 560 DIP，最大宽度可设为 380-1000 DIP，并受屏幕工作区限制；位置支持顶部居中、左上、右上、底部居中及水平/垂直偏移。

提醒在同一细条内斜向擦入，伴随一次向桌面扩散的主题色波纹；浅色使用冰蓝。课前倒计时与准备短句每 10 秒轮换，数字和课程名突出，时间与标签较轻；展示结束后回到课表，胶囊宽度随内容柔和缩短。提醒不自动展开下方操作面板。手动展开与收起沿用可中途反向的临界阻尼弹簧。Windows 关闭界面动画时直接切换，隐藏或退出时停止波纹。

教师喊话也在同一岛面展示：普通冰蓝、重要浅黄、紧急浅红，班班始终站在侧边。重要和紧急都由班班迈腿小跑、扶边拉宽；紧急时另一只手始终握住大喇叭，停稳后举到嘴边。重要和紧急的长文字可在岛内展示两行。紧急立即显示正文，普通静音，其他级别按发送设置播放声音。较高级别优先展示，同级依序排队；点击“已知晓”才发送人工确认，Esc 仅收起。托盘“预览班班喊话”提供三种样例及连播入口。详见 [顶部悬浮岛](教室端顶部悬浮岛.md)。

可使用深色、浅色或跟随系统主题，并设置 30%—100% 不透明度。“淡化”在闲置且收起时进一步降低不透明度，移入、展开或出现提醒时恢复。上课隐藏和全屏应用隐藏可分别配置；早读自身全屏时自动避让。

“隐藏”和关闭岛只改变本机显示偏好。通过教室首页的“顶部悬浮岛”或托盘的“显示顶部悬浮岛”恢复操作；这两个入口也可临时解除鼠标穿透、上课隐藏及教师关闭设置，方便维护。退出早读全屏后再使用入口。

“设置”中的“本机使用独立外观”决定是否覆盖教师下发的外观；取消勾选并保存即可恢复跟随教师。课表、提醒和自动化仍来自教师配置。本机显示偏好与绑定凭据分开保存。

## 自动化与离线

规则按选择的星期执行。课程事件基于实际课表和调课，定时事件使用北京时间。打开网页使用完整 HTTPS 地址；打开本机应用填写 exe 的完整路径，然后在教室岛“设置 → 自动化应用 → 选择并允许应用…”中选择同一个文件。应用路径必须存在且与本机允许列表一致，不接受命令、参数或网络共享路径。

最近执行记录显示在本机设置中，并在下次联网同步时回传教师端。应用未允许或执行失败时显示原因；不会自动反复重试。网页的内容加载仍取决于网络，本机早读及课表提醒可离线运行。

配置缓存按服务地址、设备及班级隔离；先写入本机文件，再回执该版本。重启或离线启动读取最后配置。每个自动化事件在产生副作用前先持久记录，避免同一事件在连续刷新或重启后重复执行。休眠恢复不补执行积压的旧事件；发生断电等中断时，已经领取但尚未执行完的事件也不自动重试。

绑定明确失效后暂停自动化并提示重新绑定。换班后不加载原班课表或通知；本机事件记录损坏或不能写入时暂停自动化，并向教师同步异常，不用空记录重放事件。

## 本地体验与验收

运行 `scripts/start-local-review.ps1 -Client Classroom`，或双击 `dist/local-review-2.3.0/体验顶部悬浮岛.bat`。最新教室端为 `dist/local-review-2.3.0/ICeClass-2.3.0-island-review.exe`；教师工作台为 `http://127.0.0.1:8838/`，此服务只监听本机。正式安装的绑定、偏好和自动更新不受影响。

自动检查：

```powershell
python -m unittest discover -s server -p "test_*.py" -v
dotnet run --project tests/ReceiverOfflineChecks/ReceiverOfflineChecks.csproj -c Release --no-launch-profile
dotnet run --project tests/ReceiverOfflineChecks/ReceiverOfflineChecks.csproj -c Release --no-launch-profile -- --native-island D:\ICeCoding\ICeClass\dist\local-review-2.3.0\config.json
```

原生联动检查必须显式提供本地验收绑定，不读取正式安装的凭据。其时钟推进只发生在测试进程，实际操作系统时间、远程课表和早读成绩保持原状。

# 致谢名单维护

致谢页沿用批准样板的三组标题与段落：感谢 AI 建模社、感谢支持与指导、特别感谢。保留原有名单、顺序、班班插画、字体、液态玻璃及关于窗口尺寸。

## 后台操作

使用超级管理员账号进入「账号设置 → 致谢名单」。在正文中追加姓名，按回车分行；可修改分组标题、添加或移除分组，也可上下调整顺序。右侧显示文字预览。点击「保存并同步」后生效。

普通教师、校长和教室设备不能修改这份全校共用内容。保存失败时保留当前编辑；其他页面已保存新版本时提示冲突，需先保留自己的修改，再重新载入核对。重新载入和退出登录前会提示尚未保存的编辑。

## 客户端更新

更新后的教室端和教师端在下次打开「关于」时读取当前学校平台的致谢。已打开的关于窗口需关闭后重开。断网时先显示上次成功同步的内容，首次使用则显示随程序附带的默认名单。旧客户端需要更新程序后才支持动态致谢。

名单按纯文字展示，保留换行。教室端的正文保持 18px、标题 20px，使用样板的深蓝文字和蓝灰正文；较小窗口及较长名单可滚动阅读，文字不进入玻璃背景滤镜。

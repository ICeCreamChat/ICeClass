# 用户权限与管理

2026-11-01：网页与 Windows 教师端使用相同的服务器权限。学校身份分为校长、主任、年级部、班主任、任课老师，超级管理员 ICe 单独保留。

| 身份 | 数据与业务范围 | 账号管理 | 学校统一设置 |
| --- | --- | --- | --- |
| 校长 | 全校早读、通知、来音、记录、班级及设备 | 校长、主任、年级部、班主任、任课老师 | 可修改 |
| 主任 | 高一、高二、高三全部班级、设备与业务 | 三个年级内的年级部、班主任、任课老师 | 只读公开禁言时段 |
| 年级部 | 所负责年级的全部班级、设备与业务 | 本年级班主任、任课老师 | 只读公开禁言时段 |
| 班主任 | 带班班级可修改课表、值班、作息、浮岛并查看来音；兼任的其他任教班级按任课老师权限 | 修改自己的密码 | 只读公开禁言时段 |
| 任课老师 | 任教班级的早读、通知、记录与教室控制；课表、值班、作息、浮岛只读；不接收或查看来音 | 修改自己的密码 | 只读公开禁言时段 |

学校统一设置包括早读统计规则、禁言时间表、全校绑定码、浮岛隐藏默认规则、学校智能助手连接及对话清理周期。超级管理员 ICe 继续维护平台，不能被其他账号编辑、停用或删除。管理账号也不能通过用户管理修改自己。

## 分配身份

1. 打开“用户管理”，点击“创建用户”或某行的“编辑权限”。
2. 校长和主任无需逐班勾选。主任自动管理高一、高二、高三；全校归档或其他年级班级由校长管理。
3. 年级部只选择负责年级。该年级已有和以后新增的班级自动进入范围。
4. 班主任分别勾选“带班班级”和“任教班级”；兼任其他班的课程时继续使用同一个账号。任课老师只分配“任教班级”。未分配班级的账号会显示“待分配”。
5. 保存身份或范围后，该账号原会话撤销，需要重新登录。密码、历史成绩与通知不因调整身份而改变。

管理者只能授予自己管理范围内的下级身份。跨年级教师由能覆盖其全部带班、任教班级的主任或校长管理。年级部和主任不能创建不在本人范围内或完全未分配班级的教师账号。

例如：同一账号带高一（1）班、在高二（2）班任课，可以管理一班的课表和来音；对二班可发送通知、调节音量和查看课表，不能修改二班配置或收听二班来音。来音弹窗也按这个范围接收。课表只读页面保留预览、导出和周次切换。

带班与任教互换时，即使可见班级总名单不变，班班旧对话也会重新校验权限。记录仍保留在数据库中，超出当前权限的上下文不可继续使用；原有仅带班账号沿用原历史范围。

## 找到和整理用户

按五种身份分类；兼任账号显示“班主任”和“任课老师”两个身份标签，在两个分类中均可找到，全部用户只计一次。支持姓名、用户名、身份及班级搜索，年级与启用状态组合筛选。点击“待分配”集中处理待分配账号。列表每页 12 位，按职责、年级和班级排序。每行显示姓名、账号、身份、范围与状态，密码重置、启停和删除集中在“更多”菜单。

## 升班和范围变化

教师的带班和任教范围跟随具体班级编号；年级部和主任跟随班级当前年级。班级从高一更名为高二后，高二年级部自动取得范围，高一年级部失去该班范围。毕业留存班不属于主任的三个高中年级范围。年级部不能把班级更名到另一个年级。

## 升级与验证

数据库升级保留现有账号、密码哈希、停用/删除状态、班级授权、设备绑定、会话关系及历史记录。原 `teacher` 继续作为班主任，原 `teacher_classes` 保留为带班班级；新增 `subject_teacher` 身份及独立的 `teaching_classes` 任教关联，不推测或自动新增教师授权。年级部仅改显示名称，沿用 `grade_leader`。

升级前备份数据库及对应服务文件；原始 SQL 迁移保持不变，由启动升级逻辑扩展身份约束。若已创建新身份或任教授权，应向前修复，不能只回退旧代码或删除新表。必须回到升级前状态时，停服后同时恢复匹配的服务文件与升级前数据库；恢复会丢失备份后的变更。

服务端验证覆盖五种身份、独立带班/任教范围、直接越权读写、来音列表/播放/删除及班班汇总、通知与教室控制、权限变更后的会话撤销、跨年级账号保护、旧数据库升级及重复启动。教室班班仍仅使用唯一有效班主任身份，任课授权不会替代或重复班主任。浏览器在隔离演示数据库检查创建、兼任标签与筛选、编辑保存、七个浮岛页签只读、周次切换、桌面与窄屏布局及键盘操作。

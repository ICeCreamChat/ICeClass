# 用户权限与管理

2026-10-19：网页与 Windows 教师端使用相同的服务器权限。

| 身份 | 数据与业务范围 | 账号管理 | 学校统一设置 |
| --- | --- | --- | --- |
| 校长 | 全校早读、通知、来音、记录、班级及设备 | 校长、主任、年级部长、班主任教师 | 可修改 |
| 主任 | 高一、高二、高三全部班级、设备与业务 | 三个年级内的年级部长、班主任教师 | 只读公开禁言时段 |
| 年级部长 | 所负责年级的全部班级、设备与业务 | 本年级班主任教师 | 只读公开禁言时段 |
| 班主任教师 | 本人班级的早读、通知、来音、记录与教室控制 | 修改自己的密码 | 只读公开禁言时段 |

学校统一设置包括早读统计规则、禁言时间表、全校绑定码、学校智能助手连接及对话清理周期。超级管理员 ICe 继续维护平台，不能被其他账号编辑、停用或删除。管理账号也不能通过用户管理修改自己。

## 分配身份

1. 打开“用户管理”，点击“创建用户”或某行的“编辑权限”。
2. 校长和主任无需逐班勾选。主任自动管理高一、高二、高三；全校归档或其他年级班级由校长管理。
3. 年级部长只选择负责年级。该年级已有和以后新增的班级自动进入范围。
4. 班主任教师勾选本人班级。保留已有多班授权，未分配班级的账号会显示“待分配”。
5. 保存身份或范围后，该账号原会话撤销，需要重新登录。密码、历史成绩与通知不因调整身份而改变。

管理者只能授予自己管理范围内的下级身份。跨年级教师由能覆盖其全部班级的主任或校长管理。年级部长和主任不能创建不在本人范围内或完全未分配班级的教师账号。

## 找到和整理用户

按校长、主任、年级部长、班主任教师分类；支持姓名、用户名、班级搜索，年级与启用状态组合筛选。点击“待分配”集中处理待分配账号。列表每页 12 位，按职责、年级和班级排序。每行显示姓名、账号、身份、范围与状态，密码重置、启停和删除集中在“更多”菜单。

## 升班和范围变化

教师跟随具体班级编号；年级部长和主任跟随班级当前年级。班级从高一更名为高二后，高二部长自动取得范围，高一部长失去该班范围。毕业留存班不属于主任的三个高中年级范围。年级部长不能把班级更名到另一个年级。

## 升级与验证

数据库升级保留现有账号、密码哈希、停用/删除状态、班级授权、设备绑定、会话关系及历史记录，新增年级负责人关联。现有主任自动按三个年级生效，现有校长按全校管理生效；不会猜测教师姓名对应班级，也不会自动把教师改为年级部长。

服务端测试覆盖四级范围、新班级自动授权、直接跨范围访问、班级/用户/设备/记录的管理、上级及本人保护、跨年级教师保护、权限变更后的会话撤销，以及旧数据库升级后的外键一致性。浏览器在隔离演示数据库验证搜索、组合筛选、分页、菜单、角色编辑、保存结果及桌面与窄屏布局；真实账号不用于破坏性测试。

# 班班智能交互 · 本地验收

全平台分析的新增主题、权限与当前状态口径见 [班班全平台说明](班班全平台说明.md)。

2026-10-16，基于 2.3.0 本地版。验收入口为 `http://127.0.0.1:8838/`；正式服务器尚未更新。

## 现在可以怎样使用

打开右下角班班，先问“看一下本周高一各班晨读”，再追问“那高一二班上周呢”。班班结合本次对话确定班级与日期，再到服务器读取这个账号能查看的数据。数据问题与继续追问的首轮强制调用只读工具，不能直接引用旧对话数字；简单问候、道谢和功能介绍可自然回应。日期以北京时间计算：“本周”是周一至今天，“上周”是上周一至周日，“上周同期”按相同日期整体向前移七天。

也可以问“比较这周与上周同期”“核对通知回执”“汇总教室来音数量与时长”“看看设备绑定”。模型只能调用查询和时段对比工具，不能发送通知、删除记录、修改账号或控制白板。查询失败与缺少记录不会被服务器改成可信的零；同步未确认时会提醒排名仅供参考。

回复逐段显示，角色从思考、慢网等待切换到回答，再归位点头。卡片只展示这次查询的主题、日期、关键数字和来源入口；晨读卡片中的班级可直接打开下面对应班级的日历。连续同范围查询会合并来源卡片，避免重复。窗口仍可拖动、放大、收起，关闭动效不影响使用。

点击“停止”会终止当前浏览器等待并向服务器取消上游请求。连接中断时保留已收到的文字，标记“回复未完成”，提供原问题重试；重试替换这条未完成回复，不重复添加问题。打开连接设置再返回也保留阅读位置。

## 配置与对话记忆

本机原有学校连接已保留。所有账号可从“更多 → 连接设置”选择“学校提供”或“自行配置”；个人配置支持 DeepSeek、阿里云百炼、智谱 GLM、Kimi、豆包的常用地址与模型，也可自定义兼容服务的 Base URL、API Key 和模型 ID。保存并测试后使用。个人配置只影响当前账号，教师的班级权限不变。学校服务仍仅限超级管理员管理。地址不变时密钥留空保留旧值，修改地址时必须重新填写对应密钥；已保存的密钥不回显。

密钥保存在数据库旁的 `banban-settings.json`，被 Git 忽略，不进入网页资源或发布包；Linux 写入权限为 0600。也支持 `DEEPSEEK_API_KEY` 与 `ICECLASS_DEEPSEEK_MODEL` 服务端环境变量。发布包不带本机配置，因此正式服务器仍需配置，不能把本机的联调结果理解为已完成上线。

完整对话按账号分别保存到服务端，每个账号可创建多段会话。点击“历史”查看、切换并继续原有话题；“新对话”不会清空旧记录，刷新或重新登录恢复最后选中的会话。不再按十轮截断，也不再按 24 小时过期。小窗口和手机使用历史抽屉，放大窗口在宽屏下显示侧栏，开合历史不移动窗口。切换会话时，未发送草稿在本次页面内保留。

每段历史对话右侧均提供删除按钮。教师及其他角色可以自主删除自己的会话；确认后从当前数据库删除会话及全部消息，无回收站。服务器校验账号归属，超级管理员也不能删除别人的聊天；正在回答时需先停止。删除当前会话会打开其余会话，删完后回到欢迎页。历史清理不影响晨读、通知、设备等业务数据，既有备份按原备份周期过期。

默认每月 1 日北京时间 00:00 进入新周期，统一清理此前创建的会话及其消息。超级管理员可以在“历史 → 清理设置”切换为每周一；修改设置不会立即删除，并会显示下次清理时间。后台沿用每小时清理任务，最迟在一个清理间隔内完成；访问历史或提交消息时也会检查到期清理。服务器停机后恢复时会补做清理，新周期内刚创建的会话不会被误删。晨读、日历、通知和设备等业务记录不受这个聊天清理周期影响。

消息和会话列表分别分页，加载更多不会删除更早内容；发给模型的近期上下文有独立长度预算，完整历史仍保留在数据库。现存旧格式对话在一次事务中迁移，不会因升级重新开始。已被旧版本清除的文字无法重建。账号角色或授权班级变化后，不再展示旧权限范围的记录；所有查询、切换和继续对话都由服务端校验归属，超级管理员也不能读取其他账号的聊天。

未完成、失败、取消的回答不会作为完整历史保存；窗口中的未完成文字在刷新后不恢复。班班后台不提供读取录音内容或全校互看对话的入口。清理会释放 SQLite 页面供后续数据复用，数据库文件不一定马上缩小；已有的运维备份仍按原有备份周期保留，当前安装脚本的每日备份保留 14 天。

## 数据与隐私

- 每次查询重新核对权限。教师、主任只能查看获授权班级，校长、超级管理员按现有平台权限查看全校。
- 工具上下文按主题裁剪。晨读问题不会附带通知正文；通知分析最多附带最近 20 条文字样本，每条最多 500 字。
- 教室来音只统计收到的数量与总时长，不读取、发送或转写音频，不推断学生说了什么。
- 服务端不向模型附带用户身份资料、设备令牌、设备识别信息、录音地址或文件路径。用户自己写在问题或通知文字中的信息仍属于正文，不会自动匿名化。
- 有效发声反映统计时段内的软件记录，不能直接等同教学质量；未同步或缺少记录不代表没有晨读。白板显示回执也不代表师生已经阅读。

## 验证结果

完整 Python 服务端 75 项测试通过，包含班班原有 12 项与流式工具、权限、记忆新增 13 项；动作状态测试 16 项通过。覆盖真实上游 SSE 分段解析、首段先于回复完成到达、异常截断、强制工具查询及阻止未查询回答、权限与账号隔离、过期记忆、停止请求、断开连接、新对话与立即重试的并发清理。JavaScript 语法与 Git 空白检查通过。

真实 DeepSeek 联调使用本地演示数据库，验证了高一年级查询、继续追问高一（2）班上周、中文流式回答和管理员连接测试。上周范围实际为 2026-10-05 至 2026-10-11，班级卡片仅含相应范围。真实回答质量仍可能波动，重要判断请结合来源数字核对。

实际内置浏览器验证了流式显示、来源卡片、班级日历跳转、自动跟随滚动、25 秒慢网停止、中途失败保留文字、重试去重、刷新恢复、教师菜单与班级权限、窗口拖动/放大、动效开关、390 像素窄屏和 600 像素低屏高布局。故障场景在独立本地模拟服务执行，没有给正式接口添加故障开关。证据位于本地 `output/banban/intelligence-checks.json`、`live-checks.json` 与 `intelligence-*.jpg`。

当前内置浏览器不支持注入触摸输入；鼠标指针拖动已验证，尚未在学校白板真机上完成班班触屏验收。

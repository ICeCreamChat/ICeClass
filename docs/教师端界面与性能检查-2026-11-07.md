# 教师端界面与性能检查 · 2026-11-07

本轮依据 Vercel React Best Practices 中适用的数据加载、并发请求和资源生命周期原则，以及 Impeccable 的界面一致性与交互检查流程，检查正式教师端。实际技术栈为 Avalonia / C# 与 WebView / 原生 JavaScript，因此沿用现有实现，没有引入 React 或新依赖。

检查覆盖全部 12 个主导航页面：早读统计、作业统计、创意计划、教室浮岛、班级通知、教室控制、通知记录、教室来音、禁言时间、班级管理、用户管理、账号设置；同时检查登录、班级与用户创建弹窗，以及桌面加载、连接失败、设置、确认、反馈和关于窗口。保留已有微软雅黑字体、字号和蓝白玻璃设计。

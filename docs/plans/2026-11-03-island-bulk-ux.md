# 教室浮岛批量设置体验

日期：2026-11-03。状态：本地实现与验证完成，已打开新版教师端供用户验收；未提交、推送或部署。

## 已确认

- 用户需要同时保留统一部分设置和复制整套配置的能力。
- 合并“批量设置”和“复制到其他班级”为一个入口，按内容勾选；未勾选的内容保留各班现有值。
- 教师端通过 WebView2 加载同一教师工作台，网页与教师端使用同一实现。
- 视觉沿用项目既有字体、共享按钮、弹窗标题栏与底部操作区。
- 用户要求中断后继续。本轮采用此前推荐的设置来源：当前班作为模板，有草稿时先明确“保存并继续”。

## 已核实的问题

- 两个入口的内容重叠，但一个只改四类共享设置，另一个会替换全部配置。
- 当前批量操作默认全校和显示浮岛；手选班级缺少年级分组、批量勾选和清空。
- 浮岛批量按钮和弹窗拥有单独的高度、标题和内边距，与其他页面的共享控件不一致。
- 当前复制流程没有逐班预览，按班逐个提交，可能部分成功；批量接口则具有预览、版本检查和整批事务。

## 已实现的界面与行为

- 工具栏保留一个“批量设置”入口，重新载入、导入、导出归入已有的“更多操作”样式。
- 统一弹窗展示来源班级、需要同步的内容和目标班级，随后预览影响并确认下发。
- 目标班级按年级分组，支持搜索、选择当前筛选结果和清空选择；默认不选全校。
- 按内容区分浮岛开关、作息、周课表、值班、临时调课、提醒、外观、课堂隐藏、轮播信息和自动化，支持明确选择全部配置。
- 当前班作为来源，不作为默认目标。各项显示实际摘要；课表、值班等内容可能替换目标对应安排，应在预览时明确展示。
- 作息和课表、值班、调课、课堂隐藏之间存在时段关联。同步这些内容时明确展示关联处理结果，不能生成失效引用或静默清掉未选内容。
- 两端沿用同一套权限：全校管理员可选择全校，其他用户只列出已有可编辑班级。
- 保留逐班版本检查、失败反馈、预览失效后重新核对，以及无变化不递增版本的行为。

## 数据与接口

- 复用 `/api/island/bulk/preview` 和 `/api/island/bulk`，增加来源班级、来源版本和勾选内容；应用时检查全部目标版本，事务内重新检查各班权限。
- 旧 `changes` 请求仍服务已打开的旧页面和历史班班调用，维持原有全校管理员限制；新模板请求使用原有逐班配置权限。
- 时段按标识和标准化名称匹配，部分同步保留目标标识及额外时段；整套复制替换全部配置。
- 班级接口实际不含 `grade`，复用工作台已有 `classGrade(name)` 完成年级分组；浏览器夹具使用同样的真实字段形状。
- 预览和完成复用同一弹窗，标题随阶段变化；应用期间禁止关闭或重复提交，结果不确定时必须重新预览，不自动重试写入。

## 实现时的验收范围

- 只改所选内容、全部配置复制、不同班级时段标识与课程引用保留。
- 全校、年级及普通教师权限，目标班级停用或权限变化。
- 未保存修改、预览版本冲突、网络失败及重复提交。
- 教师端 WebView2 与浏览器的桌面、窄窗口布局、键盘与焦点反馈。

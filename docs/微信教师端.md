# 微信教师端

教师小程序位于 `miniprogram/teacher`，使用原生 WXML、WXSS 和 JavaScript，已替换早期的 `web-view` 网页入口。页面直接调用 `https://iceclass.icecreamchat.top` 的现有学校接口，复用学校账号、班级、权限及业务数据。上传小程序不会更新学校服务或 Windows 客户端。

个人主体版提供课堂工具。小程序包不包含班班对话、模型连接、次数管理或晚自习监测页面。小程序也不提供文字合成语音；网页和 Windows 客户端继续维护各自的功能。

界面沿用[教师工作台的设计规范](teacher-liquid-glass/DESIGN.md)：使用同一班班形象、蓝白配色和控件层级，在手机上按班级工作、校园管理组织入口。账号设置提供液态玻璃、原版白色和降低透明度三种本机外观。

## 导入与通信域名

在微信开发者工具导入 `miniprogram/teacher`，确认 AppID 与运营账号一致。现有学校账号登录不需要小程序 AppSecret；不要把密码、验证码、开发工具令牌或登录票据写入配置和源码。保持 `project.config.json` 的 `setting.urlCheck` 为 `true`。

登录页的两种班班姿态和工作台头像使用 `assets/banban` 内的 PNG。两种登录姿态分别用固定路径引用，供微信开发者工具识别并随代码打包。网页使用原有的 WebP 素材。

在微信公众平台「开发管理」的「开发设置」中配置下列**服务器域名**，具体入口以平台实际显示为准：

| 类型 | 域名 | 用途 |
| --- | --- | --- |
| request 合法域名 | `https://iceclass.icecreamchat.top` | 学校登录、教学记录、管理与写入 |
| uploadFile 合法域名 | `https://iceclass.icecreamchat.top` | 教师主动录制或导入的 WAV 通知 |
| downloadFile 合法域名 | `https://iceclass.icecreamchat.top` | 来音、题图、授权创意附件和统计导出 |

当前原生包不使用业务域名或 WebSocket。服务器的普通 HTTPS 访问成功，不能证明微信后台已配置上述三类合法域名；应保持校验开启，在真机上验证。类目、隐私声明、备案与运营主体资格按实际功能在平台办理，类目通过不等于代码审核通过。

## 页面能力与边界

| 功能 | 原生页面提供的操作 |
| --- | --- |
| 学校账号 | 登录、退出、恢复会话、修改本人密码、切换本机外观 |
| 班级通知 | 大屏静音文字或教师原声；录音、导入 WAV、试听、显示时长、禁言确认与回执 |
| 通知记录 | 班级筛选、分页、送达与知晓回执 |
| 纸卡答题 | 与教室端配对，用手机扫描或手工补录；支持单选、判断、多选及本轮回执。查看课堂记录、逐题轮次、学生分析及统计导出 |
| 纸卡编号与学生账号 | 查看班级名单和不含凭据的卡面；按权限分配卡号、生成账号、重置密码或关联原账号 |
| 题库与题单 | 单选、判断、多选、题图、知识点、题单排序、发布和撤回 |
| 作业 | 班级、学期、学科和日期筛选，统计与导出；按权限维护学生名单、学期和作业预设 |
| 早读 | 统计、日期筛选与 Excel 导出；管理员可维护声量门槛、提醒与统计时段 |
| 班级与账号管理 | 依现有权限创建或修改班级、维护教师账号与授权、重置密码 |
| 教室控制 | 依权限设置音量、请求打开早读，展示实际下发与设备回报 |
| 教室电脑设置 | 按管理范围查看设备和连接状态，核实身份、启停或修改班级绑定 |
| 教室浮岛 | 只读查看课表、作息、启用状态和设备同步回执；编辑使用教师网页工作台 |
| 禁言时间 | 所有人依权限读取；学校管理员维护全校时段 |
| 教室来音 | 接收范围内读取、主动播放及删除 |
| 创意计划 | 查看公开展示；具备权限的管理员可按版本评审、维护公开摘要及查看授权附件 |

纸卡课堂先由教室端开课并生成配对码。手机相机只在老师主动开启扫描并授权后工作，画面在本机识别，答案是否写入以教室端回执为准。拒绝相机仍可手工录入。正式打印带密码的纸卡、现场作业和早读采集、Windows 文件和设备操作继续使用网页或对应客户端。教师主动开始录音或选择文件时，小程序先核对微信隐私授权。录音还需麦克风权限。通知原声在确认发送后上传，题图在选中并确认上传后才上传；取消保留原草稿。

创意计划评审需要学校服务提供 `PUT /api/ideas/admin/{idea_id}`。这条入口和网页评审共用权限、CSRF 与版本校验。学校服务尚未包含该入口时，请继续在网页评审。

班级和设备编辑通过现有确认接口执行固定的 `class.update` 和 `device.update` 操作，服务端复核权限和配置快照，不调用模型。准备操作仍按学校现有规则计次，提交前显示影响与次数提示。禁言时间没有服务端版本锁，页面保存前比对远程值并保留草稿，但无法消除两个管理员同时保存的并发窗口。

## 会话、草稿和状态

- 未登录停留在工作台首页，可阅读《用户服务协议》和《隐私政策》。主动打开「教师登录」后，需要勾选同意才能提交。取消登录或系统返回会回到原入口，不会自动再次打开登录页。
- 本机保存学校会话 Cookie、到期时间、账号响应、班级选择和外观偏好，不保存登录密码；退出时注销学校会话并清除本机登录状态。
- 发现会话失效时隐藏原业务内容，仍保留当前草稿。登录同一账号后可继续；换用其他账号时打开新工作台。协议有必须重新同意的变更时，同步更新两个协议的页面和微信后台指引，并递增 `lib/api.js` 的 `AGREEMENTS_VERSION`，以免旧会话绕开新确认。
- 新生成或重置的学生密码只在当前页面展示一次；隐藏或离开页面就清除，不能重新读取。完整纸卡代印仍在网页办理。
- 写入保留学校 CSRF 校验及真实权限检查。登录失效保留当前页面草稿；重新登录同一账号后可继续。换用其他账号会返回新的工作台，避免旧账号页面继续操作。
- 网络失败不会自动重发写入。遇到「未能确认结果」，先查看实际记录再操作，不能把超时当作未提交。
- 通知「已发送」只表示已下发，送达与知晓以回执为准；离线通知不会在教室重连后补播。
- 题目、题单、卡号、作业配置和创意评审沿用服务端版本。冲突时保留草稿，要求核对并重新载入。早读规则、设备等无服务端版本的设置按现有接口重新读取核对，并保留服务端权限校验。
- 统计保留零值、未作答、未评分和多选部分选中的区别，按服务端原始口径展示。

## 本地验证

在项目根目录运行：

```powershell
node scripts/check-wechat.cjs
$wechatTests = Get-ChildItem -LiteralPath './scripts' -Filter 'test-wechat-*.cjs'
node --test --test-reporter=spec $wechatTests.FullName
```

`check-wechat.cjs` 检查提交目录内的页面、配置和接口引用，防止退役的功能随包进入，并调用微信官方 WXML/WXSS 编译器。编译产物在 `output/wechat-native-check`，上传目录仍是 `miniprogram/teacher`。编译器不在默认位置时，以 `WECHAT_COMPILER_DIR` 指向包含 `wcc.exe` 与 `wcsc.exe` 的目录。

`test-wechat-school.cjs` 仅连接本机 `127.0.0.1` 的隔离演示服务，默认端口为 `8843`，其他测试使用模拟接口。运行全部测试前，另行启动演示服务并核对 `X-ICeClass-Preview: 1`，数据库应使用独立新文件，不要指向真实学校数据库：

```powershell
python server/preview.py --port 8843 --database '<独立演示数据库绝对路径>'
```

如果 `8843` 已被占用，给独立演示服务选择一个空闲端口，并在运行测试的 PowerShell 窗口设置同一端口，例如 `$env:ICECLASS_WECHAT_TEST_PORT = '8844'`。

测试适配器将请求映射到本机；正式小程序源码固定使用学校 HTTPS 地址。隔离演示账号只在该本机库中有效，不是线上教师账号或可直接提供给微信审核的账号。

## 预览、上传、审核和发布

1. 在微信开发者工具编译并生成**新的原生版本预览码**，使用已授权的微信账号扫码。早期网页包的预览码不能用于原生验收。
2. 在 iOS、Android 微信上检查：未登录能打开两份协议；未勾选时点「登录」或通过键盘提交均不会发出请求；「取消登录」和系统返回可停留在原入口；同意后能完成登录并看到授权班级。再检查断网、会话过期、草稿恢复，以及相机、麦克风和文件的首次拒绝、取消与重新授权。用读屏检查控件名称、顺序及状态播报。编译和模拟接口测试不能替代真机验证。
3. 使用隔离演示班级核对文字静音展示、教师原声、禁言确认和离线反馈，不向正式教室发送测试内容。平台审核需要的账号应无真实学生资料且不能操作正式设备。
4. 开发者工具上传成功后，到公众平台「版本管理」核对开发版本。若与旧包使用同一版本号，用上传时间和版本备注区分。上传成功只证明代码已送达，并不代表已经配置体验版、提交审核或上线。
5. 运营主体在后台完成真实的隐私保护指引、适用类目、备案等要求后，选择「需登录账号才可使用」，提供审核专用账号及「纸卡答题 → 课堂记录 → 查看本课统计」的验证路径，再提交对应代码审核。审核账号应可查看预置已结束的课堂，不依赖在线教室；上线单独办理。页面内的隐私说明不能替代平台正式声明。

如果后台自动操作被站点策略拒绝，保留已准备的代码与材料，明确记录停在哪一步，不能换用其他工具、登录票据或私有接口绕过。正式上线以后台发布状态及可访问的正式版本为准。

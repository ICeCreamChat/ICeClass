# 2.5.2 本地验收记录

2026-11-02 完成两端增量更新与语音待机资源优化。教室端仍为 .NET 8 / Avalonia；教师端沿用 Avalonia / WebView2。此次无需更换框架。

## 行为

- 两端按文件校验、复用本机内容；有适用补丁时用 Windows MSDelta 回建，否则下载对应变化文件。支持断点续传。
- 上课、录音、早读、创意窗口或班班对话期间暂停。教师端主窗口使用中也延后自动下载；有效无课日允许更新，课表不可用时明确显示暂停原因。
- 下载完成只标记就绪，下一次真正启动安装。关闭到托盘不算退出；保留“立即更新”。安装失败或中断会恢复变化前的文件。
- 完整离线安装包保留。绑定、登录资料、配置和业务数据不属于更新目标。
- 唤醒和语音模型保持预热；释放已完成或取消的音频引用，合并重复等待中的维护任务。

2.5.1 及更早客户端仍按自身旧逻辑升级，需要先升级到支持新协议的版本；之后才会使用增量和等待安装机制。

## 测量限制与本地窗口

音频引用夹具中，已结束的 30 秒 PCM 从原先继续持有 1,920,000 字节变为可回收；这不代表整机或完整客户端节省相同占比的内存。旧版和新版短时进程采样不构成同负载的整进程树长期统计，不承诺总内存降幅。

连续对话检查使用合成中文 PCM，覆盖 native 唤醒、实际识别、播报和两次续问；真人麦克风、真实教室声学、“唤醒词与指令同一句”和播放中打断没有在本轮真实音频链路中全部复验。

教室端完整包、更新核心和教师端已重新构建，发布准备目录为 `output/server-deploy-20261102/distribution/`。服务端 425 项、发布计划与打包 21 项、GitHub 发版 14 项、语音资源清单 7 项、语音网页 45 项及教师端活动 12 项断言通过。修正了服务端打包遗漏历史 SQL 迁移的问题，并将共用更新检查纳入 GitHub 发版流程。复核日志位于 `output/server-deploy-20261102/`。

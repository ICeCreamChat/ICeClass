# 教师端液态玻璃交互样板

2026-11-05。范围为独立的完整教师端前端交互样板，正式网页、教师端 EXE、服务器和真实资料均不在本轮修改范围。清单以现有源码的 12 个工作台模块、班班、早读预览、桌面窗口、关于和登录为依据；页内选项、弹窗及反馈状态可直接打开，不代表新增同等数量的正式业务路由。

## Direction contract

THESIS：让教师在课表、通知、统计与学校管理之间连续操作。沿用用户确认的透明液态玻璃，将深层菜单与主界面作为同一套材料设计。

OWN-WORLD：微软雅黑字体；正文 #193c59，辅助字 #3e5b72，placeholder #46637a；动作 #0064d7，键盘焦点 #005ed6。页面基底为 #dfedf7，实际曲面渐变使用 #f5fdff、#b4d4ed、#e5f4fb、#c2deee、#e2f2fa 与透明层。透明渐变、边缘折射和内高光属于独立背景镜片，文字始终在前景。

STORY：先看到真实工作台的模块导航，进入页面后可打开筛选、详情、编辑、核对及错误状态。完整目录按模块列出全部样板，可搜索、直接跳转和连续查看。

FIRST VIEWPORT：桌面左侧为约 222px 导航，顶部为连接状态与桌面操作；主要区保留工作台内容层级。早读统计先展示日期与班级筛选、横向成绩图和班级日历，不增加营销标题。窄窗口将导航收为抽屉，表单纵排，长表格在自身区域滚动。

FORM：继承用户已确认的教室端样板与项目字体规则，为教师端建立完整同风格样板；未重开视觉方向选择，未生成概念种子。操作模式为 Operate，代码驱动；无新的生图素材。

FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## 实施边界

- 复用已有蓝白曲面、玻璃折射算法和项目图像，记录素材来源；不替换项目全局 DESIGN.md 的教室端限定范围。
- 操作按钮、筛选、分段导航、下拉菜单、弹窗、二次确认及原生窗口样板均使用对应玻璃层级，减少透明度与减少动态偏好保持可用。
- 真实名称、配置含义和操作后果以源码为准；班级、用户、记录、凭据及执行结果全部使用明确标示的演示数据。
- 不连接学校 API，不调用真实麦克风、相机、系统权限或 AI，不进行真实发送、删除、绑定、下载、更新和部署。
- 使用独立样板目录内的数据清单生成目录及页面对照表。正常、选中、禁用、保存中、成功、空列表、错误和版本冲突都有可见的对应呈现。

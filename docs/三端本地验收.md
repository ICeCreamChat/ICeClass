# 三端本地验收

ICeClass 班伴当前为 2.3.0 本地验收，未上传正式服务器。桌面“班伴三端验收”文件夹沿用原目录名，提供三个独立入口，也可以从项目根目录打开下列文件。

| 端 | 启动入口 | 用途 |
| --- | --- | --- |
| 教室端（白板） | `start-classroom-preview.bat` | 教室晨读活动、接收通知、学生语音留言 |
| 网页端 | `start-web-preview.bat` 或 `http://127.0.0.1:8838/` | 在浏览器中登录，使用统计、通知、来音、班班与管理功能 |
| Windows 教师端 | `start-desktop-preview.bat` | 完整网页工作台的独立 Windows 桌面应用，关闭后收起到托盘 |

三个入口使用同一个本地演示服务器。网页与教师桌面端使用相同的账号及授权，但登录状态分别保存；教师桌面端无需教室绑定码。教室端已单独绑定“弱网验收班”，本机测试不替换真实教室绑定。

演示管理员为 `ICe / LocalDemo2026`；教师权限演示为 `teacher1 / LocalTeacher2026`。这些是本地演示账号，不能用于正式网站。请勿将本地演示目录分发到真实教室。

桌面文件夹内的三个入口连接本地 8838。新安装的普通“ICeClass 班伴 教师端”桌面图标默认连接正式平台；旧安装可能仍显示“班伴教师端”，原入口仍可使用。服务器尚未更新的功能不会出现在正式平台。教师端分发包为 `dist/release/ICeClass-2.3.0-desktop-windows-x64.zip`。

# 教室端顶部悬浮岛

已接入教室端、教师工作台与服务端。本轮完整验收候选为 2.5.1，先供本地审查；学校正式下载和更新源与 GitHub 发布分别维护。借鉴 ClassIsland 的顶部常驻信息条形式，使用 ICeClass 自有界面、图标和原生 Avalonia 控件。

现已扩展课表、作息、单双周、临时调课、Excel、上下课提醒、日期/倒数日/文字组件、外观设置和自动化，并接入教师端配置、班级下发及离线缓存。完整使用说明见 [教室岛课表与自动化](教室岛课表与自动化.md)；下方保留常驻布局和弹簧动效的设计及验收记录。

## 使用

- 完成教室绑定后，主屏幕显示日期与课表两个胶囊。信息条内容高 48 DIP，含底部留白的窗口高约 54 DIP；全天课程按顺序显示，非当前课程用首个完整 Unicode 字符缩写，当前课程或课间用全名、时间和进度显示，已结束课程淡化。默认浅色、顶部居中、最大宽 560 DIP，可设置位置与 380-1000 DIP 最大宽度，内容较少时柔和缩短。时间段使用普通连字符 `-`。
- 点击细条查看早读、今日课表、连接状态及操作，Esc 收起。手动展开与收起沿用可中途反向的临界阻尼弹簧。自动提醒保持细条高度，以约 550 毫秒的斜向擦入切换内容，并短暂向桌面扩散青色波纹；倒计时和课前短句以约 200 毫秒上下切换，每 10 秒轮换一次。提醒结束后恢复课表并更新当前课程。
- 关闭 Windows 界面动画时直接切换状态；隐藏、早读全屏或退出程序会停止过渡。收起后原生窗口同步缩小，不保留挡住下方操作的透明区域。
- 屏幕高度不足时，展开内容可以滚动，底部操作仍可到达。
- 早读状态使用当前绑定班级的现有规则及校准后的服务器时间；提醒开关不影响时段显示。配置作息与课程后展示实际课程和倒计时，不显示虚构的课程或活动进度。
- 三种教师喊话都留在同一悬浮岛里。普通为冰蓝 `#EDF6FF`：班班从左侧出现，轻招一次手后陪伴；约 2.2 秒的“班班传话”提示后显示正文，保持 48 DIP 细条，整个窗口约 72 DIP 高。重要为浅黄 `#FFF7E5`：班班抓住边缘、迈腿小跑，把短岛向两边拉长，默认总宽由 560 到 688 DIP（受屏幕可用宽度限制），停稳后扶边招呼；约 1.6 秒后显示正文，短文字保持细条，长文字在同一岛面展开成两行。紧急为浅红 `#FFF0F1`：正文立即出现，班班一手抓岛边、一手握住大喇叭，迈腿小跑拉开同样距离，停稳后将喇叭举到嘴边；手掌始终扣在手柄处，喇叭随手臂移动。长文字也在岛内展示两行。所有级别都不会自动变为全屏。
- 长消息按实际字体宽度分段，每 4 秒切换一页，重要和紧急每页最多两行，保留完整 Unicode 字符并避免标点独占行首。点击岛条可在同一岛面展开全文，最长 500 字可以滚动。沿用原有 5-60 秒展示时长，到期恢复全天课表。
- 紧急优先于重要、重要优先于普通；同级和较低级别依到达顺序排队。被较高级别打断的消息随后恢复剩余展示时间，声音不重复播放。等待时已过有效期的消息不再展示。真实消息始终优先于本机演示，结束演示只清除演示样例。
- 原文字朗读、语音下载播放、权限验证继续使用现有流程。普通级别保持静默，重要和紧急按发送设置朗读或播放录音；语音通知保留明确标记，不生成不存在的转写。点击“已知晓”收起喊话、停止声音并向教师发出人工确认；Esc 仅收起和停止声音，不算人工知晓。教师历史分别显示“已展示，待知晓”和“教室已知晓”，CSV 保留人工知晓时间。自然到期停止文字朗读，已开始的录音按原逻辑播放完。喊话期间课表提示音和自动化队列暂缓，结束后恢复。
- 即使日常悬浮岛已隐藏、淡化、设置鼠标穿透或因全屏而避让，教师喊话仍会暂时显示为清晰、可操作的置顶岛条；结束后恢复原偏好，不改变保存设置。喊话不自动展开早读和设置操作面板。关闭 Windows 界面动画时，侧边布局保留，拉动、招手与擦入直接停用。
- 点击“淡化”后，收起面板并移开鼠标，信息条透明度降至 45%；移入、键盘操作、展开面板或收到通知时恢复清晰。
- “隐藏”和窗口关闭操作隐藏悬浮岛。教室首页的“顶部悬浮岛”按钮，或托盘菜单的“显示顶部悬浮岛”，可以恢复。隐藏和淡化选择会保存，重启后继续生效。
- 自带早读窗口全屏时，日常悬浮岛自动隐藏；退出全屏、最小化或关闭早读后，按原显示偏好恢复。教师喊话在全屏期间也可显示。

显示偏好单独保存在用户数据目录的 `ICeClass/Receiver/island-settings.json`，不修改绑定凭据。连接本机回环地址的验收程序将该文件放在程序旁边，与正式安装隔离。

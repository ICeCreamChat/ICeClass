## 2026-10-18 账号独立连接

所有已登录账号都能打开“更多 → 连接设置”，选择学校提供或自行配置。个人连接填写 Base URL、API Key、模型 ID，支持兼容 OpenAI 的流式对话和工具调用接口，不再固定为 DeepSeek。DeepSeek、百炼、GLM、Kimi、豆包提供常用配置，其余兼容服务可自定义填写。关闭个人智能分析会提供数据速览，不会悄悄改用学校密钥；选择学校连接后保留个人配置，方便之后切回。

个人配置按登录账号保存，其他账号（包括超级管理员）不能通过接口读取他人的配置或密钥。已保存的密钥不回显，不写入浏览器存储。教师仍只分析获授权班级；主任、校长和超级管理员的全校分析权限沿用原规则。学校连接只有超级管理员可以从“管理学校服务”修改，旧学校配置自动兼容。

服务地址仅接受公网 HTTPS；实际连接时检查 DNS 返回的每个地址，不跟随重定向。修改已保存的服务地址必须重新填写对应密钥，学校密钥不会继承到个人连接。支持带 /v1 或其他兼容路径的地址，也会去除误粘贴的 /chat/completions 后缀。

连接设置按“连接方式 → AI 服务商 → 服务地址 → API 密钥 → 模型”排列，底部操作固定，长内容仅在表单内部滚动。配置保存后显示“已配置”，只有连接测试完成才显示“测试通过”；保存成功而测试失败会明确告知配置仍已保存。学校配置只影响选用学校连接的账号，个人配置仅作用于当前账号。数据说明区分别解释智能分析发送的授权数据、来音不发送录音、密钥由本平台服务器保存、测试不发送班级数据。统一使用“您”，不再使用“全校共用”“仅供您使用”“可选择下方建议”等不准确描述。

所有账号可从“更多 → 连接设置”选择自己的连接，填写 Base URL、API Key、模型名称后点击“保存并测试”；已有配置可直接“测试连接”。“返回对话”保留原聊天和阅读位置。个人配置按用户主键保存在数据库的 `banban_connections`，更改不会影响其他账号。学校配置仍由超级管理员管理，保存在数据库目录旁的 `banban-settings.json`，Linux 写入权限为 0600。数据库与该配置均不进入 Git、静态资源或发布包。学校连接也支持服务端环境变量 `DEEPSEEK_API_KEY` 与 `ICECLASS_DEEPSEEK_MODEL`，后台保存的配置优先。地址不变时，密钥留空保留旧值。

服务器调用所选连接的公网 HTTPS `/chat/completions` 接口，支持自定义模型 ID。个人与学校连接均可使用兼容服务；原 DeepSeek 学校配置无需重新填写。单账号同时只处理一个分析或测试请求；连接超时或额度/凭据问题显示错误并保留问题供重试。

**此前已使用用户提供的 API Key 完成本地真实 DeepSeek 联调**，使用模型为 `deepseek-flash`。本次设置界面改造只使用独立模拟服务测试，未再次调用真实模型。密钥存放于被 Git 忽略的本地配置，不写在本文或发布包中。真实流式回答、跨班级与日期追问及管理员“测试连接”此前已验证；正式学校服务器的连接与配置需部署时另行验证。未配置或关闭智能分析时仍可使用服务器计算的“数据速览”。

# 2.5.5 轻量安装与语音资源准备

本轮为本地构建与验收记录，尚未发布或部署到学校平台。

- 默认提供轻量教室端和教师端，另提供两端完整离线包；保留原有绑定、设置和登录资料。
- 教室设置和教师端“桌面设置”增加“下载语音资源”，一次补齐全部所需资源。支持下载进度、暂停、继续与失败重试；自动准备遵守课堂和空闲规则，手动准备仍让早读、录音和对话优先。
- 资源未齐时继续使用文字与原声录音。教室端优先补齐播报；下载完成后无需重启。教师端复用既有识别缓存，完整教师包支持校验安装识别模型。
- 语音资源由当前学校平台提供，校验路径、文件大小与 SHA256，支持断点续传；不会生成程序待安装记录。
- 沿用两端原有字体、SemiBold 按钮及进度样式，检查正常与窄窗口、键盘焦点、错误和就绪状态。

安装与下载入口见[客户端更新说明](客户端更新说明.md)。实际构建、测试、安装包尺寸和验收结果记录在本轮本地验收报告中；尚未完成的现场硬件检查不计为通过。

# ICeClass · 班伴

**班级伴学与管理平台**，把早读陪伴、班级比赛、白板管理和远程通知放在同一套系统里。管理员用浏览器管理，教师用手机或电脑查看，教室白板运行一个 Windows 单文件程序。

班伴由 ICeCreamChat 维护，基于原 ICeCreamShouter 平台扩展为独立项目。当前版本 **2.0.1**。

## 早读与比赛

- 包含拔萝卜、诗词镌刻、粒子浮雕、火箭升空四种陪伴模式，沿用原早读陪伴的内容和动画。
- 管理员设置每周早读时段、统一声量门槛和玩法参数。教师可以选模式和内容、开始与暂停，不能在陪伴页面改这些参数。
- 软件可以随时打开，只有北京时间的指定时段内，运行且声量达到门槛的秒数计入比赛。
- 排名按所选日期累计的**有效发声时长**计算，相同时长并列。不设置必须读满的时间或满分目标。
- 同班多个窗口或设备不能把同一秒重复计入时长。暂停、隐藏页面和时段外活动不增加有效时长。
- 展示各班使用次数、使用天数、运行时长、有效时长、达标占比、所选模式和完成量；可按天查看、筛选日期和班级、导出 CSV。
- 完成量按模式展示：萝卜、诗词、徽章、火箭发射和能量格，分别记录，作为过程信息。

这里的声量是软件检测的相对强度，代表出声参与情况，不代表朗读正确率。按相对公平的约定，不做麦克风校准；建议比赛时使用相同门槛，并由管理员统一白板播放音量。

## 教室管理与通知

- 管理员远程设置 Windows 默认播放设备音量，支持 30%、50% 快捷按钮、任意 0—100% 和全部启用班级。音量设置在离线时保存，设备重连后应用。
- 显示设备在线状态、当前/期望音量、应用状态和教室端版本；可在在线教室远程打开早读。
- 保留文字和教师原声通知、普通/重要/紧急提醒、学生给教师的语音留言、历史记录及删除/导出功能。
- 管理员 `ICe` 管理班级、教师和授权；教师只查看自己获授权的班级。
- 教室端支持 Windows 10/11 x64、系统托盘、开机启动、断线重连和自动更新；一次性绑定码有效 15 分钟。

## 先验收，再正式部署

1. 从 GitHub Releases 下载教室端 ZIP 和服务器 ZIP。
2. 本地体验：在源码目录双击 `start-preview.bat`，打开 `http://127.0.0.1:8837/`。需要 Python 3.10+，首次运行自动创建隔离环境。演示账号与数据见 [验收指南](docs/验收指南.md)。
3. 正式部署：使用独立域名和 Ubuntu Server 24.04 LTS，按 [部署手册](docs/完整操作流程.md) 操作。
4. 创建班级、教师和绑定码，把 `ICeClass.exe` 放到教室电脑，填写新平台网址并绑定。
5. 管理员设置早读时段，在一间真实教室检查麦克风、计时、完成量、远程 30%/50% 音量，再推广到各班。

正式数据库不包含演示账号或密码。本地演示只监听 `127.0.0.1`，示例数据存放在 `.tools/preview/demo.db`。

## 代码与构建

| 路径 | 用途 |
| --- | --- |
| `server/` | Python/aiohttp、SQLite、WebSocket 服务端及早读统计 |
| `web_controller/` | 教师/管理员网页和完整早读陪伴资源 |
| `Receiver/` | Avalonia/.NET 8 Windows 教室端 |
| `cloud/migrations/` | 服务端使用的数据库结构 |
| `scripts/` | 部署、交付、发布包和本地演示脚本 |
| `cloud/src/` | 原 Cloudflare 通知服务参考实现，未实现班伴新增的早读/教室控制接口 |

班伴完整功能使用 `server/` 部署。`deploy-cloud.bat` 是旧通知服务的可选入口，不用于部署本版完整平台。

```powershell
python -m pip install -r server/requirements.txt
python -m unittest discover -s server -p "test_*.py" -v
npm ci
npm run typecheck
npm test
dotnet build Receiver/Receiver.csproj -c Release
```

双击 `build.bat` 生成自带运行环境的 `dist/receiver/ICeClass.exe`。管理员运行 `package-release.bat` 生成两个发布 ZIP；配置正式地址后运行 `prepare-delivery.bat` 生成教师快捷方式和教室交付目录。教室电脑不需要安装 .NET、Python 或 Node.js。

# ICeClass 班伴

班级伴学与管理平台，把早读陪伴、课表浮岛、班级通知、教室来音和班班助手放在同一套系统里。教师和管理员使用网页或 Windows 教师端，教室大屏使用独立的 Windows 教室端。

[学校平台](https://iceclass.icecreamchat.top/) · [轻量教室端](https://iceclass.icecreamchat.top/api/client/download/classroom) · [轻量教师端](https://iceclass.icecreamchat.top/api/client/download/teacher) · [GitHub Releases](https://github.com/ICeCreamChat/ICeClass/releases/latest)

由 ICeCreamChat 维护，基于原 ICeCreamShouter 平台扩展为独立项目。项目采用[非商业学习参考许可](LICENSE)，运行、部署、修改和再分发等使用须另行取得书面授权。

## 三端分工

| 入口 | 使用者与用途 | 环境 |
| --- | --- | --- |
| 网页工作台 | 教师、管理员维护班级、课表、通知、统计和权限 | 现代浏览器，连接学校平台 |
| Windows 教师端 | 网页工作台功能，加桌面来音提醒、本机转文字、反馈和自动更新 | Windows 10/11 x64、WebView2 Evergreen Runtime |
| Windows 教室端 | 教室绑定、离线早读、通知接收、课表浮岛、留言、创意计划和班班语音 | Windows 10/11 x64、WebView2 Evergreen Runtime |

## 安装与首次使用

### 教室端

1. 下载并完整解压[轻量教室端](https://iceclass.icecreamchat.top/api/client/download/classroom)，运行“安装或升级.cmd”。
2. 确认平台网址，输入学校提供的全校绑定码或单班绑定码，点击“读取班级”。
3. 按“年级 → 班级”选择本教室，核对后绑定；每台新电脑独立绑定，不复制其他电脑的设备资料。
4. 根据需要启用开机自动接收通知，在本机验证声音、麦克风和课表显示。

班级名单由服务器读取。新增班级、升班、更名或管理员改绑不需要重新安装程序；正常升级保留原绑定、设备身份和本机设置。点窗口“×”会收起到托盘并继续接收，托盘“退出”才结束程序。

### 教师端

1. 下载并完整解压[轻量教师端](https://iceclass.icecreamchat.top/api/client/download/teacher)，运行“安装到本机.cmd”。
2. 使用学校网页账号登录，无需教室绑定码；可操作范围与网页一致。
3. 从“桌面设置”管理本机选项和语音资源，从“关于”查看更新记录及诊断日志。

教师端安装到当前 Windows 用户目录，并创建桌面和开始菜单入口。关闭窗口后收起到托盘。安装、目录及多端验收方式见 [Windows 教师端](docs/Windows教师端.md)和[三端本地验收](docs/三端本地验收.md)。

## 轻量安装与语音资源

默认轻量包先安装程序，语音资源在课间空闲时后台准备。文字通知、教师原声和来音播放不依赖资源全部下载完成；教室端先准备自然语音播报，再准备唤醒、识别等资源，界面分别显示就绪状态。

需要主动下载时：

| 客户端 | 入口 |
| --- | --- |
| 教室端 | 教室设置 → 更新与测试 → 下载语音资源 |
| 教师端 | 桌面设置 → 语音资源 → 下载语音资源 |

点击下载会一次补齐**当前客户端所需的全部语音资源**，可查看进度、暂停、继续或失败重试。断线和重启保留下载断点，校验通过的本机资源直接复用；手动暂停会保持到再次继续。早读、录音和对话等实际活动优先，结束后继续下载。资源就绪无需重启程序。

需要集中拷贝到多台电脑时，也可下载[含完整语音资源的教室包](https://iceclass.icecreamchat.top/api/client/download/classroom-offline)或[教师包](https://iceclass.icecreamchat.top/api/client/download/teacher-offline)，完整解压后安装。这里的“完整”指客户端资源已随包提供；首次绑定、账号登录、学校同步、在线 AI 及云端来音仍需联网。

## 后续更新

教师端和教室端都支持文件级增量更新：未变化的文件校验后复用；有适用且更小的差分补丁时下载补丁，否则下载发生变化的文件。更新不要求每次重新下载完整安装包，但跨版本或缺少匹配基线时，部分文件仍需完整下载。

- **自动更新**：课间空闲时检查和下载；早读、录音、对话等活动期间暂缓。课表未知时延后自动下载。下载校验完成后显示“已就绪”，下次真正启动时安装，关闭到托盘不算退出。
- **立即更新**：手动操作后下载、校验、启动安装助手，退出旧程序并自动打开新版；已就绪的内容不重复下载。有正在进行的任务时提供明确提示，教师端提示先保存页面内容。
- **保留与恢复**：保留班级绑定、登录资料、设置和本机数据；安装前核对文件大小与 SHA256，支持断点续传及失败恢复。

2.5.6/2.5.7 教室端曾存在“立即更新”按钮无响应的缺陷，需要从托盘退出后重新打开，让已下载更新在启动时安装，或用新版轻量包运行“安装或升级.cmd”完成一次升级。旧版协议与体积限制见[客户端更新说明](docs/客户端更新说明.md)。

## 早读陪伴与统计

教室端内置兔拔萝卜、诗词镌刻、粒子浮雕、火箭升空四种模式及媒体。断网可运行，统计先保存本机，联网后补传。

- 点击“开始早读陪伴”进入全屏；白板长按空白处 2 秒退出全屏，移动或松手取消，键盘 Esc 也可使用。退出全屏后早读继续，返回教室首页才结束采音。
- 校长与超级管理员设置全校早读时段及声量门槛；玩法目标、时长和动画速度在本机原设置面板调整。
- 比赛只累计北京时间指定时段内、活动运行且声量达标的有效发声秒数；同班多台设备不重复累计同一秒。暂停、隐藏页面和时段外活动不增加有效时长。
- 按日期、班级查看使用次数、使用天数、运行时长、有效时长、达标占比和各模式完成量，支持 CSV 导出；排名按有效发声时长计算，相同时长并列。

声量表示相对出声强度，不代表朗读正确率，也不进行麦克风校准。早读检测不上传原始麦克风音频。详见[早读使用说明](docs/早读使用说明.md)。

## 课表浮岛与批量设置

教师端和网页共同维护周课表、作息时间、单双周、临时调课、值班、提醒与外观、轮播信息和自动化，支持 Excel 导入导出。教室端同步后离线显示和运行。

“批量设置”统一包含按内容同步和整套复制：选择来源、勾选内容、选择年级或班级、预览各班变化后应用。未勾选的内容保留各班原设置，权限范围外班级不能修改；支持班级搜索、草稿保存和继续编辑，版本冲突时提示重新核对。

浮岛提供日期、倒数日、文字和课表显示，以及课前、上下课提醒。教师端可预览；教室端保留本机动画开关。普通、重要、紧急通知在岛内展示，使用不同强调色与班班动作，保留语音、优先级队列和人工知晓回执。详见[课表与自动化](docs/教室岛课表与自动化.md)、[顶部浮岛](docs/教室端顶部悬浮岛.md)和[批量设置实现说明](docs/plans/2026-11-03-island-bulk-ux.md)。

## 通知、来音与教室控制

- 支持文字和教师原声通知、普通/重要/紧急等级、通知记录及回执。
- 学生可给教师发送语音留言；教师端提供桌面提醒、主动收听及本机转文字，不自动播放录音。
- 管理员在授权范围内查看已绑定设备的在线状态、客户端版本、当前和期望音量，远程设置 0～100% 音量或打开早读。离线音量设置在设备重连后应用。
- 班级升班保留编号、授权、设备绑定与历史；换教室时可远程改绑。同班多设备可通过电脑名、设备编号、局域网地址和位置备注核实。

## 班班助手与桌宠

网页和教师端可用班班查询授权范围内的早读表现、通知回执、来音数量与时长、设备概况，并按明确要求维护通知、班级、课表及允许的电脑操作。修改、删除、保存等操作提供确认卡，执行结果以服务端或设备实际回执为准。

学校连接由校长与超级管理员维护；个人可使用自己的模型连接，密钥保存在服务端，不向界面回显。切换模型不扩大账号权限。未配置或停用 AI 时提供标明状态的数据概览，不执行 AI 操作。

教室端绑定班级后，关联该班唯一启用的班主任账号，沿用其模型连接，查询与操作限定当前班级。教室与教师的对话隔离；班主任未分配或关联不唯一时显示具体提示。

资源准备好并启用语音后，可说“你好班班”唤醒，也可点击桌宠或“呼叫班班”立即收听。支持连续对话、语音反馈、打断、停止和取消；识别在本机进行，在线分析与任务仍依赖学校平台和配置的模型服务。桌宠复用分层角色及连续动作：

| 操作 | 行为 |
| --- | --- |
| 单击人物 / 首页“呼叫班班” | 召出并开始收听 |
| 双击人物 / 右键“打开对话” | 查看完整对话、历史和确认卡 |
| 拖动人物 | 完整展开，松手停靠到最近的左右边缘并保存位置 |
| 右键“大小” | 25%～150% 实时预览并保存，“恢复默认”为 80% |
| 右键“移回桌面右下角” | 复位位置，保留大小 |
| 右键“停止操作” / “暂停语音” | 取消当前任务，或暂停收听与播报 |
| 右键“隐藏班班” | 收起人物，从托盘可恢复 |

上课时桌宠自动隐藏，语音唤醒仍可使用。识别效果受距离、噪声、麦克风和多人声音影响，实际学校环境需要现场验收。详见[语音助手](docs/班班语音助手.md)、[防串声说明](docs/班班语音防串声.md)、[电脑操作](docs/班班操作与电脑控制.md)和[桌宠说明](docs/班班桌宠与响应速度.md)。

## 创意计划与教师反馈

学生从教室端“创意计划”提交文字、手写、纸条图片或语音，先核对再提交，也可查看本班进度。超级管理员评审并回复，是否向全校展示单独确认；公开成果只展示确认后的标题、摘要、班级和状态，不公开原稿、姓名、照片或录音。

Windows 教师端的“反馈”支持问题描述、可选联系方式、诊断和截图，发送前可预览日志。邮件通过服务器配置的邮箱投递，SMTP 密钥不放在客户端；未配置或发送失败时提供错误提示并保留草稿。详见[创意计划](docs/千人创意计划.md)和[反馈邮件配置](docs/教师反馈邮件配置.md)。

## 更新记录与诊断日志

教室端和教师端的“关于”均提供致谢、许可说明、更新记录与诊断日志，可刷新、复制、导出，也可手动提交近期完整日志。

错误与必要运行状态默认自动脱敏上报；完整近期日志由用户手动提交。超级管理员在“账号设置 → 客户端日志”按设备、版本、时间等条件查看，方便远程排查动画、下载、更新和连接问题。

服务器每周一北京时间 03:00 起的首次维护中，批量删除超过 7 天的客户端诊断；停机后恢复运行会补做。诊断另有容量及条数限制，清理不删除账号、班级、早读统计等业务数据。日志不应包含密码、令牌或原始麦克风音频，提交前仍可查看诊断内容。设计范围见[关于与诊断说明](docs/superpowers/specs/2026-11-03-about-diagnostics-design.md)。

## 权限、数据与隐私

校长、主任、年级部、班主任和任课教师按授予范围工作；超级管理员管理系统。查询与操作分别鉴权，全校统计权限不会自动扩大可操作班级。班班复用现有业务接口的授权和版本校验。

业务数据由学校服务端保存，本机保存必要的绑定、偏好、缓存与待补传统计。Windows 教室端资料位于 `%LOCALAPPDATA%\ICeClass\Receiver`，早读相关数据位于同级的 `Reading`、`ReadingAssets` 和 `ReadingData`。不要删除待补传数据或把绑定配置复制给其他班级。

早读声量检测不上传原音；教师原声、学生留言和创意附件按用户主动操作提交。启用在线 AI 后，与当前问题或任务有关的授权资料、对话和必要上下文会发送到配置的模型服务，具体范围见[智能交互说明](docs/班班智能交互说明.md)。账号、班级与设备维护见[用户权限与管理](docs/用户权限与管理.md)。

```powershell
.\build.bat
.\build-desktop.bat
.\package-release.bat
```

`build.bat` 校验语音模型并分别生成完整教室程序和精简核心；模型二进制不进入 Git，已校验资源可复用。`package-release.bat` 默认重新构建两端并打包，使用已验收产物时可调用 `scripts/package-release.ps1 -SkipBuild`。

| 产物路径 | 内容 |
| --- | --- |
| `dist/receiver/ICeClass.exe` | 内嵌完整语音资源的教室端 |
| `dist/receiver-core/ICeClass.exe` | 轻量教室核心及增量更新用程序 |
| `dist/desktop/ICeClass.Desktop.exe` | Windows 教师端 |
| `dist/release/` | Windows 完整交付、服务端、轻量/完整教室包、轻量/完整教师包 |

打包可通过 `-DistributionDirectory` 指定已有构建目录，通过 `-PreviousServerDirectory` 指定上一版服务端目录以生成差分补丁；无匹配旧文件时仍生成可用的文件级更新计划。教师端与服务端包不包含个人登录资料或 API Key。

GitHub Actions 的 **Publish release** 在推送 `v*` 版本标签或手动运行时检查、构建和发布。当前工作流发布教室端、Windows 教师端、Windows 完整交付和服务端四种 ZIP，另附 Ubuntu 更新脚本及 SHA256 校验清单；普通源码推送不生成 Release。完整步骤见 [GitHub 自动发布](docs/GitHub自动发布.md)。

## 部署与维护

推荐 Ubuntu Server 24.04 LTS、专用域名与 HTTPS。首次部署按[完整操作流程](docs/完整操作流程.md)配置，例如：

```bash
sudo bash server/install-ubuntu.sh YOUR_DOMAIN YOUR_RANDOM_BOOTSTRAP_TOKEN
```

使用自己生成的至少 32 字符初始化令牌，不要把令牌或服务器环境文件提交到 Git。首次设置管理员后创建班级、分配教师、开放绑定码，再在一间教室验证后推广。

已有安装使用与目标版本配套的服务器 ZIP 更新，例如：

```bash
sudo bash scripts/update-ubuntu.sh /path/to/ICeClass-2.5.9-server.zip 2.5.9
sudo systemctl status iceclass
sudo journalctl -u iceclass --no-pager -n 80
```

更新脚本备份数据库与程序，核对账号、班级、绑定及配置，失败时恢复。默认程序位于 `/opt/iceclass/app`，虚拟环境位于 `/opt/iceclass/venv`，数据位于 `/var/lib/iceclass`，备份位于 `/var/backups/iceclass`，环境文件为 `/etc/iceclass.env`；`iceclass.service` 监听本机 `127.0.0.1:8865`，由 HTTPS 反向代理提供访问。

备份和迁移须同时覆盖数据库及实际使用的媒体目录；创意附件与普通来音的保留规则不同。不要把客户端诊断每周清理当作业务数据清理，也不要删除更新失败恢复所需资料。

# ICeClass 班伴

**班级伴学与管理平台**，把早读陪伴、班级比赛、白板管理和远程通知放在同一套系统里。教师和管理员可用网页或 Windows 教师端；教室白板使用独立的教室端。

ICeClass 班伴由 ICeCreamChat 维护，基于原 ICeCreamShouter 平台扩展为独立项目。学校平台最近一次已确认部署版本为 **2.4.0**，地址为 [ICeClass 班伴平台](https://iceclass.icecreamchat.top/)。[学校平台教室端下载](https://iceclass.icecreamchat.top/download/ICeClass-classroom.zip) · [学校平台 Windows 教师端下载](https://iceclass.icecreamchat.top/download/ICeClass-teacher.zip) · [GitHub 发布页](https://github.com/ICeCreamChat/ICeClass/releases/latest)。

当前开发与本地审查候选为 **2.5.1**。源码同步、GitHub 安装包发布与学校部署分别处理；本候选尚未发布安装包或部署至学校服务器。候选继续包含 2.5.0 的完整功能，并修复大包更新与真实桌宠动作衔接。升级步骤与验收边界见 [2.5.1 版本说明](docs/发布记录-2.5.1.md)。班班支持“你好班班”后台唤醒、连续对话、任务操作、语音反馈、打断和取消，复用学校权限及真实设备回执。Windows 教室端内置 SenseVoiceSmall INT8 整句识别、MeloTTS 中英神经语音、Silero 语音活动检测与本次对话的说话人比对，结合 Windows 回声消除处理播报中的插话。未知词会要求重说，不直接提交为任务；数学公式先转成适合朗读的语句。新增贴边、课中隐藏、唤醒跳出的班班桌宠和 24 种连续动作，以及文件夹访问、文稿创建、应用最大化和可配置的视觉 API 操作。已有真人验收覆盖中文唤醒、完整识别、实际改字与停止口令；真实教室远场、多人声音及第三方软件兼容性仍需现场验收。包含教室浮岛课表与自动化、教师工作台切换和聊天排版改进。功能与限制见 [语音使用说明](docs/班班语音助手.md) 和 [2.5.0 版本说明](docs/发布记录-2.5.0.md)。GitHub 发版与学校部署分别执行，发布附件不表示正式服务器已更新。

2026-10-31 源码整理包含此前累积的通知提示音与自然语音、两端致谢、班主任自动关联、共享控件及安装升级修复，并保留本轮确认的连续对话、气泡、收听声波、退场动作和教室首页直接收听入口。每轮回答后继续等候，空闲 3 分钟回待机；“退下吧”会让班班挥手、退到停靠边缘消失，再次唤醒可以回来。身份回答围绕“马鞍山市第二十二中学数学学科许斌老师开发、AI 建模社参与共建”自然表达。

教师登录页沿用浅蓝与白色及左侧原有班级插画，右侧班班随密码框焦点捂眼、随显示密码操作偷看。最后一次分层动画实验已撤回，当前保留撤回前的逐帧版本；素材与交互说明见 [Windows 教师端说明](docs/Windows教师端.md)，本次实际检查与未验证项见 [2.5.1 完整验收报告](docs/完整验收报告-2.5.1.md)。

四种活动和视频随客户端提供，断网照常运行，统计先保存本机、联网后补传，客户端更新支持续传。正式服务器、教室端下载及教师端更新接口仍以学校已部署版本为准，原账号、班级绑定和早读规则保留。使用范围和早期本地验证记录见 [2.3.0 验收说明](docs/本地验收-2.3.0.md)。

平台加入“班班”悬浮数据助手：采用用户提供的小书灵与 MAS 徽章，眼神、侧身与托脸依次衔接，等待时显示更大的陪伴角色，按真实记录区别回应，支持点击招呼、附近眼神、拖动回弹和每天最多一次的静音轻提醒。聊天小窗支持移动、收起，动效和轻提醒均可关闭。接入方式、隐私范围与验证结果见 [班班验收记录](docs/班班本地验收.md)。

**Windows 教师端**随本次候选配套交付：安装到当前 Windows 用户目录，创建桌面和开始菜单入口，关闭窗口后收起到托盘。沿用网页账号、功能和授权，不需要班级绑定码；详情见 [Windows 教师端说明](docs/Windows教师端.md)。教师端应用、工作台侧栏和网页图标统一使用新版教师图标。

本机分别打开教室端、网页端和 Windows 教师端，请使用桌面“班伴三端验收”文件夹（沿用原目录名），或参照 [三端本地验收入口](docs/三端本地验收.md)。学校职责已区分校长、主任、年级部长和班主任教师，分配与操作说明见 [用户权限与管理](docs/用户权限与管理.md)。

## 早读与比赛

- 点击教室首页的“开始早读陪伴”，内容铺满整个显示器，全屏时隐藏客户端栏和网页栏。白板长按屏幕空白处 2 秒退出全屏，松手取消；退出后点击“返回”结束早读并停止采音。键盘 Esc 仍可使用。需要 Windows 10/11 x64 与 WebView2 Evergreen Runtime。
- 包含兔拔萝卜、诗词镌刻、粒子浮雕、火箭升空四种陪伴模式，沿用原早读陪伴的内容和动画。粒子封面改为去除底框的原图，内部玩法保持原样。
- 校长与超级管理员 ICe 可在后台查看和设置全校每周早读时段、统计声量门槛。目标、时长、动画速度继续在早读陪伴的原本地操作面板设置，平台后台不管理玩法参数。
- 软件可以随时打开，只有北京时间的指定时段内，运行且声量达到门槛的秒数计入比赛。
- 排名按所选日期累计的**有效发声时长**计算，相同时长并列。不设置必须读满的时间或满分目标。
- 同班多个窗口或设备不能把同一秒重复计入时长。暂停、隐藏页面和时段外活动不增加有效时长。
- 展示各班使用次数、使用天数、运行时长、有效时长、达标占比、所选模式和完成量；可按天查看、筛选日期和班级、导出 CSV。
- 完成量按模式展示：萝卜、诗词、徽章、火箭发射和能量格，分别记录，作为过程信息。

这里的声量是软件检测的相对强度，代表出声参与情况，不代表朗读正确率。按相对公平的约定，不做麦克风校准。

## 教室管理与通知

- 管理员远程设置 Windows 默认播放设备音量，支持 30%、50% 快捷按钮、任意 0—100% 和全部启用班级。音量设置在离线时保存，设备重连后应用。
- 教室控制只显示已绑定且启用的电脑，展示在线状态、当前/期望音量、应用状态和客户端版本；可在在线教室远程打开早读。
- 保留文字和教师原声通知、普通/重要/紧急提醒、学生给教师的语音留言、历史记录及删除/导出功能。
- 校长管理全校；主任管理高一、高二、高三；年级部长管理负责年级；班主任教师使用本人班级。管理账号可在各自范围内维护班级、设备、记录与下级用户；全校规则由校长与超级管理员维护。
- 年度升班保留班级编号、教师授权、设备绑定和历史记录；换教室时可单独远程改绑电脑。同班多台电脑提示核实，显示电脑名、设备识别编号、局域网地址和位置备注。
- 教室端支持 Windows 10/11 x64、开机启动、断线重连和自动更新。首次运行创建桌面快捷方式，同时显示系统托盘图标；点窗口“×”收起到托盘，连接继续，再点桌面图标可打开已有窗口；托盘“退出”才结束程序。
- 本地新增教室岛：教师端维护课表、作息、单双周与临时调课，支持 Excel、课前和上下课提醒、日期/倒数日/文字组件、外观设置及时间/课程自动化；教室端同步后离线运行，以 48 DIP 顶部细条显示课表，提醒使用斜向擦入、扩散波纹和文字切换，操作面板可手动展开。教师端支持本地动画预览。使用方式及验收见 [课表与自动化](docs/教室岛课表与自动化.md) 和 [顶部悬浮岛动效](docs/教室端顶部悬浮岛.md)。
- 本地喊话预览：普通冰蓝、重要浅黄、紧急浅红，三种都在岛内展示，班班在侧边招手、扶边拉宽或认真指向正文；保留语音、优先级队列与人工知晓回执。托盘“预览班班喊话”可单选或连播，演示仅在本机运行。GitHub 附件与学校正式下载分别更新；本次候选先供本地审查。
- 首次绑定使用“年级 → 班级”联动下拉框，预设高一 16 班、高二 14 班、高三 14 班；名单从后台读取，后续增减不需重装 EXE。新功能支持自动或手动更新，保留原绑定。详见 [客户端更新说明](docs/客户端更新说明.md)。
- 默认使用 ICe 开放的全校绑定码，各教室自行选班级，无需逐班生成；单班一次性码仍作为备选，有效 15 分钟。

## 下载与部署

1. 从 [GitHub Releases](https://github.com/ICeCreamChat/ICeClass/releases/latest) 下载教室端 ZIP 或服务器 ZIP。现有教室端可在托盘菜单或教室设置中点击“检查更新”。
2. 本地体验：在源码目录双击 `start-preview.bat`，打开 `http://127.0.0.1:8837/`。需要 Python 3.10+，首次运行自动创建隔离环境。演示账号与数据见 [验收指南](docs/验收指南.md)。
3. 正式部署：使用专用域名（可以是子域名）和 Ubuntu Server 24.04 LTS，按 [部署手册](docs/完整操作流程.md) 操作。
4. 创建班级和用户，开放全校绑定码。把 `ICeClass.exe` 放到教室电脑，输入绑定码、读取班级并选择本班。ICeClass 班伴正式网址已内置，其他部署可在连接设置中修改。
5. 管理员设置早读时段，在一间真实教室检查麦克风、计时、完成量、远程 30%/50% 音量，再推广到各班。

已有 Ubuntu 安装使用 `scripts/update-ubuntu.sh` 更新：`sudo bash scripts/update-ubuntu.sh /path/to/ICeClass-2.2.4-server.zip 2.2.4`。脚本备份现有数据库和程序，核对账号、班级、设备绑定与早读配置，失败时恢复原版本。首次部署仍使用部署手册。

正式数据库不包含演示账号或密码。本地演示只监听 `127.0.0.1`，示例数据存放在 `.tools/preview/demo.db`，脚本默认端口为 8837。连接本地验收服务的教室端不会修改 Windows 开机启动设置。

## 班班智能助手（本地验收）

登录后点击右下角“班班”，可以按日期、年级、班级查看晨读表现、通知回执、累计来音数量和时长，以及已绑定设备概况。班主任教师分析本人班级，年级部长分析负责年级，主任分析高一、高二、高三，校长与超级管理员分析全校；查询与操作分别核对权限，全校分析权限不会扩大可操作的班级范围。

每个账号可在“更多 → 连接设置”选择学校连接，或填写自己的 Base URL、API Key 和模型 ID；个人连接仅供本账号使用，切换连接不会扩大班级数据权限。学校连接由校长与超级管理员维护。密钥仅存服务端，不回显，也不进入 Git 或发布包。关闭智能分析或未配置时提供明确标注的数据概览。

启用 AI 后，班班按问题查询、比较数据，并可按明确要求发送通知、维护班级与账号、修改晨读和教室岛设置，以及操作已绑定电脑的允许应用。修改、删除、保存和应用控件等操作提供人工确认卡；密码只在确认卡填写。用户直接用自然语言安排任务，班班在后台查找目标并操作电脑；聊天仅显示必要的确认和执行结果。未配置模型时仍可查看数据速览，但不会执行操作。应用切换、课件放映、网站、文稿读取和文字替换的设置与兼容性见 [班班操作与电脑控制](docs/班班操作与电脑控制.md)。

服务器发送与当前问题或操作有关的授权资料：统计、通知文字样本、近期对话，以及所需的目标账号、设备与应用名称、控件文字和所选文稿内容。音频、转写、录音地址、密码、API 密钥和设备令牌不作为工具资料交给模型；教室来音仅使用数量、时长。每个账号独立保存多段完整会话，通过“历史”切换继续，“新对话”保留旧记录；默认每月 1 日按北京时间清理上一周期的对话，可改为每周一。账号和班级权限变化后，不再展示旧权限范围的对话。实现与验收说明见 [班班智能交互说明](docs/班班智能交互说明.md)。

教室端绑定班级后，班班自动使用该班唯一启用的班主任账号，无需另行登录；沿用该账号的模型连接和对话记录，教室查询和操作限定在当前班级。未分配班主任或关联多位时显示具体提示，由管理员调整班级归属。

## 代码与构建

| 路径 | 用途 |
| --- | --- |
| `server/` | Python/aiohttp、SQLite、WebSocket 服务端及早读统计 |
| `web_controller/` | 教师/管理员网页和完整早读陪伴资源 |
| `Receiver/` | Avalonia/.NET 8 Windows 教室端 |
| `Desktop/` | Avalonia/.NET 8 + WebView2 教师与管理员 Windows 教师端 |
| `cloud/migrations/` | 服务端使用的数据库结构 |
| `scripts/` | 部署、交付、发布包和本地演示脚本 |
| `cloud/src/` | 原 Cloudflare 通知服务参考实现，未实现 ICeClass 班伴新增的早读/教室控制接口 |

ICeClass 班伴完整功能使用 `server/` 部署。`deploy-cloud.bat` 是旧通知服务的可选入口，不用于部署本版完整平台。

```powershell
python -m pip install -r server/requirements.txt
python -m unittest discover -s server -p "test_*.py" -v
npm ci
npm run typecheck
npm test
node scripts/test-auth-mascot.cjs
node scripts/test-banban-voice.cjs
python -m unittest discover -s tests -p "test_*.py" -v
powershell.exe -NoProfile -File tests/test_classroom_installer_defaults.ps1 -OutputDirectory output/installer-defaults-check
dotnet build Receiver/Receiver.csproj -c Release
dotnet run --project tests/ReceiverOfflineChecks/ReceiverOfflineChecks.csproj --no-launch-profile
dotnet run --project tests/DesktopChecks/DesktopChecks.csproj -c Release
powershell.exe -NoProfile -File scripts/test-desktop-update.ps1
```

推送版本标签后，GitHub Actions 会自动检查、构建四种安装 ZIP、生成 Ubuntu 更新脚本和 SHA256，并发布对应的 Release。已有标签可通过 Actions 的 **Publish release → Run workflow** 补发；操作与权限见 [GitHub 自动发布](docs/GitHub自动发布.md)。GitHub 发版与学校服务器部署分开进行。

双击 `build.bat` 生成自带运行环境的 `dist/receiver/ICeClass.exe`。干净源码构建需要 Python 3.11+，脚本会先按固定来源和 SHA256 准备离线语音模型；模型二进制不放入 Git，已验证资源可直接复用。管理员运行 `package-release.bat` 生成 Windows 完整交付、服务端、精简教室端和 Windows 教师端四个 ZIP；精简包只含 EXE、一步说明和教师端入口。配置正式地址后运行 `prepare-delivery.bat` 生成教师快捷方式和教室交付目录。教室电脑不需要安装 .NET、Python 或 Node.js，也不需另行下载语音模型。

双击 `build-desktop.bat` 生成 `dist/desktop/ICeClass.Desktop.exe` 和独立安装 ZIP。`start-desktop-preview.bat` 使用独立本机资料连接 `http://127.0.0.1:8838/`；请先启动该本地验收服务。完整发布脚本也会生成桌面安装 ZIP，并将桌面更新 EXE 与信息放入服务器包的 `desktop_release/`；不包含个人登录资料或 API Key。

# 视频展台设计

本规范仅用于新的插件工作台、置顶浮窗和手机采集页，不替代 ICeClass 其他界面的 DESIGN.md。

模式为 Operate。画面是主体：顶部一行名称、来源与窗口操作；中央大预览；底部一条集中操作栏。设备和扫码仅在选择相应来源时展开。点评出现时显示简短结论、建议和知识点，保留固定作答。

色彩：canvas #e5f0f8、surface #f7fbff、ink #193c59、muted #4e6c83、action #0064d7、stage #142b42。文字使用 Microsoft YaHei UI, Microsoft YaHei, Segoe UI；正文 16px，操作 16-17px 半粗，标题 23px。大预览稳定，不通过背景动画抢夺注意力。

完整工作台默认 1200×780，可在 900×620 使用；浮窗约 580×440，360px 宽仍可操作。浮窗保留画面、拖动区、恢复工作台、点评/继续和停止；低频旋转、镜像等集中收纳，避免溢出。浮窗置顶，恢复后回到原工作台尺寸。

文案仅含名称、控件、真实状态和必要错误。没有口号、功能介绍、重复标题、技术路径、常驻协议说明或模拟学生评价。空画面只提示选择来源并提供动作。图标统一描边；图标按钮有 title 和 aria-label，键盘焦点为细淡蓝描边。

实现采用新 WinForms/WebView2 窗口和新 HTML/CSS/JS，复用经过验证的传输及点评算法。新程序为 ICeClass.VideoBooth.exe，旧桌面程序不进入插件包。最小可用闭环之后检查正常、窄窗、键盘、无摄像头、断流、点评错误与继续展示。
